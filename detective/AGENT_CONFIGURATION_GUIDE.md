# 叙事总监 Agent 配置指南

## 一、配置步骤

### 1. 打开Agent创建界面
在CodeBuddy界面中，找到"创建Agent"或"新建Agent"的入口。

### 2. 模式选择说明
CodeBuddy有两种Agent模式：
- **Agentic模式**：由主Agent自动判断调用时机，拥有独立上下文窗口，执行时不会污染主会话。适合任务明确、无需实时干预的自动化场景。
- **Manual模式**：由用户手动选择并启用，完全替代主Agent，全程可控。适合需要精细控制、深度定制交互的专业场景。

**推荐选择**：`agentic`模式，因为叙事总监Agent需要在剧情撰写时自动触发，无需每次手动调用。

### 3. 填写基本信息
- **名称**：`叙事总监`
- **Agent模式**：选择 `agentic`（下拉菜单中）
- **描述**：`专注于《神探沙盒》古代篇的剧情撰写和对话质量控制，确保符合游戏框架、角色一致性，且对话质量达到逆转裁判标准。`
- **Auto Run**：选择 `Enabled`（已默认选中）

### 4. 填写系统提示词
**重要**：系统提示词需要从简化版文件中复制。

**获取方式**：
1. 打开文件：`e:\godot\DetectiveSandbox\detective\AGENT_SYSTEM_PROMPT_SIMPLIFIED.txt`
2. 全选内容（Ctrl+A）
3. 复制（Ctrl+C）
4. 粘贴到"系统提示词"文本框中

**系统提示词内容概要**：
- 核心职责：剧情撰写、对话编写、逻辑校验、质量把控
- 必须参考的文档：META_STORY_BIBLE.md等
- 工作流程：剧情撰写流程、逻辑编写流程
- 质量标准：逆转裁判级别的对话节奏、角色语言风格
- 约束条件：叙事边界、技术约束、角色一致性约束
- 输出格式：剧情、对话、逻辑的输出格式

### 5. 选择模型
**推荐选择**：`mimo-v2.5-pro`
- 支持工具调用（supportsToolCall: true）
- 支持推理（supportsReasoning: true）
- 最大输入 tokens：128000
- 最大输出 tokens：8192
- 温度：0.7（适合创意写作）

**备选模型**：`mimo-v2.5`
- 额外支持图像（supportsImages: true）
- 其他参数相同

### 6. 配置工具
**推荐勾选所有工具**：
- ✅ **Read**：搜索并查看项目文件（必需，用于读取文档）
- ✅ **Edit**：创建、更新或删除文件和规则（必需，用于编辑CSV/JSON）
- ✅ **Execute**：在终端中运行Shell命令（必需，用于运行验证脚本）
- ✅ **Web**：访问网页内容与预览（可选，用于访问文档）
- ✅ **Skills**：Skill相关工具（可选，用于使用相关技能）
- ✅ **Others**：其他未分类工具（可选）

**工具配置说明**：
- **Read**：Agent需要读取META_STORY_BIBLE.md、character_profiles.md等文档
- **Edit**：Agent需要编辑对话树JSON、CSV数据文件
- **Execute**：Agent需要运行validate_case_tables.py等验证脚本
- **Web**：可选，用于访问在线文档
- **Skills**：可选，用于使用相关技能
- **Others**：其他工具

### 7. 确认创建
点击"确定"按钮完成Agent创建。

## 二、配置验证

创建完成后，验证Agent是否正常工作：

### 1. 测试剧情撰写
```
@叙事总监 请为序章「渡口沉舟」设计开场对话，要求：
1. 符合陆昭冷面书生的语言风格
2. 凌瑶碎嘴侠女的互动
3. 对话节奏达到逆转裁判标准
```

### 2. 测试逻辑校验
```
@叙事总监 请检查以下CSV数据格式是否正确：
case_id,case_name,difficulty
prologue_ferry,渡口沉舟,simple
```

### 3. 测试质量审核
```
@叙事总监 请审核这段对话的质量：
陆昭："说。"
凌瑶："嘶——大人，你看那个船家眼神不对啊！"
```

## 三、常见问题

### Q1: 系统提示词应该填什么？
A1: 从`AGENT_SYSTEM_PROMPT_SIMPLIFIED.txt`文件中复制全部内容。

### Q2: 应该选择哪个模型？
A2: 推荐`mimo-v2.5-pro`，支持工具调用和推理，适合剧情创作。

### Q3: 需要勾选哪些工具？
A3: 至少勾选Read、Edit、Execute，其他可选。

### Q4: Agent创建后在哪里找到？
A4: 创建后，Agent会出现在Agent列表中，可以通过`@叙事总监`调用。

### Q5: 如何测试Agent是否正常工作？
A5: 参考"配置验证"部分的测试用例。

## 四、进阶配置

### 1. 自定义系统提示词
如果需要调整系统提示词，可以编辑`AGENT_SYSTEM_PROMPT_SIMPLIFIED.txt`文件。

### 2. 添加更多工具
根据需要，可以添加更多工具，如：
- 文件搜索工具
- 代码分析工具
- 数据库工具

### 3. 配置工作目录
可以设置Agent的工作目录为项目根目录：`e:\godot\DetectiveSandbox\detective`

## 五、注意事项

1. **系统提示词长度**：确保系统提示词不超过模型最大输入限制
2. **工具权限**：谨慎授予Execute工具权限，避免误操作
3. **模型选择**：不同模型有不同的能力，根据任务需求选择
4. **测试充分**：创建后务必进行充分测试，确保Agent正常工作
