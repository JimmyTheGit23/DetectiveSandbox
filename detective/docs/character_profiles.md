# 序章「渡口沉舟」角色设定卡

---

## 1. 陆昭（主角 · 巡按御史）

### 基本定位
冷面青年官员。言语极简但每句都有分量。内心其实比外表活跃得多——有吐槽欲但忍着不说。

### 口头禅/语癖
- 正式场合："说。"、"继续。"、"这句话——再说一遍。"
- 审问收尾："好。记下了。"
- 内心OS（括号）："（……又来。）"、"（这人说了三遍'没有'。通常说一遍就够了。）"
- 冷幽默极少但致命："你说的这些，能在堂上再说一遍吗？——我给你准备好笔墨。"

### 情绪范围
| 标签 | 使用场景 |
|------|---------|
| cold | 默认审讯态度 |
| serious | 分析推理时 |
| quiet_fury | 发现恶行时（不爆发，但语气骤冷）|
| tired | 序章逃生后的疲惫 |
| dry_humor | 极罕见的内心吐槽 |

### 核心矛盾
刚上任的年轻御史，差点死在第一次赴任路上。需要证明自己不是"京城来的书呆子"。

### 动作习惯
- 审问时目光不移开
- 思考时无意识敲桌面
- 下结论前会停顿一拍（文本中用"……"表达）

---

## 2. 凌瑶（助手 · 金鳞镖局信使）

### 基本定位
碎嘴侠女。嘴比脑子快，但眼睛比嘴更快。说话像连珠炮，情绪全写在脸上。

### 口头禅/语癖
- 自称："本姑娘"（激动时）/ "我"（正经时）
- 感叹："嘶——"、"哈？！"、"得了吧！"
- 评价人："这人有鬼。"、"瞧他那样——"
- 催促："快快快！"、"等什么呢？"
- 吐槽："话本子都不敢这么写。"、"他上辈子是X？"（X 随语境变）
- 鼓励："行吧行吧，本姑娘信你。"

### 情绪范围
| 标签 | 使用场景 |
|------|---------|
| cheerful | 默认/闲聊 |
| anxious | 有进展但不确定 |
| determined | 抓住线索 |
| shocked | 重大发现 |
| worried | 对陆昭/案情担心 |
| smug | 验证了她的猜测 |

### 核心矛盾
第一次参与查案，兴奋和不安并存。想证明自己不只是个"跑腿送信的"。

### 动作习惯
- 激动时拍桌子/拍大腿
- 压低声音碎碎念（"（低声）"开头）
- 偷偷观察人时歪头眯眼
- 紧张时咬嘴唇/来回踱步
- 高兴时会拍陆昭肩膀（不分场合）

### 助手特殊功能
- **提示系统**：用吐槽形式给玩家方向（"嘶——他刚才那个眼神不对啊。那个证据……就是那个——"）
- **总结推进**：每阶段结束用"所以现在咱们知道了——"句式总结

## 3. 阿贵（主犯 · 死者仆从）

### 基本定位
十二年老仆。表面卑微忠诚，实际积怨已深。伪装"可怜人"是他的本能——但在被逼到绝路时会爆发出完全不同的气质。

### 口头禅/语癖
- 卑微态："小的……小的……"、"大人明鉴"、"小的不敢"
- 装悲："老爷对小的不薄……"（后期成为最大讽刺）
- 紧张时：结巴、重复句首（"那、那是——"、"不是！不……不是的……"）
- 爆发时：突然不再自称"小的"，改用"我"——"我跟了他十二年！十二年！"
- 关键谎话：每次撒谎前会先"吞口水"（动作描写暗示）

### 情绪范围
| 标签 | 使用场景 |
|------|---------|
| grief | 初始伪装（假哭） |
| nervous | 被追问时 |
| defensive | 狡辩中 |
| panic | 证据出现时 |
| shaken | 被揭穿后 |
| broken | 彻底崩溃认罪 |
| cold_flash | 罕见——差点说出"教他的人"时闪过的阴冷 |

### 核心矛盾
他不是天生的恶人。十二年的积怨和二两银的侮辱把他逼上了绝路。观众应该"理解他的恨，但不原谅他的选择"。

### 动作习惯
- 紧张时抠手指甲（对话中多次出现）
- 撒谎时不看人眼睛（"目光飘向别处"）
- 装悲时动作夸张（捶地、跪伏）
- 崩溃时相反——完全静止，声音反而平了
- 关键矛盾：提到"二两银子"时，伪装会瞬间碎裂

### 审讯阶段演变
1. **初始**：忠仆面具（"老爷的仇一定要报"）
2. **松动**：被追问细节时开始出错（结巴增多）
3. **修补**：编新谎来补旧谎（"那是因为……"）
4. **崩溃**：证据链闭合后彻底垮掉
5. **坦白**：反而冷静了——用"我"不用"小的"

---

## 4. 老范（共犯 · 船家）

### 基本定位
码头老油条。跑了二十年船，嘴皮子比浪花还滑。用"粗人"人设当挡箭牌——实际上精明得很。

### 口头禅/语癖
- 自称："老汉"
- 经典句式："嗐！大人这话说的……"、"这能怪老汉？"、"那不是嘛——"
- 俗语/谚语："船翻三次还怕水啊？"、"吃水的饭哪有不湿鞋的"
- 转移话题："说起来——"、"哎对了大人——"
- 抽烟动作贯穿：每次紧张就"磕烟灰"、"深吸一口"、"把烟杆别在腰上"

### 情绪范围
| 标签 | 使用场景 |
|------|---------|
| smirk | 默认老油条态 |
| dismissive | 不当回事 |
| defensive | 被质疑时 |
| nervous | 证据出现 |
| cornered | 无法自圆其说 |
| pleading | 最后求情 |

### 核心矛盾
赌债压身，被阿贵利用。他不是主谋但心甘情愿配合——因为那五十两货银是他唯一的出路。

### 动作习惯
- 靠在东西上说话（船舷、门框、墙）——表演"松弛"
- 紧张时烟抽得急/磕烟灰频率加快
- 被逼急了会站直身子（平时从不站直）
- 说谎时话变多、语速加快（与平时慢悠悠形成对比）

### 审讯特征
- 不会像阿贵那样崩溃，而是"硬扛到底"
- 翻供方式：把锅往阿贵身上推（"是他求小的！小的不过是……"）
- 最后的弱点：赌债字据——证明他有动机

## 5. 周氏（死者妻子）

### 基本定位
精明商人妻。悲痛是真的，但脑子从未停止运转。她对丈夫的感情复杂——爱过，也恨过他的刻薄。

### 口头禅/语癖
- 提丈夫："我家老爷他……"、"他那个人……"（语气复杂）
- 感叹："唉——"（几乎每段话都有叹气）
- 精明面："大人，我多嘴说一句——"、"您别怪我多想——"
- 悲痛时：话说到一半会停（"他本来答应我……算了。"）
- 关键判断力："我不信。"（简短有力）

### 情绪范围
| 标签 | 使用场景 |
|------|---------|
| grief | 悲痛（真实的） |
| suspicious | 怀疑某人 |
| bitter | 提到丈夫刻薄时 |
| determined | 要求查明真相 |
| resigned | 接受丈夫不是完人 |

### 核心矛盾
她知道丈夫待下人刻薄，但仍然要为他讨公道。复杂的"又爱又恨死去的人"情感。

### 动作习惯
- 说话时擦眼角（即使没在哭）
- 提到钱/生意时本能地攥紧手
- 判断人时眼神很锐利（与悲痛形成反差）
- 犹豫要不要说某句话时会"咬了咬嘴唇"

---

## 6. 钱里正（地方小吏）

### 基本定位
八面玲珑的基层官僚。不想惹事，不想得罪人，只想把事糊弄过去。用圆滑当盾牌。

### 口头禅/语癖
- 开场必用："哎呀大人——！"
- 和稀泥："不至于不至于"、"这话不好说"、"小人斗胆……"
- 两面讨好："要我说嘛……两边都有道理"
- 推卸："小人也是听说的"、"这个小人就不太清楚了"
- 拍马屁："大人英明！大人这一来，小人心里就踏实了！"

### 情绪范围
| 标签 | 使用场景 |
|------|---------|
| fawning | 讨好上官 |
| evasive | 不想回答 |
| gossip | 八卦时（信息最多的时候）|
| nervous | 被逼表态 |
| reluctant_honest | 不情愿但说了实话 |

### 核心矛盾
他其实知道很多（地方小吏消息灵通），但不想得罪任何一方。关键信息往往要"绕三圈"才能从他嘴里掏出来。

### 动作习惯
- 搓手（讨好时）
- 左顾右盼（怕被人听到）
- 压低声音说八卦
- 被追问时擦汗

### 设计用途
- 提供背景信息的"润滑剂"
- 他的八卦往往是通往关键线索的桥
- 喜剧担当之一

## 7. 王大爷（渔翁 · 关键证人）

### 基本定位
硬骨头老渔翁。话极少，但每句都是钉子。一辈子在江上讨生活，见过太多人世。对不公有天然的愤怒。

### 口头禅/语癖
- 否定："放屁。"（直接、不留情面）
- 肯定："老头子看得清清楚楚。"
- 总结："杀了人就该偿命。"
- 沉默比语言多："……"（常用省略号开头）
- 少有的长句用来回忆："那天夜里……"（语气变慢、变沉）
- 朴素哲理："活了一辈子，在这江上。见过太多死在水里的人。"

### 情绪范围
| 标签 | 使用场景 |
|------|---------|
| stoic | 默认 |
| angry | 提到不公时 |
| solemn | 回忆/证词 |
| contempt | 提到老范撒谎时 |
| gentle | 罕见——对周氏表达同情 |

### 核心矛盾
他本可以不管——一个老人没必要蹚浑水。但他选择站出来。"不怕得罪人"是这个角色的脊梁。

### 动作习惯
- 补渔网（对话全程在做——象征"手里有活但心里明白"）
- 抬头看人时动作缓慢（不着急）
- 说到愤怒处会"啪"地把渔网摔在地上
- 指方向时用烟杆/手里的梭子

### 设计用途
- 第二阶段的"破局者"——他的证词直接击碎老范的谎言
- 对比钱里正：一个什么都说但不可靠，一个话少但字字千金

## 8. 沈清月（真凶 · 药材商之女）

### 基本定位
双面角色：**表面是飒爽干练的女商人**，实际是冷静精密的策划者。她精心设计了整起谋杀案——利用阿贵的仇恨、老范的赌债，一手导演了凿船沉舟。

### 基本信息

| 项目 | 设定 |
|------|------|
| 年龄 | 二十二 |
| 身份 | 浔阳沈氏药材行独女，替病重的父亲跑账收债 |
| 外貌 | 身量高挑、穿男装劲服、长发高束如少年。五官精致冷艳——像一把好看的刀。|
| 第一印象 | 泼辣的女债主——嗓门大、气势足。所有人觉得她"太粗暴了不像凶手"。 |
| **真实面目** | 心思缜密、手段狠辣的幕后策划者。"粗暴"是演给别人看的保护色。 |

### 动机设计（三层递进）

```
表面动机 ： 周德茂欠沈家三十八两药材款 → 追债
  ↓
深层动机 ： 周德茂不仅赖账，还散布谣言毁掉沈家货源
             → 沈父急怒攻心病倒 → 药钱不够 → 她恨入骨
  ↓
真正目的 ： 杀人 + 夺财（五十两货银）
             她安排人在沉船后打捞货银
             三十八两旧债 + 五十两新财 = 八十八两
             足够救父 + 重建家业
```

### 完美犯罪计划

1. **制造公开矛盾**：故意当众骂周德茂，让所有人知道她有"动机"
   → 反向利用：太明显了，别人反而不怀疑她
2. **操纵阿贵**：她暗中接触阿贵，得知十二年积怨 → 煽动仇恨 → 教他凿船
   → 阿贵说的"有人教我"就是她
3. **利用老范**：通过赌坊的关系找到欠债的老范 → 许诺分账 → 让他配合
4. **设置替罪羊**：所有物证（浮囊、凿痕、遣散字据）指向阿贵
   → 她设计好让阿贵当背锅侠
5. **案发当夜在码头**：确认计划执行到位
6. **事后收割**：安排人次日黎明打捞沉入浅水区的货银箱

### 为什么初期不会被怀疑

- 所有物证指向阿贵（她安排的）
- 她有"完美反向逻辑"：周德茂死了她的三十八两就要不回来了
- 公开的"仇恨"太过明显 → 反而像个粗人不像凶手
- 她主动配合调查、态度坦荡 → "有什么不能问的？"
- 周氏、钱里正都不怀疑她（觉得她只是吵架）

### 暴露线索链

```
① 阿贵对峙失口说"有人教我" → 不是老范（老范不懂策划）
② 老范的赌坊 → 追问中间人 → 有个"药材行的姑娘"找过他
③ 凌瑶的码头目击 → 沈清月声称的时间与实际矛盾
④ 王大爷清晨目击 → 沉船下游有人打捞东西
⑤ "三十八两" → 如果货银被捞回，她不亏反赚五十两
```

### 口头禅/语癖

#### 表演模式（飒爽女商人）
- 自称："我"（从不用谦称）
- 开场："问吧。我怕什么？"
- 反问："我杀他对我有什么好处？——他活着我才能要到钱。"
- 佯怒："三十八两！三十八两啊大人！白纸黑字的借据！现在人死了钱也没了——你说我亏不亏？！"
- 自嘲："我要是想杀人——我会当着二十个人放话？大人，我虎，但没虎到那份上。"

#### 真实模式（被揭穿后）
- 语速变慢："……你比我想象的聪明。"
- 不再装粗："（沉默很久）好。那我换个方式跟你说话。"
- 冷静反击："你有证据——还是只有推测？这两个字之间，隔着一条人命。"
- 最后一道防线："就算货银被人捞了——你能证明是我捞的？你能证明那个人跟我有关系？"
- 提到父亲时失控："我爹躺在床上等死！五十两的药——他吞了，他不还！他不配活着！"
- 认罪最终台词："我没杀他。我只是让他死在他该死的地方。——你说这叫什么？"

#### 关键台词设计（对峙高潮时刻）
- "你知道一个人欠另一个人的命，是什么感觉吗？不是三十八两。是我爹的命。"
- "阿贵恨他十二年。老范被逼到绝路。我——我只是给了他们一个机会。"
- "周德茂这辈子欠了多少人？我只是那个——不愿意忍了的人。"

### 情绪范围

| 标签 | 使用场景 | 说明 |
|------|---------|------|
| bold | 初见时的飒（表演） | 大嗓门、不怕事、像个粗人 |
| cooperative | 配合调查时（伪装） | 主动提供信息（都是无害的） |
| deflecting | 话题靠近真相时 | 巧妙转移话题，不露痕迹 |
| sharp | 被质疑时反击 | 不怒反笑，反问"你有证据？" |
| cracking | 证据链开始合拢 | 语速微变、眼神控制出现裂隙 |
| cold_fury | 伪装完全撕裂后 | 真面目——极冷、极静、极危险 |
| broken | 提到父亲时唯一的软处 | 声音颤抖，几乎失控 |

### 核心矛盾
她不是无缘无故的恶人。周德茂确实害了她家。但她选择了谋杀+利用无辜者（阿贵）作为棋子，这是她的罪。观众应该"理解她的恨，但无法原谅她把别人当棋子"。

### 动作习惯
- **表演态**：抱臂靠墙、单手叉腰、目光直视（表演"无所畏惧"）
- **真实态**：双手交叉放在身前（防御姿态）、说话前会微微侧头（在计算该说什么）
- **被揭穿时**：先是一动不动（像被冰冻了）→ 然后慢慢笑了 → 笑完才开口
- **提到父亲时**：唯一一次无法控制表情——嘴唇咬到发白、眼眶发红但不让泪落下
- **认罪后**：整个人松了下来——"像绷了太久的弦终于断了"

### 审讯阶段演变

1. **调查A期（旁观者）**：飒爽债主 → 主动配合 → "我亏大了好吗"
2. **调查B期（被追查）**：开始闪避细节 → 用反问压制 → "你有证据？"
3. **对峙开始**：维持冷静 → 用逻辑反驳 → "我没有理由"
4. **第一道防线破**：微微失色 → 但迅速切换新防御
5. **第二道防线破**：沉默变长 → 语气变冷 → 不再"表演"
6. **最终击破**：完全静止 → 长久沉默 → 认罪
7. **爆发/动机揭露**：压抑的情感洪流 → 提到父亲 → 几乎崩溃但咬牙撑住

## 对白密度参考

逆转裁判对白节奏：
- 重要对话：4-8句一组，中间插入助手评论
- 闲聊：2-4句，快节奏
- 对峙：每句证词配3-5句press反应 + 2-3句助手OS
- 转场：5-10句（总结+推进）
- 关键揭露：10-15句连续演出（不可跳过感）
