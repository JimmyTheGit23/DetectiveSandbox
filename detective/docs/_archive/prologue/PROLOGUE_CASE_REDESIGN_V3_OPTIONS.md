## 🥢 方案 A：「客栈夜雨杀」 ⭐⭐⭐⭐⭐ 最推荐

### 一句话剧情
**陆昭住进荆江客栈避雨，半夜隔壁房间传来惨叫。冲过去时发现客栈老板娘倒在血泊里，店小二指着陆昭说"是他杀的"——而陆昭手里正巧握着凶器（他刚从地上捡起来）。**

### 案发时间线
- 戌时三刻：陆昭入住"荆江·安福客栈"，老板娘热情接待。
- 子时：陆昭在房中休息，听到隔壁老板娘房间有争吵声。
- 子时一刻：惨叫一声。陆昭冲过去看，门虚掩着，地上是老板娘的尸体，旁边一根**血迹斑斑的擀面杖**。陆昭出于本能弯腰捡起来——**就在这时**店小二带着围观的客人冲进来。
- 寅时：里正赶到，店小二指认"陆昭手握凶器站在尸体旁"。

### 案情核心（一眼能懂）

| 要素 | 内容 |
| --- | --- |
| 死者 | 安福客栈老板娘 王氏 |
| 死因 | 后脑被钝器击中，当场死亡 |
| 凶器 | 厨房里的擀面杖（沾血） |
| 被诬陷者 | 陆昭（捡起凶器时被撞见） |
| 真凶 | **店小二·阿福** |
| 真凶动机 | **想偷老板娘私房钱**（藏在床底木匣里） |
| 真凶背后 | **沈清月**（雇佣阿福杀王氏，灭口"漕账纸条"） |

### 诡计（普通玩家 30 秒能听懂）

凶手阿福的杀人逻辑：
1. 子时偷偷去老板娘房间，想偷木匣里的银子
2. 老板娘惊醒，认出阿福，破口大骂
3. 阿福慌乱中抓起擀面杖打死老板娘
4. 听到隔壁陆昭起身，灵机一动——**故意制造响声**让陆昭过来"撞见现场"
5. 阿福藏在门后，等陆昭弯腰捡擀面杖时立刻冲进来喊"杀人啦"

### 决定性逆转点（一眼可见的物证）

#### 第一层：鞋底
- 阿福指控："陆公子手握凶器站在血泊旁，必是他杀的！"
- 陆昭反击：「请里正大人看我们俩的鞋底！」
- **陆昭的鞋底干净** → 没踩过血
- **阿福的鞋底有血印** → 他比陆昭更早进过现场

#### 第二层：木匣的痕迹
- 阿福改口："是我冲进去抢救老板娘，所以鞋底有血！"
- 陆昭反击：「老板娘床底的木匣，**钥匙孔有新划痕**——是被人撬过的。」
- **阿福的指甲缝里有铜屑**（撬锁时蹭到的）

#### 第三层（沈清月介入）
- 沈清月："阿福只是想偷钱，杀人是临时起意。最多过失致死。陆御史，案子已经查清了。"
- 陆昭抓住一点：阿福口袋里有**一锭刻有"沈"字的银子**——比偷来的私房钱多得多
- 沈清月："沈氏开钱庄的，全城三成银子都过我家手。一锭银子定不了我的罪。"
- 陆昭最后一击：老板娘临死前**手心攥着一张纸条**——上面写着"漕账·腊月廿三·西仓"。**这纸条上的笔迹与沈清月的扇面笔迹相同**。
- 沈清月（脸色第一次变）："......陆御史。您只能证明我和老板娘有过往来，证明不了我教唆杀人。**法律不判可能。**" → **撑伞离去**

### 角色重新分配

| 角色 | 新身份 | 戏份功能 |
| --- | --- | --- |
| 陆昭 | 奉旨南下查漕运的御史，途中借宿被卷入命案 | 主角 |
| 凌瑶 | 金鳞镖局女镖师，住在客栈对面铺子，惨叫吵醒后赶来 | 助手 |
| 沈清月 | 本地县丞之女兼讼师，第一时间到场"协助查案"，实则灭口纸条 | 宿敌 |
| 阿福（店小二） | 真凶，被沈清月雇佣 | 第一场对峙证人 |
| 王氏 | 客栈老板娘，发现纸条意义后被灭口 | 死者 |
| 王老板 | 客栈老板，外出进货不在现场 | 配角证人 |
| 钱里正 | 来主持公道的本地小吏 | 法官 |
| 孙秀才 | 隔壁住客，赶考书生，听到争吵但听不清内容 | 第二场对峙证人 |

### 为什么这个方案最好

1. **场景日常**：客栈住宿，每个人都见过
2. **凶器具象**：擀面杖，玩家能"看见"
3. **动机浅显**：偷钱杀人，最普世
4. **诡计三层递进**：鞋底→木匣→纸条，一层比一层深，但每层都靠物证
5. **沈清月的"灭口角色"很经典**：她不亲手杀人，但是真正的黑手——这是逆转裁判 Case 4 风格
6. **大主线钩子完美**：纸条上的"漕账·腊月廿三·西仓"为后续埋下种子，不要求玩家序章就懂
7. **三层逆转都用日常逻辑**：鞋底干净 / 指甲铜屑 / 笔迹比对——全是侦探剧常见手法

### 风险
- 擀面杖打死人有点直白，但 Case 1 雕像砸头也是这个套路，没问题
- 纸条作为大主线钩子玩家可能"跳过"——所以**老板娘临死前的特写镜头**要做得醒目

## 🍲 方案 B：「腊八粥馆」 ⭐⭐⭐⭐ 备选

### 一句话剧情
**腊八节，荆江"福满堂"粥馆排长队送腊八粥。粥馆老板周福满喝下自家招牌粥后当场暴毙。陆昭路过被卷入，老板的小妾哭着指认是大房（正妻）下毒——而正妻看上去贤淑无辜。**

### 案情核心

| 要素 | 内容 |
| --- | --- |
| 死者 | 福满堂老板 周福满 |
| 死因 | 中毒身亡 |
| 凶器 | **一只鎏金小勺**（老板专用，没人碰） |
| 嫌疑人 1 | 大房·李氏（小妾指控） |
| 嫌疑人 2 | 陆昭（路人，被卷入） |
| 真凶 | **小妾·柳娘** |
| 真凶动机 | **怀了别人的孩子，怕老板发现** |
| 真凶背后 | **沈清月**给柳娘提供毒粉，目的销毁老板与漕运商的账本 |

### 诡计（核心：勺柄下毒）

- 当天清晨，柳娘借口"擦勺子"，把毒粉抹在**鎏金小勺的勺柄上**
- 老板握勺时手心吸收毒素（接触性毒物）
- 喝粥时毒下肚发作
- **粥本身没毒**——这是诡计的关键
- 任何人喝那锅粥都没事，**只有用那把勺子的老板会死**

### 决定性逆转点

#### 第一层：让小妾自己喝粥
- 小妾："是大房在粥里下了毒！"
- 陆昭："请柳娘喝一口这粥。"
- 柳娘不敢喝（她以为粥里也有毒）
- 但喝下去什么事也没有——**证明粥里无毒**
- 那毒在哪里？

#### 第二层：勺子上的痕迹
- 陆昭检查老板的右手——**手心有一片黑斑**
- 鎏金勺柄上能擦出微量毒粉
- **谁每天负责擦这把勺子？柳娘。**

#### 第三层（沈清月介入）
- 沈清月："柳娘只是想自由，毒是她自己配的。陆御史，案子结了。"
- 陆昭：「毒粉的成分是**朱砂+铅丹**——这是名贵药材，柳娘一个内宅女子从哪儿弄到？」
- 沈清月："荆江每家药材行都卖。"
- 陆昭最后一击：毒粉的**包装纸**——是沈氏药材行特有的"双桐叶"印记纸
- 沈清月："纸是我家的，毒不一定是。**法律不判可能。**" → 撑伞离去

### 难度评估
比方案 A 略难。"勺柄下毒"虽然不复杂，但玩家需要理解"接触性毒物"。整体仍在生活常识范围内——古装家庭剧常见桥段。

### 大主线钩子
老板生前**正在和"沈氏药材行"谈一笔大宗药材生意**——账本上写着"漕仓·腊月廿三·西仓"。沈清月以"账本继承人"的身份出现，**实则是来收尸灭据的**。

## 🎭 方案 C：「戏班杀人案」 ⭐⭐⭐ 戏剧性最强但稍复杂（概要）

### 一句话剧情
**陆昭路过荆江戏班正在演《白蛇传》。台上"白娘子"演员一刀刺向"许仙"——这一刀竟然是真的，许仙演员当场毙命。**

### 核心要素
- **凶器**：道具刀被调换成真刀
- **真凶**：戏班班主齐三爷（贪污公款被许仙演员发现）
- **诡计**：班主借口"磨刀"，把道具刀换成真刀，让白娘子在不知情下杀死许仙
- **决定性逆转**：刀柄上的金漆指纹——白娘子只摸刀身（演戏握的位置），班主摸过刀柄（换刀时蹭到）
- **沈清月**：戏班的金主，要灭口的是许仙手里的漕账抄本

### 优点
- 舞台杀人，戏剧张力最强
- "百老汇杀人"模板，玩家代入感新鲜

### 缺点
- "调换道具刀"需要玩家想象舞台后台的运作
- 比方案 A 复杂一档
- 戏班场景制作成本（美术资源）较高

## 五、最终推荐

### 推荐方案 A「客栈夜雨杀」

**理由**：
1. **零认知门槛**：客栈、擀面杖、店小二、偷钱杀人——这是**侦探小说最朴素的入门款**
2. **三层物证完美递进**：鞋底→木匣→纸条，每层都是看得见摸得着的实体
3. **沈清月作为"幕后教唆"很高级**：玩家序章就能感受到她的可怕，但又抓不到她的实证
4. **美术成本最低**：客栈一间房 + 大堂 + 对面铺子（凌瑶住处），可复用现有素材
5. **大主线钩子"纸条"最自然**：临死前攥纸条是侦探剧经典桥段，玩家本能会注意

### 备用方案 B「腊八粥馆」
如果觉得 A 太普通，B 的"自饮验毒"戏剧性更强。但**勺柄下毒**对玩家化学知识有一点点要求。

### 不推荐 C
戏班美术成本高，且"道具刀调换"需要解释舞台后台运作，新手案不适合。
