# 凌瑶台词改写规则

## 核心问题

当前凌瑶是**攻略提示框**，不是活人。对比真宵（逆转裁判）：

| | 真宵 | 当前凌瑶 |
|--|------|---------|
| 说什么 | 她感受到/观察到的 | 玩家下一步该做什么 |
| 失败时 | 担心、沉默 | "先去看X""换个证据" |
| 提示方式 | 扔纸条（行动） | 直接说答案路径 |

## 四条改写规则

**规则1：只说她感知到的具体事物**
她是镖师，她的专长是观察人——表情、手、声音、呼吸。
每句话必须有具体载体，不能是抽象分析。
```
✅ 他手指戳得那么直。
✅ 她停了。
❌ 别跟他争水性，先看船底。（攻略指令）
```

**规则2：失败时她给感受，不给方向**
玩家用错证据，凌瑶不说"该去看哪里"，而是说她感受到的：
```
✅ 她没动。这个没扎到她。
✅ 你刚才那句——他眼神没变。
❌ 那个证据压不住，换一个。
```

**规则3：readthrough_end_hint 全部删除**
这是游戏系统提示，不是凌瑶该说的话。
全删，或改成通读中她观察到的一个细节（不指向答案）。

**规则4：她有时候不知道答案**
真宵也会给错建议，凌瑶可以困惑、沉默、说"我不知道"。
全知角色不真实。
