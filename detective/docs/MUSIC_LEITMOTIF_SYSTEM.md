# 音乐主题动机（Leitmotif）系统设计

> 参考：《大逆转裁判》音乐设计哲学 — 围绕核心旋律动机，通过变奏而非换曲实现情绪递进。

---

## 一、核心旋律动机（陆昭 / 游戏主题）

### 动机定义

**5音下行动机** — 代表"探寻真相"的宿命感：

```
A4 - G4 - E4 - D4 - C4  (la - sol - mi - re - do)
```

**性格**：小调色彩、下行走向暗示沉郁与执念，但末尾落在do上给予一丝解决感。

**节奏型**：附点四分 + 八分 + 四分 + 四分 + 二分（ ♩. ♪ ♩ ♩ 𝅗𝅥 ）

### 各场景变奏规则

| 场景类型 | 演奏乐器 | 速度 | 处理方式 |
|----------|----------|------|----------|
| 主题曲/标题 | 古琴独奏 | BPM 60 | 原调原速，庄重呈示 |
| 船舱探索 | 古琴低八度 + 洞箫伴奏 | BPM 52 | 减速、加混响，疑云感 |
| 客栈调查 | 古筝分解拨弦 | BPM 66 | 动机拆散为分解和弦 |
| 码头调查 | 竹笛远空 | BPM 60 | 动机仅前3音，悬而不决 |
| 对峙/Press | 二胡急奏 + 太鼓 | BPM 90 | 动机加速2倍，循环重复 |
| 击破/高潮 | 全奏（二胡+古琴+太鼓+笛） | BPM 100 | 动机升调半音（Bb调），力度fff |
| 败局 | 二胡独奏 | BPM 48 | 动机倒行（C-D-E-G-A），哀鸣 |
| 好结局 | 古琴 + 暖弦乐 | BPM 66 | 动机转大调（A-B-C#-E-F#） |
| 坏结局 | 二胡泛音 | BPM 50 | 仅动机前2音反复，渐弱 |

## 二、沈清月角色动机

### 动机定义

**4音上行不协和动机** — 代表"算计、危险、冷冽的优雅"：

```
E4 - F4 - A4 - Bb4  (mi - fa - la - 降si)
```

**性格**：增四度（E→Bb=tritone跨度）制造不安；上行暗示野心与步步逼近。

**节奏型**：十六分 + 十六分 + 八分 + 延长二分（♬ ♪ 𝅗𝅥~ ）

### 使用规则

| 场景 | 处理方式 |
|------|----------|
| 沈清月出场/走廊 | 琵琶冷冽弹奏，solo呈示 |
| 沈清月对话中 | 动机以古琴泛音在背景极弱浮现 |
| 对峙中沈清月发言 | 动机与主题动机交织（二胡奏主题 + 琵琶奏沈动机） |
| 翻盘（击破沈清月） | 主题动机压过沈动机，沈动机降速消解 |
| 败局（沈清月得逞） | 沈动机变为主导，主题动机碎片化 |

## 三、统一调性系统

### 中心调性：**A小调 (Am)**

选择理由：
- 古琴常用定弦 C-D-E-G-A 天然契合
- 二胡内外弦 D-A 天然共鸣
- 洞箫/笛子常用筒音 = A
- 小调色彩契合悬疑推理氛围

### 调性族谱

```
Am (i)  ── 主调：调查、探索、日常
 │
 ├── Dm (iv) ── 哀伤：败局、坏结局
 │
 ├── Em (v)  ── 紧张：对峙开始
 │
 ├── A大调 ── 解决：好结局、真相大白
 │
 └── Bbm (bii) ── 异质：沈清月主题（半音关系制造不安）
```

### 跨案件调性规划

| 案件 | 主调 | 说明 |
|------|------|------|
| 序章·渡口沉舟 | Am | 建立主调 |
| 浔阳楼案 | Dm | 四度关系，更悲情 |
| 临川驿案 | Em | 五度关系，更紧张 |
| 金陵大清洗 | Am→A大调 | 回归主调，终章解决 |

## 四、BPM 族谱

### 核心 BPM：**60**（主题曲）

所有曲目 BPM 为 60 的整数比关系：

```
48  = 60 × 0.8  ── 极慢：败局、守夜
52  = 60 × 0.87 ── 慢：船舱夜航（接近但略偏，可接受）
60  = 60 × 1.0  ── 基准：主题曲、调查
66  = 60 × 1.1  ── 稍快：客栈日常（微提速）
72  = 60 × 1.2  ── 中速：社交场景
80  = 60 × 1.33 ── 快：Press / 追问
90  = 60 × 1.5  ── 对峙高潮（3:2比）
120 = 60 × 2.0  ── 极快：逃生/击破（2:1整倍）
```

### 同案件内 BPM 递进设计（序章）

```
船舱夜航(52) → 获救(48) → 客栈调查(66) → 码头调查(60)
→ 开庭(60) → 对峙(90) → 击破(120) → 败局(48) / 好结局(66)
```

## 五、Lyria Prompt 植入策略

由于 Lyria 不支持 MIDI 输入，我们通过以下方式在文字prompt中植入动机：

### 核心动机植入模板

```
"IMPORTANT: Include a recurring 5-note descending motif (A-G-E-D-C in A minor) 
played by [主奏乐器], this motif should appear at least twice during the piece, 
it represents the main theme of the game"
```

### 沈清月动机植入模板

```
"IMPORTANT: Include a dissonant 4-note ascending motif (E-F-A-Bb) played by 
[琵琶/古琴泛音], suggesting danger and calculation"
```

### 对峙曲双动机交织模板

```
"Weave two motifs together: (1) a 5-note descending phrase A-G-E-D-C in erhu 
representing the protagonist, and (2) a dissonant 4-note ascending phrase E-F-A-Bb 
in pipa representing the antagonist. The two motifs should alternate and build tension"
```

## 六、已有曲目处理策略

对于已生成的曲目，有两个路径：

1. **重新生成（推荐）**：使用新prompt批量重新生成所有曲目
2. **后期叠加**：保留现有底层，手动叠入主题动机录音

当前选择：**方案1 — 全部重新生成**

重新生成顺序：
1. `main_theme` — 先确立核心旋律，作为其他曲目的听觉锚点
2. 序章系列 — 依场景顺序生成，确保递进感
3. 浔阳楼系列
4. 通用曲目（调查、对峙等）
