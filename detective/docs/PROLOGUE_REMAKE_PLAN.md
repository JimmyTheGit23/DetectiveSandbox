## 〇、为什么要重制 —— 四个核心病灶

经对真实 CSV（`data/case_tables/prologue_ferry/`）和逆裁第一案文本的逐行分析，确认现版序章四大问题：

1. **核心诡计太难懂**：双层延时毒囊 + 油脂锁毒 + 毒素时效性法理，叠了 5 个专业概念，是"药剂师+讼师双学位考试"，不是侦探推理。
2. **法庭缺逆转感**：12 组证词全是"一击一崩"的线性击穿；真正的"击破→更大逆境→反杀"只有终局一次。
3. **台词机翻味重 + 主角/助手无个性**：陆昭全程 determined 一个调；凌瑶是复读机解说员；老范靠标点"嘛"假装方言；句子节奏雷同。
4. **玩法单一 + 无独有玩法**：只有 press/present 两种交互，缺"威慑追加、指认图片、被迫指认人物/回答"，更没有本作核心独有玩法。

> 用户额外约束：① 诡计不用毒；② 沈清月序章不直接成为嫌疑人；③ 最重视台词自然度；④ 体量需支撑约 2 小时（含/不含搜索）。

## 一、新案件骨架（结构层）

### 1.1 角色定位重构

| 角色 | 新定位 |
|---|---|
| 陆昭 | 主角（失忆身份的隐秘御史），被指控 → 自证 → 查案。需要有**脆弱、被逼、赌一把**的人味，不再全程冷静正确。 |
| 凌瑶 | 搭档（金鳞镖局首席镖师）。**镖师之眼读人**，护着陆昭、有江湖气，不做逻辑复读机。 |
| **沈清月** | **以讼师/辩护人身份坐堂当陆昭的对手**（类比逆裁御剑）。全程在场、每轮反压，**但不被任何人怀疑**。她不上被告席、不被指认。 |
| 阿贵 + 老范 | **序章实际伏法者**（骗保凿船致死，认罪收押）。案件能定罪、玩家有破案满足感。 |

### 1.2 沈清月的"灯下黑"

- 沈清月不是躲在幕后，而是**大大方方坐在辩护席，玩家全程与她交锋却不知她就是真凶**。
- 她每次"反压"表面是维护律法/替当事人辩护，实则在悄悄把线索引开、保护自己。
- **序章结局**：定了阿贵老范的罪（赢），沈清月作为讼师全身而退（玩家不知她是凶手）。
- **真正的反转放在结案后**：陆昭独自复盘，惊觉"那个讼师把每一条线索都引开的方向，恰恰都在保护一个没人提过的人——她自己"。→ 接尾声「第一步棋，落下了」→ 主线漕运黑网。

### 1.3 三幕推进结构

```
【第一幕·被指控】 王大爷伪证 → 沈清月（讼师）首次反压登场
   └ 自证清白 + 把矛头从"陆昭"转向"船本身有问题"
【第二幕·船的真相】 老范（凿船骗保）→ 拉锯式逆转
   └ 凿船 → 会水为何死 → 有浮囊为何沉 → 浮囊为何独独他坏
【第三幕·谁布的局】 阿贵（执行者）→ 拉锯式逆转
   └ 买浮囊 → 怨恨动机 → 崩溃供出"一个药材行的姑娘"（无名/无脸/无物证）
【尾声·灯下黑】 结案后陆昭独自复盘 → 幕后黑手浮现 → 接主线
```

## 二、新核心诡计：「移花接木」（多层咬合，纯物理，不用毒）

> 原则：好诡计 = 一句话能复述 + 凶手必须做动作 + 留下看得见的实体证据；但要**多齿轮咬合**才配得上"幕后高手"。

沈清月不做"一个动作"，而是把阿贵老范的**骗保局**改造成**他们自己都看不穿的杀人装置**，靠三件互相咬合的事：

1. **调座次**：借"风水/行李重量"为由，让周德茂住进**最里侧、舱门朝内开**的舱（逃生最慢）。
2. **换浮囊**：把周的牛皮浮囊换成**接缝虚粘、入水即瘪**的次品。
3. **改时辰/航线**：买通老范**务必走东汊、在过石矶嘴（水流最急、离岸最远）时凿船**。

三者叠加 = 周德茂必死（最里舱+瘪囊+离岸远），而阿贵老范（外舱+好囊+近岸）必活。**连从犯都以为周是"运气不好/水性不行"**。

### 逆转层次（诡计天然分层）

- 破"凿船"（这是骗保）→ 破"会水为何淹死"（座次+时辰）→ 破"有浮囊为何沉"（调包）→ 发现**这三件是同一只手安排的**（指向没露面的人）。
- "**谁能同时做这三件事**"自动锁定凶手画像：能调座次（追债登船）+ 能换浮囊（接触采购）+ 能定时辰（买通老范）= 三线交汇于"一个药材行的姑娘"。

### 证据清单（5~8 件核心，精而非多）

> 校准自逆裁第一案：一场 1 小时庭审核心证据仅 5 件，体量靠"反复拉锯"而非堆证据。

| 证据 | 第一次出现（自然获得） | 法庭激活时机 |
|---|---|---|
| 船底人工凿痕 | 勘验沉船残骸 | 破"暗礁意外" |
| 死者会水（证言/旧识） | 问周氏/码头 | 破"凿船=死" |
| 瘪掉的牛皮浮囊（接缝虚粘） | 下游芦苇/残骸搜到周的遗物 | 破"有浮囊为何沉"（决定性） |
| 舱位安排（座次记录/船家口供） | press 老范 / 周氏回忆 | 破"为何在最里舱" |
| 东汊航线异常 + 老范赌债 | 赌坊/借据 | 证老范被买通定时辰 |
| 阿贵购囊记录（买两只、问绑法） | 杂货铺 | 破阿贵"怕水"伪供 |
| 遣散二两字据 | 阿贵处 | 阿贵怨恨动机 |
| （指向沈的"姑娘"线索，无物证） | 阿贵老范口供 | 推出第三人，但写不出名字 → 法律输 |

> 证据获得遵循逆裁三法则：①调查时"看见但不懂"，法庭才激活；②press 逼出新证物/搜查点；③反转瞬间由证人之口当庭诞生新线索。**杜绝凭空 gain。**

## 三、法庭玩法重制

### 3.1 拉锯式逆转节拍（每个矛盾点 3~5 拍）

```
拍1【陆昭进攻】 出证据戳穿一个谎 → 小胜
拍2【沈清月反压】 用法理/常理把证据打回（"凿船≠杀人""旧囊漏气常事""带浮囊=想活"）
              → 钱里正甚至偏向对方 →【更大逆境】
拍3【陆昭再起】 发现证据"第二层含义" 或 缀连新证据 → 反杀
（可重复 4~5 拍，同一件证据意义变形）
```

**体量来源**（校准结论）：不是更多证据，而是**把少数证据榨干** + 沈清月持续反压 + **陆昭大量内心挣扎**（"可恶……只剩这一样了""糟了，被她绕进去了"）。

### 3.2 玩法分档

**A 档·现有引擎已支持（改数据即可用足）**
- 威慑（press，安全无惩罚）、举证（present，选错扣信心）、信心值、击破。
- `forced_proof`（被迫出示指定证据自证）——王大爷场已用，要每场都用。
- press_add_trigger（press 出某句才解锁后续矛盾句）——已支持，要铺开。
- 引擎已具备：`_opponent_rect`（对手立绘）、`_shake_tween`、立绘三态、镜头切换。

**B 档·小改引擎可加（用户点名）**
- **威慑追加**：press 安全证词 → 沈反压 → 解锁该证词隐藏后半句（新矛盾）。
- **被迫指认人物**：扩展 forced_proof → `forced_select_person`，从角色列表选人，选错扣信心/触发危机。
- **被迫回答关键问题**：`forced_choice` 选择题式逼问，答错失去翻盘机会。

**C 档·本作独有核心玩法（序章冒头，后续深化）—— 待用户最终拍板**
- **候选① 证据缀连（Evidence Weaving）⭐ 推荐**：单件证据无法定罪（对应"推理赢、法律输"主题），关键时刻须把 2~3 件证据**缀连成链**呈堂才能击破沈清月"单件无效"反压。玩法即主题，序章教"缀连两件"，后续缀连更多。
- **候选② 读人（凌瑶镖师之眼）**：进入观察模式，在角色立绘上**点出微表情/小动作**逼出隐藏证词。对应逆裁"灵魂之眼"，且实现"指出图片中的问题"，让凌瑶有不可替代的玩法功能。

> 待定：① / ② / 两个都要（缀连为主、读人为辅）。

## 四、台词改造（最高优先级）

### 4.1 去机翻味四原则
1. 删除所有**括号动作/表情描写**（动作交给美术 + emotion 字段驱动）。内心独白（inner_thought）可叙事，但不替他人做动作描写。
2. 打破"等长短句+句号断行"的 AI 节奏，长短句交错、有半截话与打断。
3. 主角要有情绪起伏（nervous/shaken/desperate），不只 determined。
4. 凌瑶从"逻辑复读机"变"镖师读人 + 有温度的搭档"。

### 4.2 角色句法指纹

| 角色 | 句法指纹 |
|---|---|
| 陆昭 | 只追问不下结论；急了压低声音重复对方的话；内心戏多（慌、赌、被噎） |
| 凌瑶 | 江湖比喻 + 护着陆昭 + 偶尔损一句；认真时"我信你"；读身体不读证据链 |
| 沈清月 | 越冷静话越短；永远在算账；反压用"法理/没人证"；cold_fury 仅极限处 |
| 阿贵 | 短、慌、自称"小的"，崩溃时蹦出"我"（去敬称=真情绪外露） |
| 老范 | 老江湖躲闪，用"船话"打太极；方言落在用词句式，不靠尾缀堆砌 |
| 钱里正 | 和稀泥，半句官腔半句乡音，永远先顾自己 |
| 周氏 | 欲言又止，悲痛克制 |

## 五、立绘动态化（独立技术专题）

### 5.1 现状与问题
- 现状：每个角色每种情绪 = 一张完整 PNG，切换靠换整图（沈清月已 12 张）。
- 问题：静态、死板；但"整图序列帧"会美术爆炸。

### 5.2 方案：逆裁式分层（身体大图 + 眼/嘴小贴图 + 程序动画）
- **第1层 身体/姿势**：1 张静止大图（=现有情绪图，最贵，不做逐帧）。
- **第2层 眨眼**：眼部位置盖 2~3 帧小贴图，每 3~5 秒随机播一次。
- **第3层 口型**：嘴部位置盖 2~3 帧小贴图，监听打字机状态循环开合，停字=闭嘴。
- **情绪切换**：仍换 base 大图（保留现状）。
- **冲击动作**（拍桌/后仰/objection）：用程序动画（位移/缩放/抖动/闪白）作用于整图，**不需新美术**。`ConfrontationPanel` 已有 `_shake_tween`/镜头/三态可复用。

### 5.3 实现要点
- 新建 `AnimatedPortrait` 组件：base TextureRect + 眼/嘴子节点，自驱眨眼与口型（口型监听 `_typewriter_playing`）。
- 眼/嘴贴图在同角色多情绪间**大量复用**，非"情绪数×2"，实际增量小。
- `portrait_expressions.csv` 扩两列 `eyes_sheet`/`mouth_sheet`，**留空则退化为静态图（向后兼容、可逐角色渐进升级）**。
- 进阶（后续可选，序章不做）：Live2D / Spine / Skeleton2D 顶点形变，留给高规格角色。
