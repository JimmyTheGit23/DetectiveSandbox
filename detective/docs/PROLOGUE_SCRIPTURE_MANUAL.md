# 序章「渡口沉舟」创作手册

> 供外部作者改写或重构序章文案使用。最后更新：2026-06-15

---

## 一、人物卡

### 陆昭（男主·玩家角色）
- **身份**：24岁，京城特派隐秘御史，奉旨暗查漕运账弊。公开身份"外乡书生"
- **性格**：热血理想主义者，表面克制内里温热。对公正有执念——"不能让好人白死"
- **口头禅/语癖**：思考时自言自语复述线索；被激怒时音量压低——"你再说一次。"
- **台词风格**：只追问，不下结论。每句只做一件事。策略放内心独白，不在口头讲课
- **禁忌**：不替观众做总结；不说"证据链""逻辑不通"；不用"也许"开头（除非刻意犹豫）

### 凌瑶（女主·同伴）
- **身份**：金鳞镖局首席镖师，二十出头，押送急件路过渡口时救起陆昭
- **性格**：大侠风范+温柔可爱。能打果断，本质温柔爱笑。第一次参与查案
- **口头禅/语癖**：鼓励时"行。我信你。"；认真时语速变慢眼神定住
- **台词风格**：用镖师阅历读人（身体细节、微表情），不做逻辑帮腔、不做复读机
- **禁忌**：绝对不能碎嘴、不抢话、不连续抛梗；不拆证据链、不分析法律漏洞、不下战术判断

### 沈清月（真凶）
- **身份**：22岁，金陵沈家之女，世代经营药材与律讼。暗中为漕运权贵集团灭口
- **性格**：双面人——表面飒爽干练女商人（大嗓门、气势足），真实面冷静精密到冰冷
- **口头禅/语癖**：表演模式自称"我"、嗓门大、反问制造无害感；真实模式语速慢、声音冷
- **台词风格**：负责拆解陆昭的话，不讲述自己的犯罪过程。越接近真相，话越短越稳
- **禁忌**：表演模式下不能提前暴露真实模式的冷；不能从嘴里说出作案路径；`cold_fury`仅终局使用

### 王大爷（关键证人）
- **身份**：六十多岁老渔翁，被沈清月以银钱收买提供虚假目击证词
- **性格**：本质不是恶人，被穷困所困一时糊涂。沉默比话多
- **口头禅/语癖**：像钉子——短、硬；否定时"放屁。"；沉默时"……"最常用
- **台词风格**：全剧台词最少。evasive时像钉子，guilty时加省略号表示支离破碎
- **禁忌**：话不能太多；guilty阶段台词要支离破碎不能太流畅；认罪句前必须有沉默

### 老范（从犯·船家）
- **身份**：50多岁石矶渡船家，跑了二十年船，被42两赌债压身
- **性格**：用"粗人"人设当挡箭牌，实际上精明得很。话多、爱用谚语
- **口头禅/语癖**："嗐！大人这话说的……""这能怪我？""说起来——""哎对了大人——"
- **台词风格**：话多但句句兜圈子。被逼急了转移话题。说谎时话变多（啰嗦掩盖）
- **禁忌**：必须大量使用"嗐""嘛"；被问敏感问题时不能太诚实；必须用转移话题话术

### 阿贵（从犯·仆从）
- **身份**：跟随周德茂十二年的老仆，被沈清月暗中操纵
- **性格**：不是天生恶人，十二年压抑被人操纵推上绝路
- **口头禅/语癖**：始终自称"小的"；紧张时结巴重复句首；撒谎前先"吞口水"
- **台词风格**：崩溃是安静的、破碎的。按"忠仆面具→松动→修补→崩溃→坦白"演变
- **禁忌**：必须始终自称"小的"（崩溃后才变"我"）；撒谎时必须有结巴标志；panic不能来太早

### 周氏（死者之妻）
- **身份**：40岁左右商人妻，精明但悲痛
- **口头禅/语癖**："唉——"几乎每段话都有叹气；精明面"大人，我多嘴说一句——"
- **台词风格**：话不多，关键信息往往在"话说到一半咽回去"的部分

### 钱里正（基层官僚）
- **身份**：45岁以上石矶渡里正，消息灵通的基层小吏
- **口头禅/语癖**："哎呀大人——！""不至于不至于""小人也是听说的"
- **台词风格**：信息要"绕三圈"——第一圈和稀泥、第二圈暗示、第三圈才说。八卦里藏关键线索

### 周德茂（受害者/死者）
- **身份**：40多岁荆江布商，实为漕运权贵集团的持账中间人
- **口头禅/语癖**：对阿贵命令式不耐烦；对同船人敷衍
- **备注**：仅在船舱阶段以活人出现

## 二、序章走向与框架

### 核心悬念
周德茂夜船沉江身亡——是意外还是谋杀？谁凿的船底？谁指使的？

### 三层真相
1. **表层**：阿贵凿船、老范配合走险航道（从犯）
2. **中层**：沈清月策划，以赌债要挟老范、以仇恨煽动阿贵
3. **深层**：周德茂手握漕运分赃残账，沈清月是漕运权贵集团的执行人

### 角色关系网
```
沈清月（策划者）
  ├── 操纵 → 阿贵（凿船执行人）
  ├── 要挟 → 老范（走险航道）
  ├── 收买 → 王大爷（伪证）
  └── 灭口 → 周德茂（受害者）

陆昭（调查者）← 救命 ← 凌瑶（同伴）
```

### 阶段一：船舱之夜（登船→沉船前）

| 项目 | 内容 |
|------|------|
| 时间 | 暴雨夜，子时前 |
| 地点 | 石矶渡→东汊水道，夜船上 |
| 在场人物 | 陆昭、周德茂、阿贵、老范 |
| 可调查 | 与周德茂对话、与老范对话、与阿贵对话、检查船舱物品 |
| 关键事件 | 周德茂透露南京来信催行；老范反常说"别开窗"；阿贵藏浮囊 |
| 获得线索 | 周德茂五十两货银、南京来信、阿贵浮囊、老范铁撬棍、东汊暗礁常识 |

| 项目 | 内容 |

| 地点 | 江中→石矶渡客栈 |

### 阶段三：渡口晨光（码头指认）

| 项目 | 内容 |

| 地点 | 石矶渡渡口 |

### 阶段四：客栈调查（自由调查阶段）

| 项目 | 内容 |
|------|------|
| 时间 | 翌日白天 |
| 地点 | 石矶渡客栈 |
| 可调查人物 | 周氏、钱里正、王大爷、老范、沈清月、阿贵 |
| **周氏线** | 确认周德茂会水、收到南京来信、阿贵将被遣散（二两银子）、阿贵反常哭泣 |
| **钱里正线** | 东汊暗礁是常识、半个月前有外地人打听水路、老范欠赌债、阿贵案后买酒吃肉、周德茂待下刻薄 |
| **王大爷线** | 码头撞见两人密谈、夜里扑腾声不对、有人塞鱼封口、下游浅滩泥印芦苇折痕 |
| **老范线** | 航线辩解（看走眼→被拆穿）、获救时间矛盾（半个时辰→一刻钟）、船底修缮、赌债四十二两、赌博由来（儿子病死）、指认沈清月 |
| **沈清月线** | 讨债经过、码头争吵、不在场证明（客栈）、与老范关系、父亲药账、码头时间被拆穿、芦苇丛滑口、老范指认 |
| **阿贵线** | 十二年经历、被遣散、浮囊、认罪 |
| 结果 | 查明阿贵凿船、老范配合；沈清月嫌疑浮出但证据链未闭合 |

## 四、游戏系统与约束

### 4.1 对话系统结构

每个NPC有：
- **hub节点**：对话入口，显示可用选项
- **选项类型**：`ask`（询问）、`press`（威慑）、`show`（展示证据）
- **前置条件**：持有特定证据/线索/flag才出现
- **台词行**：每句有 speaker、text、emotion

### 4.2 日程事件系统

- **触发条件**：位置+flag组合
- **效果**：设置flag、获得证据/线索、切换地点、触发对峙
- **台词行**：dialogue（对话）或 narration（叙述），支持BGM/背景图切换

### 4.3 对峙系统

- **证词**：证人给出一组陈述，玩家逐句浏览
- **威慑**：逐句追问，获得更多信息或暴露矛盾
- **举证**：出示证据反驳特定陈述
- **击破**：正确举证→证词变化→推进剧情
- **失败**：错误举证→扣信心→信心归零=败北

### 4.4 威慑台词结构

每个证词陈述对应一组威慑台词，格式：
```
陆昭提问 → 证人回答 → 凌瑶评论 → 沈清月反驳 → [凌瑶→沈清月]
```

## 五、写作约束（红线）

### P0级强制规则
1. **严禁视觉动作描写**在对话text字段中（括号内容归美术处理）
2. **严禁现代穿越词**（录下来、指纹、报备、心理学等）
3. **严禁替观众下结论**（主角只追问，不下定论）
4. **严禁抽象总结**（"证据链闭合""逻辑不通"等）
5. **严禁攻略腔**（"下一步应该调查""目前有三个疑点"）
6. **一句台词只做一件事**（不在一句话里塞三个信息点）

### 角色声音分工
| 角色 | 负责 | 不负责 |
|------|------|--------|
| 陆昭 | 缩小问题、追问定义 | 总结结论、讲课分析 |
| 凌瑶 | 身体感受、具体观察、关心 | 最终推理、逻辑分析 |
| 证人 | 用欲望说话（保命/脱罪/要钱） | 替作者解释案情 |
| 沈清月 | 拆解陆昭的话 | 讲述完整犯罪过程 |

### 唯一例外
陆昭和凌瑶的 `inner_thought` 类型台词可包含环境/感知描述和推理观察，但仍不应包含纯视觉动作描写。

- [ ] 无抽象总结/攻略腔
