# 项目规则（统一版）

> 旧规则已归档至 `BACKUP/rules_archive/`。本文件为唯一有效规则文件。

---

## 一、文案规范

### 1.1 禁止破折号
- **严禁使用 `——`（中文破折号）除非必要**
- 分隔用逗号、句号、省略号代替
- 破折号只在极度强调或转折时才允许使用，且需有明确理由

### 1.2 心理活动格式
- 陆昭的心理独白（自言自语、内心念头）：**必须用中文括号 `（...）` 包裹，在引擎中自动渲染为蓝色**
- 数据标记方式：CSV 中 `type` 或 `emotion` 字段设为 `inner_thought`
- 心理活动可穿插在任何句子中：`陆昭,,,跟周老爷相识多久了？（十二年……这不短了。）,casual`

### 1.3 说话口吻
- 调查阶段（初识、随意询问）：**闲聊口吻**，情绪用 `casual`/`curious`/`friendly`/`soft`
- 质问/逼问阶段（亮证据、拆穿）：**温和但坚定**，情绪用 `gentle`/`soft`，避免 `serious`
- `serious` 情绪原则上禁止在陆昭台词中出现（对峙阶段例外）
- 开场独白：纯心理活动，不显示说话人名和头像

### 1.4 叙述视角
- 搜索点/调查结果的叙述文本：**必须用第一人称括号格式 `（...）`**，禁止第二人称 `你`
- 描述性文字（如物品描述、场景旁白）可保持第三人称，不强制括号

## 二、UI/显示规范

### 2.1 陆昭头像
- **非对峙阶段（DialogueBox）：陆昭不显示头像，只显示名字**
- 对峙阶段（ConfrontationPanel）：独立渲染，正常显示头像
- 心理活动（`inner_thought`）：不显示名字、不显示头像

### 2.2 对话框文字偏移
- 有 NPC 立绘时：文字区域 `offset_left = 48px`（`DIALOGUE_TEXT_LEFT_DEFAULT`）
- 有同伴头像时：文字区域 `offset_left = 264px`（`DIALOGUE_TEXT_LEFT_WITH_AVATAR`）

### 2.3 选项面板
- 选项面板始终**居中于对话框区域**（`box.global_position.x + (box.size.x - panel_w) / 2`）
- **禁止 `hide_after_visit`**：已访问过的选项保持在列表中，仅标记"✓ 已完成"，不消失

## 三、角色规则

### 3.1 陆昭（lu_zhao）
- 身份：隐秘御史，外热内冷
- 表面：儒生，有礼，好奇，会闲聊
- 内在：警觉，观察入微，但不说破
- 情绪：`casual`/`curious` > `gentle`/`soft` > `determined`（极度避免 `serious`）

### 3.2 凌瑶（xia_lingyao）
- 身份：金鳞镖局首席镖师，大侠风范+温柔可爱
- **称呼陆昭直接叫"陆昭"，不用"陆公子"**
- 对话中的观察句：**不说出结论性推断**，改为 `inner_thought` 内心独白
- 短促细节观察（外部可见）可保留为说出来的话
- **禁止战术简报**：不给陆昭指路、不拆证据、不分析对手策略
- **禁止读心式全知视角**：不说"她早就准备好""像排练过"等
- 支持方式：情感共鸣 + 直觉观察 + 轻推（把球抛回给陆昭）

### 3.3 钱里正（li_zheng）— 主审官
- 身份：石矶渡里正 + 公堂主审官（类似逆转裁判中的法官）
- **对峙阶段的控场者**：传唤发言、控制顺序、做阶段性总结、宣布休堂
- 不是铁面判官：优先自保，尽量不得罪任何一方，但必须维持基本秩序
- 语言标志：「依我看」「都缓缓」「轮到你了」「今日先到这儿」
- 八面玲珑但不失底线：关键证人开口时才真正认真起来

## 五、数据规范

### 5.1 ID 命名
- 全部使用 `snake_case`，小写字母开头
- 证据ID：`evidence_` 前缀
- 线索ID：`clue_` 前缀
- NPC ID：如 `lu_zhao`、`agui`、`lao_fan`

### 5.2 对话节点
- 必须可从 start 节点到达
- 必须有退出选项（`__exit__`）
- goto 必须指向存在的节点

### 5.3 证据链
- 质询前必须获得相关证据
- 证据获取顺序合理
- Flag 依赖不形成死锁

## 六、美术规范

### 6.1 立绘
- **必须使用已有角色图片作为参考（img2img）**
- 纯紫背景 `#FF00FF` → 运行抠图脚本去底
- 尺寸：848×1264（同伴/序章NPC）

### 6.2 CG
- 全屏整图，不需要透明背景
- 背景为自然场景，不要纯色抠图背景
- 尺寸：1920×1080

### 6.3 物品图标
- 纯紫背景 → 抠图去底
- 无文本、无水印

### 6.4 输出目录
| 类型 | 目录 |
|------|------|
| 立绘 | `assets/cn/portraits/` |
| CG | `assets/cn/scenes/` |
| 证据图标 | `assets/ai_processed/objects/evidence_icons/` |
