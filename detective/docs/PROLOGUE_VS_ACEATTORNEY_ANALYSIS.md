## 二、剧本深度分析

### 2.1 案件复杂度

| 维度 | 本作 | 逆转1话 |
|------|------|---------|
| 案件层次 | **三层** (表层意外→阿贵执行→沈清月策划) | 两层 (嫌疑人→真凶) |
| 动机深度 | 阿贵：12年压迫+遣散绝望；沈清月：父病+经济算计 | 较单一的仇恨/利益 |
| 犯罪手法 | 多人协作凿船沉船+事后打捞+伪造证词 | 单人直接行凶 |
| 翻转次数 | 2次 (老范→阿贵→沈清月) | 1次 |

**评估**：案件设计显著超越逆转第一话，接近逆转3-4话的复杂度。但对序章而言可能过于复杂——逆转第一话刻意简单是为了降低教学门槛。

### 2.2 主题深度

核心隐线："杀人的和被杀的，谁更可怜？"
- 阿贵十二年被压榨 → 凶手也是受害者
- 沈清月为父治病被逼到绝路 → 动机令人同情
- 周德茂欠债不还、克扣仆从 → 死者并非无辜

**问题**：这个深度只在 `ask_twelve_years`（可选对话，13行）中体现。大多数玩家可能跳过。

### 2.3 伏笔与回收

| 伏笔 | 埋设 | 回收 | 效果 |
|------|------|------|------|
| 沈清月"别想走" | ask_quarrel | 对峙第三轮 transition | ✓ 双关，优秀 |
| "亥时前回客栈" | ask_alibi | 对峙第三轮 break | ✓ 三次改口递进 |
| "码头闲话"口头禅 | 多次使用 | 对峙第二轮被拆穿 | ✓ 模式识别 |
| 沈清月随口说出"量刑" | 对峙 sf1_4 press | 仅在 inner_thought 点出 | △ 未回收为实际矛盾点 |
| 阿贵十二年血泪 | ask_twelve_years | 无回收 | ✗ 可选且孤立 |
| 五十两货银 | 多处提及 | 打捞目击串联 | ✓ 核心推理链 |

## 三、人物表现分析

### 3.1 语言辨识度

| 角色 | 语言特征 | 评分 |
|------|----------|------|
| 沈清月 | "大人"、反问式攻击、逻辑防守、语气从"飒"→"冷"递进 | ★★★★★ |
| 阿贵 | "小的"、重复语式（说三遍）、肢体泄露 | ★★★★☆ |
| 凌瑶 | "嘶——"、"本姑娘"、直觉判断、低声提示 | ★★★★☆ 但稍单一 |
| 陆昭 | 极简冷峻、用问题回答问题 | ★★★☆☆ 有范儿但单调 |

### 3.2 角色弧线

**沈清月（5阶段递进）**：
```
cooperative/bold → sharp/deflecting → cracking → cold_fury → broken
（合作掩饰）     （锋利转守）       （裂痕）    （冷怒反击）  （崩溃）
```
每步有肢体描写触发（抱臂紧了→手指扣着→手放下来→嘴唇颤抖）。教科书级别。

**阿贵（3阶段）**：
```
grief (悲伤伪装) → nervous/panic (紧张暴露) → 对峙击破
```

**问题**：
1. 陆昭（主角）全程 cold/serious，没有情绪弧线。逆转中成步堂有紧张→顿悟→自信→爆发。
2. 凌瑶 90% 台词是功能性提示，缺乏独立情感/成长。对比真宵/矛盾。

### 3.3 "废笔"缺失

逆转大量"无用"对话实际做三件事：建立人设、制造松弛、隐藏伏笔。
本作几乎没有废笔——每句都在推案。导致：角色不够立体、节奏过紧、无法投射情感。

## 四、节奏分析

### 4.1 整体结构

```
逆转第一话：
  开场杀人(5min,紧张) → 法庭上午(20min,递进) → 调查(10min,松弛) → 法庭下午(30min,高潮) → 收尾(5min)

本作：
  逃生(5min,紧张) → 铺垫(10min,松弛) → 调查Phase1(20min,中) → 阿贵对峙(15min,高潮1)
  → 调查Phase3(15min,中) → 沈清月对峙(20min,高潮2)
```

**问题**：
1. 缺少"不可退出的紧张"段落——开放探索让节奏主导权在玩家手里
2. 两个高潮之间缺少情绪落差/缓冲
3. 开场到第一次对峙路径过长（20-30min无强制推动）

### 4.2 对峙内部节奏

逆转每轮 5-7 分钟，形成"新证词(升温) → 浏览(积压) → 发现矛盾(顿悟) → 举证(爆发) → break演出(高潮) → 过渡(松弛)"的脉冲式节奏。

**本作问题**：每轮平均 3-4 条陈述太短，玩家没来得及积累"找线索的焦虑感"就已突破。

### 4.3 情绪光谱

| 情绪 | 逆转中来源 | 本作 |
|------|-----------|------|
| 紧张 | 法庭倒计时 | ✓ 信心系统 |
| 爆发 | "Objection!" | △ 文本有但缺演出数据 |
| 幽默 | 证人搞笑、错误举证趣味反应 | ✗ 基本没有 |
| 温情 | 助手安慰、回忆 | ✗ |
| 恐惧 | 新证据揭露黑暗 | ✓ Phase3 反转 |
| 同情 | 凶手认罪独白 | △ 有但弱 |

**核心缺失**：幽默和温情。

## 五、逻辑分析

### 5.1 推理链

**阿贵链**：船底有洞(人为) + 浮囊(预谋逃生) + 遣散字据(动机) → 三证合一 ✓
**沈清月链**：打捞目击 + 中间人指认 + 时间矛盾 → 三证合一 ✓ + 补充动机(药账)

### 5.2 精彩的逻辑交锋

sf1_4 节点（对峙中）：
```
沈："阿贵认罪后攀咬——减轻罪责。教唆从重、被教唆从轻——量刑不一样。"
陆："一个仆从知道这种律法知识？"
[内心：她比阿贵更懂律法。]
```
用"不该知道的知识"反推涉案深度，超过逆转早期所有对峙。

### 5.3 逻辑弱点

1. `evidence_dock_timing`（凌瑶证词）= 搭档的话，非独立证据
2. sf3_2 break 从时间线跳到药账缺少逻辑桥接
3. 阿贵的矛盾点太直接（"完全没准备" vs 浮囊），缺少一步推理

## 七、阻塞性 Bug

### 问题

Phase 2 对峙（沈清月）无法触发。

### 根因

`scripts/main/MainGame.gd` 第 1039-1054 行：

```gdscript
func _on_confrontation_finished(result: String, mistakes: int) -> void:
    _close_subpanel()
    if result == "victory":
        var confront_key: String = GameManager.active_confrontation_key
        var suspect: String = GameManager.case_data.get(confront_key, {}).get("suspect", "")
        if suspect == "agui":
            GameManager.set_flag("agui_confessed_mastermind")
    GameManager.active_confrontation_key = "confrontation"  # ← 重置（非致命）
    var ending_id := GameManager.judge_confrontation(result, mistakes)
    if ending_id == "bad" or ending_id == "partial":
        _try_companion_banter("accuse_fail")
    if _try_play_case_epilogue(ending_id):
        return
    _show_ending(ending_id)  # ← 致命：阿贵胜利后直接显示结局
```

阿贵是中BOSS，胜利后应返回调查进入Phase 3，而非触发结局。`judge_confrontation("victory", n)` 返回 "perfect"/"good"/"partial" → 直接走 `_show_ending()` → 游戏结束。

### 修复方案

核心思路：区分"中间对峙"和"最终对峙"。

方案A（数据驱动）：case.json 对峙数据增加 `"is_final": false/true`，代码据此判断。

方案B（检测后续）：检查 case_data 中是否还有未完成的后续对峙。

推荐方案A，更显式可控。
