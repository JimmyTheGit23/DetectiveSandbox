# 序章剧情逻辑修复方案

## 概述

修复周氏指控中的逻辑漏洞，使剧情更加合理。

---

## 1. 问题分析

### 1.1 官服与"付不起钱"的矛盾

**现状：**
- 陆昭是巡按御史，应该穿着官服
- 官服是在船上才湿掉的（说明上船时还穿着）
- 但周氏说"上船的时候你连船钱都付不起"

**矛盾：**
如果陆昭穿着官服上船，周氏应该能看出他是官员，不会说他"付不起钱"。

### 1.2 只怀疑陆昭的逻辑问题

**现状：**
- 周氏说"同船的人只有你活着"是错误的
- 阿贵和老范也都活着
- 但周氏只指控陆昭

**问题：**
如果要怀疑，应该怀疑所有人，而不是只怀疑陆昭。

---

## 2. 修复方案

### 2.1 方案A：陆昭便装出行（推荐）

**设定：**
- 陆昭便装出行，没穿官服
- 周氏不知道陆昭是官员
- 周氏认为陆昭是个穷书生

**修改内容：**

**prologue_lines.csv 修改：**
```csv
day2_zhou_accuse_1,0,周氏,"同船的人——他死了，你活着！

（扑过来抓住你衣领）你一个外乡人，连行李都没有，上船时还是我家老爷替你垫的船钱！五十两货银——钱呢？！你就是图财害命！！",grief,
```

**解释：**
- 删除"连船钱都付不起"，改成"连行李都没有"
- 周氏认为陆昭是个穷书生，没有行李，所以需要别人垫付船钱
- 这样更合理，因为陆昭确实没有行李（沉在江底了）

### 2.2 方案B：周氏只指控"外人"

**设定：**
- 周氏知道阿贵和老范都活着
- 但周氏认为阿贵和老范是"自己人"（仆从和船家）
- 陆昭是"外人"（陌生人），所以重点怀疑他

**修改内容：**

**prologue_lines.csv 修改：**
```csv
day2_zhou_accuse_3,0,周氏,"你还想狡辩？！阿贵跟了老爷十二年，老范跑了二十年船——他们为什么要害老爷？

只有你——一个来路不明的外乡人！你从天窗跑了，老爷却淹死了！不是你是谁？！",grief,
```

**解释：**
- 周氏不怀疑阿贵和老范，因为他们是"自己人"
- 周氏重点怀疑陆昭，因为他是"外人"
- 这样更符合周氏的心理：悲伤过度，只想要一个"凶手"

### 2.3 方案C：周氏悲伤过度乱咬人

**设定：**
- 周氏悲伤过度，没有仔细核实
- 周氏只看到了陆昭，没有看到阿贵和老范
- 周氏的指控是情绪化的，不是理性的

**修改内容：**

**prologue_lines.csv 修改：**
```csv
day2_zhou_accuse_3,0,周氏,"你还想狡辩？！我丈夫死了——死了！你却好端端站在这儿！

（哭喊）你为什么不救他？！你为什么不救他？！",grief,
```

**解释：**
- 周氏不指控陆昭是凶手，而是质问陆昭为什么不救她丈夫
- 这样更符合周氏的心理：悲伤过度，只想找一个人发泄
- 避免了逻辑漏洞
