# 序章「渡口沉舟」逆转裁判体量改造计划

## 目标
将序章从当前约350句对白扩展至1000-1100句，达到逆转裁判1序章（矢张的审判）的体量。每个角色需有强烈性格辨识度和口头禅。

## 现状
- 5 NPC + 主角陆昭 + 助手凌瑶 = 7人
- 每NPC约10-30句对白（总计约150句）
- 对峙系统3轮证词已有（约200句）
- 序章演出（沉船逃生+客栈）质量不错

## 执行步骤

### Step 1: 角色设定卡 [P0]
为7个角色编写详细设定（口头禅/语气/性格/情绪范围/核心矛盾）

### Step 2: 对峙台词丰富化 [P0]
- 证词内心OS (+30句)
- 追问二级深度 (+40句)
- 错误举证反应多样化 (+15句)
- 阿贵情绪演变台词 (+30句)

### Step 3: 主线NPC对话树扩展 [P1]
- 阿贵：阶段变体 + 闲聊 + 交叉验证 + 证物反应
- 老范：阶段变体 + 闲聊 + 交叉验证 + 证物反应

### Step 4: 凌瑶Companion台词 [P2]
- 地点触发闲聊 (+40句)
- 证据讨论 (+30句)
- 阶段转场对话 (+30句)

### Step 5: 配角NPC扩展 [P3]
- 周氏、钱里正、王大爷对话树扩展
- 交叉验证反应

### Step 6: 序章/过场增量 [P4]
- 凌瑶救人碎嘴 (+15句)
- 客栈暖场加长 (+25句)
- 发现尸体冲击感 (+20句)
