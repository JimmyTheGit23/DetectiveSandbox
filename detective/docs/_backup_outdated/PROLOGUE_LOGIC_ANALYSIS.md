# 序章剧情逻辑分析

## 概述

分析序章中周氏和阿贵对陆昭的指控，指出其中的逻辑漏洞。

---

## 1. 周氏的指控

### 1.1 "同船的人只有你活着"

**原文：**
> "你还想狡辩？！同船的人只有你活着！只有你从天窗跑了！不是你是谁？！"

**问题：**

这个指控在事实上是错误的。同船四人中：

| 人员 | 状态 | 说明 |
|------|------|------|
| 周德茂 | 死亡 | 溺亡 |
| 陆昭 | 存活 | 玩家角色 |
| 阿贵 | 存活 | 周德茂的仆从 |
| 老范 | 存活 | 船家 |

**分析：**
- 周氏说"只有你活着"是错误的，阿贵和老范都活着
- 可能的原因：
  1. 周氏悲伤过度，没有仔细核实
  2. 周氏只看到了陆昭，没有看到阿贵和老范
  3. 剧情设计漏洞

**建议修复：**
- 修改周氏的台词为："同船的人——他死了，你却好端端站在这儿！"
- 或者解释周氏为什么不知道其他人活着

### 1.2 "你连船钱都付不起"

**原文：**
> "上船的时候你连船钱都付不起，还是我家老爷替你垫的！五十两货银——钱呢？！你就是图财害命！！"

**问题：**

剧情中没有明确解释为什么陆昭付不起船钱。

**可能的解释：**
1. 陆昭是巡按御史，但便装出行，身上没带钱
2. 官印和行李都沉在江底了
3. 有人故意设计让陆昭看起来穷困

**剧情中的线索：**
- `prologue_lines.csv:125`: "官印落在了船舱里。连同行李、文书——全沉在江底了。"
- `prologue_lines.csv:127`: "你看我现在这样，确实不像个御史。"

**分析：**
- 陆昭确实没有官印和行李，但这不能说明他付不起船钱
- 周氏说"老爷替你垫的"，说明周德茂帮陆昭付了钱
- 但这不能作为陆昭"图财害命"的证据

**建议修复：**
- 增加背景说明：陆昭便装出行，身上确实没带钱
- 或者修改周氏的指控，不要用"付不起钱"作为证据

## 2. 阿贵的指控

### 2.1 "铁器打人"

**原文：**
> "他用铁器打了老爷！老爷被打晕了才落水的！"

**问题：**

尸检报告证明死者没有钝器伤。

**证据：**
- `evidence_items.csv`: "尸检报告：无钝器伤 - 周德茂的尸体面色青紫、口鼻有泡沫——典型的溺亡特征。头部和身体没有钝器击打的痕迹。"

**分析：**
- 阿贵说"铁器打人"是假的
- 尸检证明死者是溺亡，不是被打死的
- 这是阿贵编造的谎言

**游戏中已处理：**
- 对峙中可以用 `evidence_no_blunt_trauma` 反驳这个指控

### 2.2 "天窗逃走"

**原文：**
> "他从天窗逃走的！那扇天窗平时用铁锁锁死——他肯定是用那把铁器撬开的！"

**问题：**

陆昭确实从天窗逃走了，但这是为了逃生，不是为了逃跑。

**剧情：**
- `prologue_lines.csv:165`: "昏暗中能看到：头顶一扇天窗透进雨夜的微光。舱壁上挂着一根铁撬棍。"
- `prologue_lines.csv:171`: "你扯下舱壁上的铁撬棍，把漂起来的木箱踹到天窗正下方——踩上去。"
- `prologue_lines.csv:174`: "锁扣断裂，天窗向外弹开。冷雨浇在脸上。"

**分析：**
- 陆昭用铁撬棍撬开天窗是为了逃生
- 船在沉，水在涨，陆昭必须逃出去
- 这不是"逃跑"，而是"求生"

**建议：**
- 在对峙中强调陆昭是为了逃生，不是为了逃跑
- 凌瑶可以作证：陆昭被救上来时都快断气了

### 2.3 "凶器"

**原文：**
> "那个铁家伙——一定是凶器！他肯定是在舱里趁老爷不备，用铁器砸了老爷！"

**问题：**

铁撬棍是船上的工具，不是陆昭带来的凶器。

**剧情：**
- `prologue_lines.csv:165`: "舱壁上挂着一根铁撬棍。"
- 铁撬棍是船上的工具，挂在舱壁上

**分析：**
- 铁撬棍是船上的工具，不是陆昭带来的
- 陆昭用它来撬天窗，不是用来打人
- 尸检证明死者没有钝器伤，所以铁撬棍不是凶器

## 3. 其他指控

### 3.1 "没有官印"

**原文：**
> "你说你是御史？有官印文书吗？"

**问题：**

官印沉在江底了，但这不能证明陆昭不是御史。

**剧情：**
- `prologue_lines.csv:125`: "官印落在了船舱里。连同行李、文书——全沉在江底了。"

**分析：**
- 官印沉在江底是事实
- 但这不能证明陆昭不是御史
- 只能说没有证据证明他是御史

### 3.2 "岸边有人接应"

**原文：**
> "码头王大爷说，翻船前半刻钟，南岸就有人打着灯笼在走。船一沉，那人就朝下游跑。你这位姑娘，恰好在那个时辰、那个地方把你捞起来的——这也太巧了吧？"

**问题：**

凌瑶是偶然在那里的，不是来接应陆昭的。

**剧情：**
- 凌瑶是金鳞镖局的信使，送信路过石矶渡
- 她在码头等天亮过江
- 听到江上响动才跑出去的

**分析：**
- 凌瑶的出现是巧合，不是接应
- 但这个巧合确实可疑
- 需要解释凌瑶为什么在那里
