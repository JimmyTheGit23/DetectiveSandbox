# 序章「渡口沉舟」剧本框架总纲

> **case_id**: `prologue_ferry`
> **时代背景**: 万历廿二年 · 腊月 · 荆江石矶渡
> **游戏定位**: 教学+钩子案件 · 陆昭×凌瑶首次搭档
> **结构**: 五幕双对峙（中BOSS → FINAL BOSS）
> **对白总量目标**: ~1500行
> **预估时长**: 60-90分钟

## 一、案件概要

万历廿二年腊月。长江中游荆江段，石矶渡——一个偏僻的江畔小渡口。连日冬雨，江水暴涨。

布商**周德茂**携仆从**阿贵**乘船过江，准备经水路去武昌府办货。随行还有刚上任的巡按御史**陆昭**。当夜船在江中倾覆，周德茂溺亡，陆昭九死一生，被困渡口的金鳞镖局信使**凌瑶**所救。

表面看这是一起暗礁翻船事故。实际上，这是一桩经过精密策划的三人合谋谋杀案：

- **执行者**：仆从阿贵（凿穿船底、按住死者）
- **帮凶**：船家老范（选航道、打开活板、事后转移残骸）
- **幕后主谋**：药商之女沈清月（策划全局、操纵二人、事后打捞货银）

玩家需要在两次对峙中层层剥开真相——先揭穿直接凶手阿贵，再追查操纵一切的沈清月。

### 第一幕：沉舟逃生（Opening）

**时长**: 5-8分钟
**情绪曲线**: 紧张 → 危机 → 获救 → 搭档建立

#### 节拍分解

| 节拍 | 内容 | 情绪 | 对白要点 |

#### 各NPC对话设计（Phase A）

**阿贵**（3轮对话 × 8-12行/轮 = 约30行 + 证据反应20行）

- 证据出示反应：每件证据2-4行特殊反应

**老范**（3轮 × 8-12行 = 约30行 + 证据反应15行）

- 证据出示反应：老范不像阿贵那样崩，而是"硬扛"

**周氏**（3轮 × 6-10行 = 约25行）
- 第1轮：悲痛+疑点提出
- 第2轮：丈夫为人细节（刻薄面暴露）+ 遣散字据
- 第3轮（解锁条件：搜集3件证据）：关于沈清月和丈夫生意纠纷

**钱里正**（3轮 × 8-10行 = 约25行）
- 第1轮：讨好+八卦总汇
- 第2轮：老范赌债细节、暗礁常识
- 第3轮：沈清月骂人事件复述（关键伏笔）

**王大爷**（2轮 × 5-8行 = 约12行）

#### 三段证词详细设计

**第一段："那晚的经过"**

证词内容（4句循环）：
1. "那天夜里船开得好好的……突然就晃了起来……"
2. "小的吓坏了！老爷在舱里喊救命——小的想去拉他——"
3. "水太急了……一下子就翻了……小的什么都抓不住……"
4. "小的也差点死了啊大人！要不是命大——"

追问重点：第4句（"命大"）
- 追问后阿贵补充："小的……小的抱住了一块船板……"
- 凌瑶OS："抱住船板？那他身上为什么……"

举证：**牛皮浮囊** → 第4句
- 陆昭："你说你靠船板活命。那这个东西——是什么？"
- 阿贵："那、那是……！"
- 破绽展开：在冰冷江水中，没有浮囊不可能存活。你事先准备了逃生手段。

**第二段："关于船底那个洞"**

证词内容（4句循环）：
1. "那个洞……一定是撞上暗礁弄的！"
2. "老范说那片水域有礁石——连他都没看到……"
3. "船撞上去的时候，'咔嚓'一声——小的到现在还记得那个声音！"
4. "一定是暗礁……不然怎么会破那么大一个洞……"

追问重点：第3句（"咔嚓一声"）
- 追问后阿贵犹豫："是……是吧？小的记得是……"（开始不确定）

举证：**船底人工凿痕** → 第1句或第4句
- 陆昭："暗礁——不会留下凿子的痕迹。"
- 阿贵："…………！"

#### 三段证词详细设计

**第一段："我没有理由"**

证词内容（5句循环）：
1. "周德茂欠我家三十八两。白纸黑字。"
2. "他活着——我至少还能讨债。他死了——我一文钱都拿不到。"
3. "你觉得我会杀一个欠我钱的人？——那我脑子被门夹了。"
4. "我确实骂了他。当着二十个人的面。因为我气啊——但气不等于杀人。"
5. "大人，杀债主等于杀财路。没有比这更蠢的事了。"

核心逻辑：**杀死债主=失去债款=对自己不利=没有动机**
这是一个精心设计的反向逻辑陷阱。

追问重点：第2句（"他死了我一文钱都拿不到"）
- 追问后她补充："三十八两。没了。您说我亏不亏？"
- 凌瑶OS："她说得好像有道理……但——"

举证：**evidence_salvage_mark（打捞痕迹）** → 第2句
- 陆昭："你说他死了你一文钱拿不到。——但如果他随身带的五十两货银被人打捞了呢？"
- 沈清月："…………"
- 陆昭："王大爷清晨在下游看到有人打捞重物。一男一女。女的穿男装。"
- 破绽展开：38两拿不回——但50两货银可以捞回来。你不亏。你反赚。

**第二段："我跟他们没有关系"**

证词内容（5句循环）：
1. "阿贵？——我跟那仆人说过几句话？追债的时候吧。仅此而已。"
2. "老范？——我连他姓什么都不知道。"
3. "大人，我在这渡口待了不到十天。你说我操纵两个陌生人杀人？"
4. "巧合不等于罪行。我在这里追债——他们在这里杀人——这是两件事。"
5. "你不能因为我恰好在场就认定我有嫌疑。否则——渡口上百人都有嫌疑。"

核心逻辑：**否认与阿贵、老范的任何联系**

追问重点：第3句（"操纵两个陌生人"）
- 追问后她冷笑："大人是写话本的？这种剧情——太精彩了。"

举证：**evidence_shen_connection（赌坊中间人）** → 第2句
- 陆昭："你说你不认识老范。——但老范供称，有个'药材行的姑娘'通过赌坊找到了他。"
- 沈清月："（微微一顿）……他瞎说的。"
- 陆昭："赌坊的人也证实了。一个月前有女子替老范还了部分利息——作为'定金'。"
- 破绽展开：你通过赌坊中间人联络老范在先，案发在后。关联确实存在。

**第三段："你没有证据"**

证词内容（6句循环）：
1. "就算有人打捞了——你能证明是我？你亲眼看到了？"
2. "就算我认识老范——认识人犯法吗？"
3. "你所有的'证据'——全是推测。间接的。模糊的。"
4. "在公堂上——这些东西一条都不够定罪。大人应该比我更清楚。"
5. "我没杀人。我没碰那条船。我没按住任何人。——你有任何人证物证说我做了这些？"
6. "大人。收手吧。——你抓到了阿贵和老范。案子已经结了。"

核心逻辑：**所有证据都是间接的，她没有直接实施任何暴力行为**
这是真正的硬骨头——她说的每一句在法律上都是对的。

追问重点：第5句（"我没碰那条船"）和第6句（"案子已经结了"）
- 追问第5句后："我确实没碰。——是他们做的。不是我。"（技术性真话）
- 追问第6句后："（停顿）……你想怎样？"（第一次不再主动反击）

举证：**evidence_dock_timing（码头时间矛盾）** → 第5句或第6句
- 陆昭："你说你当晚在客栈睡觉。——但凌瑶在子时看到你出现在码头。"
- 沈清月："（极长的沉默）"
- 陆昭："案发前夜。凿船的夜晚。你在码头。——你在确认一切就绪。"
- 凌瑶补证："我当时就觉得奇怪——那个时辰、那个地方——"

追加举证：**evidence_father_ledger（沈父药账）** → 补刀
- 陆昭："你父亲需要八十两救命。你手头只有四十二两。"
- 陆昭："三十八两追不回来——但五十两货银足够补上缺口。"
- 陆昭："八十八两。够了。——这就是你的全部计划。"

## 十、暗线设计：沈家与幕后黑手

> **核心暗线**：沈清月不是孤立的犯罪者。她的行为背后有一个更大的势力在推动——沈家只是这个势力的一枚棋子。

### 10.1 暗线层次结构

```
表层（玩家在序章看到的）：
  沈清月为救父杀人 → 个人犯罪 → 案件结束

中层（序章埋线，后续章节揭开）：
  沈清月背后有人 → "教她如何策划犯罪"的不是她自己
  → 有人提前告诉了她周德茂的行程、货银数额
  → 这个信息源是谁？

深层（整个游戏的暗线主轴）：
  存在一个操控商路、信息、甚至司法的隐藏组织
  → 沈家药材行曾是这个组织的末端渠道
  → 周德茂散布谣言不是偶然——是有人授意他切断沈家
  → 沈清月的复仇，从更高视角看，是组织内部的"清理棋子"
```

### 10.2 幕后势力概念（暂定）

| 项目 | 设定 |
|------|------|
| 代号 | "织网者" / "商会暗部" / 待定 |
| 性质 | 横跨数省的地下商业网络，表面是正常商帮 |
| 手段 | 操控货源、散布谣言毁对手、借刀杀人、收买官吏 |
| 与沈家的关系 | 沈家药材行曾替他们走货（不知情），后被弃用 |
| 与周德茂的关系 | 周德茂是组织的"白手套"之一，散谣言是受指令 |
| 与沈清月的关系 | 有人"巧合地"让沈清月知道了周德茂的行程和货银 |

### 10.3 序章中的暗线伏笔（已埋设/待埋设）

| 伏笔 | 位置 | 表面含义 | 暗线真意 |
|------|------|---------|---------|
| 泡烂的密信 `evidence_wet_letter` | 沉船残骸中可搜到 | 看不清的字迹 | 周德茂与上线的通信 |
| 阿贵的"第三种笔迹" `clue_third_handwriting` | 遣散字据旁的小纸条 | 陌生人的笔迹 | 有人给阿贵传递了信息（中间联络人） |
| 沈清月说的"有人告诉我周德茂的行程" | 对峙胜利后（可选追问） | 她自己打听的 | 信息是被"喂"给她的 |
| 陆昭差点被杀 | 第一幕（他恰好在那条船上） | 巧合 | 可能不是巧合——有人建议他搭那条船 |
| 平水驿的驿丞建议改水路 | prologue.json 中已有 | 好心指路 | 驿丞可能受人指使 |
| 沈清月最后的话"你会遇到更难对付的人" | S结局 | 虚张声势/感慨 | 她知道组织的存在 |
| 王大爷提到"外地人" | Phase B调查中（模糊） | 路过的陌生人 | 组织的联络人/观察者 |

### 10.4 沈清月的暗线角色定位

```
序章定位：真凶 → 落网
后续可能性（取决于结局）：

S结局路线：
  → 沈清月入狱
  → 后续章节中她成为"狱中线人"
  → 她愿意提供组织信息（因为组织利用了她）
  → 但她的信息有限（她只是末端）
  → 关键台词："他们把我当棋子——跟我把阿贵当棋子一样。"

B结局路线：
  → 沈清月逃脱
  → 她可能被组织灭口（知道太多）
  → 或者她主动投奔组织求庇护
  → 后续章节再次出现时身份升级
  → 从"单案凶手"变为"组织中层"
```

### 10.5 暗线推进节奏（全游戏）

```
序章：渡口沉舟
  → 埋线：密信、驿丞、"有人告诉我行程"
  → 暗示：有更大的力量在背后
  → 玩家感受：隐约不安（"这案子底下还有东西"）

第二章：（待设计）
  → 暗线推进：发现周德茂的"上线"
  → 玩家发现：多个看似独立的案件有共同的影子

第三章：（待设计）
  → 暗线显化：组织的面貌逐渐清晰
  → 沈清月（若S结局）在狱中提供关键碎片

中后期：
  → 暗线主线化：玩家直接与组织对抗
  → 陆昭的赴任可能本身就被组织关注

终章：
  → 暗线收束：组织的核心是谁？目的是什么？
  → 呼应 META_FRAMEWORK 中的"世界级谜题"
```

### 10.6 设计原则

1. **序章不过度揭示**：玩家结案后应该感到"这案子结了，但好像还有什么没说完"——仅此而已
2. **伏笔要自然**：所有暗线伏笔在序章中都有合理的"表面解释"，不会让玩家觉得强行留悬念
3. **沈清月的角色弧完整**：她在序章中是完整的反派，暗线是额外维度而非必要条件
4. **后续章节可灵活调整**：暗线的具体走向可以根据玩家反馈和创作方向调整，序章只负责"埋种子"
