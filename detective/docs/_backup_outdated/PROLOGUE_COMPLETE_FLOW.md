# 序章「渡口沉舟」完整流程

## 流程概览

```
开场独白 → 沉船逃生 → 获救 → 客栈暖场 → 发现尸体 → 被指控 → 调查阶段 → 阿贵对峙 → 沈清月对峙 → 结局
```

---

## 第一阶段：开场剧情（沉船逃生）

### 1. 开场独白（opening_monologue_1-4）
- **背景**：纯黑
- **内容**：陆昭回忆往事
- **台词**：
  - "每逢阴雨，我便想起那条江。"
  - "黑水，沉船，以及那些再也没能上岸的脸。"
  - "那时候，我以为真相会让人好过一些。"
  - "后来才明白——有些真相，比谎言更冷。"

### 2. 时间卡
- **文字**：万历廿二年 · 腊月 · 亥时
- **副标题**：荆江 · 石矶渡

### 3. 沉船逃生（cabin_1 → cabin_swim_b）
- **场景**：船舱 → 甲板 → 江水
- **BGM**：ferry_prologue_escape
- **事件**：
  1. 船舱进水，陆昭惊醒
  2. 发现船底有方形破洞（人为凿穿）
  3. **3回合密室逃脱**：
     - 回合1：水到膝盖
     - 回合2：水到大腿
     - 回合3：水到腰（最终）
  4. 使用铁撬+木箱撬开天窗
  5. 跳入江中游泳
- **获得线索**：clue_cabin_hole_memory（沉船记忆：方形的洞）

### 4. 岸边获救（shore_1 → inn_arrival）
- **场景**：岸边 → 客栈
- **BGM**：ferry_prologue_shore
- **事件**：
  1. 凌瑶救起陆昭
  2. 凌瑶自我介绍：金鳞镖局信使
  3. 扶陆昭去客栈
- **角色出场**：凌瑶（companion_lingyao）

## 第三阶段：第二天 - 发现尸体

### 7. 黎明（day2_dawn → day2_dawn_innkeeper_b）
- **场景**：客栈大堂
- **事件**：
  1. 掌柜告知：昨晚翻船，仆从和船家都没死
  2. 布商的婆娘一早赶来

### 8. 码头发现尸体（day2_dawn_commotion → day2_body_4b）
- **场景**：码头
- **BGM**：ferry_dock_investigation
- **事件**：
  1. 凌瑶跑来报告：有人被冲上来了
  2. 周德茂的尸体面朝下
  3. 陆昭认出：昨夜同船的布商
  4. "三个人落水，只有不会游泳的那个死了"

### 9. 周氏指控（day2_body_5 → day2_zhou_accuse_3）
- **场景**：码头
- **BGM**：accuse_tension
- **事件**：
  1. 周氏冲出来扑倒在尸体旁
  2. 指控陆昭：
     - "同船的人——他死了，你活着！"
     - "你一个外乡人，连行李都没有，上船时还是我家老爷替你垫的船钱！"
     - "阿贵跟了老爷十二年，老范跑了二十年船——他们为什么要害老爷？只有你——一个来路不明的外乡人！"

### 10. 阿贵指证（day2_agui_appears → day2_agui_2b）
- **场景**：码头
- **事件**：
  1. 阿贵出现，眼圈通红
  2. 指控陆昭：
     - "看见这位爷蹲在船底舱口那边"
     - "他手里好像攥着个铁家伙"
     - "他用铁器打了老爷！老爷被打晕了才落水的！"
     - "他从天窗逃走的！那扇天窗平时用铁锁锁死——他肯定是用那把铁器撬开的！"

### 11. 里正调解（day2_lizheng_appear → day2_lizheng_5b）
- **场景**：码头
- **事件**：
  1. 钱里正出现
  2. 要求陆昭证明身份
  3. 指出疑点：
     - 没有官印
     - 没有行李
     - 带着铁家伙
     - 知道天窗逃生路线
  4. 凌瑶为陆昭辩护
  5. 给出两天期限

### 12. 决心调查（day2_framed_resolve → day2_start_game）
- **场景**：码头 → 客栈
- **BGM**：ferry_dock_investigation
- **事件**：
  1. 人群散去
  2. 阿贵飞快地瞥了陆昭一眼
  3. 凌瑶支持陆昭
  4. 陆昭决定找出真相
  5. **游戏正式开始**
- **操作说明**：
  - 右侧菜单：地图 / 对话 / 移动 / 探索 / 笔记本 / 讨论
  - 「讨论」：随时与凌瑶交流，获取下一步方向
  - 跨地点移动花费一个时段
  - 收集到足够证据后，对话中会出现「对峙」选项

## 第四阶段：调查阶段

### Phase 1：初步调查
- **地点**：ferry_inn, ferry_dock, wreck_site
- **目标**：勘察沉船残骸，走访滞留人员
- **提示**：先去码头和打捞处看看那条船，再问问死者妻子和那个仆从
- **关键证据**：
  - evidence_hull_hole（船底人工破洞）
  - evidence_float_bladder（牛皮浮囊）
  - evidence_no_blunt_trauma（尸检报告：无钝器伤）
  - evidence_wrong_channel（错误的航道）
  - clue_fan_alibi_hole（老范时间矛盾）
  - evidence_dismissal_note（遣散字据）
  - evidence_gambling_iou（赌债字据）

### Phase 2：深入追查
- **地点**：river_bend
- **解锁条件**：evidence_hull_hole 或 evidence_wrong_channel
- **目标**：船底的破洞说明这不是意外。下游渔村有人知道更多
- **提示**：有个老渔翁住在下游江湾，案发当夜他在江上。去找他
- **NPC解锁**：fisherman_wang（王大爷）

### Phase 3：追查幕后
- **地点**：shen_room, gambling_alley
- **解锁条件**：flag agui_confessed_mastermind
- **目标**：阿贵不是主谋——他背后还有人。那个'教他的人'，就在这客栈里
- **提示**：沈清月还在客栈二楼。现在需要找到能把她钉死的证据
- **关键证据**：
  - evidence_cargo_silver（失踪的货银）
  - evidence_salvage_mark（下游打捞痕迹）
  - evidence_shen_connection（赌坊中间人）
  - evidence_dock_timing（码头时间矛盾）
  - evidence_father_ledger（沈父药账）

## 第五阶段：阿贵对峙（confrontation）

### 13. 开场剧情（intro_dialogue 0-14）
- **场景**：客栈大堂
- **BGM**：ferry_confrontation
- **内容**：
  1. 环境氛围渲染：雨声、霉味、香烛烟气
  2. 角色状态描写：
     - 阿贵：双手绞在一起，指节发白
     - 老范：旱烟杆转圈
     - 周氏：攥皱帕子
     - 王大爷：半睁半闭
  3. 钱里正宣布开始
  4. 陆昭："好。——那就从头说起。"

### 14. 证人证词（4组）

#### testimony_wang：王大爷的证词（3条）
1. "那天夜里我在江上收网。亥时过后——听见东汊那边一声闷响。然后就看见船翻了。"
2. "船翻之后，不到一刻钟——就有个人爬上了南岸。动作利索得很，不像是快淹死的人。"
3. "还有一件事。翻船前一天傍晚，码头上有两个人碰面。一高一矮，说了'明天亥时''走东汊'。" **（矛盾）**
   - **反驳证据**：evidence_wrong_channel（错误的航道）

#### testimony_lao_fan_route：老范其一·翻船原因（3条）
1. "那晚雨急，江面全是雾。船出码头时还稳，到了东汊才突然被浪顶了一下。"
2. "船底破开，是撞上暗礁和浪头后裂的。老船再结实，也经不住江水折腾。" **（矛盾）**
   - **反驳证据**：evidence_hull_hole（船底人工破洞）
   - **替代证据**：evidence_nail_marks（船底钉痕）
3. "我也是受害人。船翻了，我差点把命丢在江里。"

#### testimony_lao_fan_rescue：老范其二·落水之后（3条）
1. "船一翻，我也被卷进水里。冬江冷得像刀子，哪里还分得清东南西北。"
2. "我在水里泡了半个时辰，后来才被下游渔民拉上去。要不是命硬，早没了。" **（矛盾）**
   - **反驳证据**：clue_fan_alibi_hole（老范时间矛盾）
3. "周老爷不会水，阿贵又慌。我自己都顾不上，哪里还能救人？"

#### testimony_lao_fan_motive：老范其三·无冤无仇（3条）
1. "我跟周老爷第一次见。收了船钱，送他过江，仅此而已。"
2. "我不缺这点船钱，也不缺银子。杀人？为了什么？" **（矛盾）**
   - **反驳证据**：evidence_gambling_iou（赌债字据）
3. "再说了，周老爷死了，货银也沉江。我能落着什么好？"

### 15. 阿贵证词（4组）

#### testimony_0：他杀了老爷！（3条）
1. "那晚三更刚过，我起来解手——看见他蹲在船底舱口，手里攥着个铁家伙！"
2. "他用铁器打了老爷！老爷被打晕了才落水的！" **（矛盾）**
   - **反驳证据**：evidence_no_blunt_trauma（尸检报告：无钝器伤）
3. "他从天窗逃走的！那扇天窗平时用铁锁锁死——他肯定是用那把铁器撬开的！"

#### testimony_1：那晚的经过（4条）
1. "那晚老爷说要坐船赶路，叫我一起伺候。上了船我就在舱里待着。"
2. "船突然就翻了——什么征兆都没有！我完全没有准备，差点就淹死了！" **（矛盾）**
   - **反驳证据**：evidence_float_bladder（牛皮浮囊）
3. "我不会水——落水之后就什么都不知道了。醒过来已经在岸上。"
4. "到了岸上浑身湿透，冻得不行。天亮才挣扎到客栈求救。"

#### testimony_2：关于那个洞（3条）
1. "老范之前就跟我说过，这段水路有暗礁。我害怕才带的浮囊——提前防备而已！"
2. "船底那个洞——就是被暗礁撞出来的！石头尖利得很！" **（矛盾）**
   - **反驳证据**：evidence_hull_hole（船底人工破洞）
   - **替代证据**：evidence_nail_marks（船底钉痕）
3. "带浮囊防身又不犯法！我只是谨慎！小心驶得万年船！"
   - **追加选项**：追问后承认"是有人跟我说过'带个浮囊保险'"
   - **反驳证据**：evidence_dismissal_note（遣散字据）

#### testimony_3：不是我干的（4条）
1. "老爷对我不薄！跟了十二年，吃穿不愁。我怎么会害他？"
2. "老爷遣散我的时候还给了路费银子——他是体恤我，让我自由！" **（矛盾）**
   - **反驳证据**：evidence_dismissal_note（遣散字据）
3. "要说动机——老范欠了赌坊四十二两！他才是被逼急的那个！不关我事！"
4. "小的冒枉！我只是个仆从！哪有胆子杀人！"

## 第六阶段：沈清月对峙（confrontation_final）

### 18. 开场剧情（intro_dialogue 0-14）
- **场景**：客栈二楼沈清月房间
- **BGM**：accuse（紧张）
- **内容**：
  1. 沈清月坐在窗边，连姿势都没换
  2. 沈清月："来了啊。比我预计的快了半天。"
  3. 凌瑶提示："她不是阿贵。她不会哭着认罪的。得一步步把她的逻辑全部拆碎。"
  4. 陆昭："沈清月。阿贵已经招了。"
  5. 沈清月："一个因谋杀被捕的人——为了减轻自己的罪，把锅推给别人。大人觉得这种供词有几分可信？"
  6. 沈清月："你要定我的罪——就拿能让我闭嘴的东西出来。"

### 19. 沈清月证词（3组）

#### shen_testimony_1：我没有理由（4条）
1. "周德茂欠我三十八两。他死了——这笔钱就永远要不回来了。我杀他等于杀自己的钱袋子。"
2. "我当着二十多人的面骂了他。你见过哪个凶手杀人之前先大张旗鼓地公开动机？"
3. "五十两货银随船沉了江。人死了，钱也没了——我是这件事里亏得最惨的人。" **（矛盾）**
   - **反驳证据**：evidence_salvage_mark（下游打捞痕迹）
   - **替代证据**：evidence_cargo_silver（失踪的货银）, evidence_father_ledger（沈父药账）
4. "阿贵的供词？一个杀人犯为了脱罪什么都敢说。大人不会连这点都不明白吧？"

#### shen_testimony_2：我跟他们没有关系（3条）
1. "老范？见过。码头的人谁没见过？但我没跟他说过超过三句话。"
2. "老范欠赌坊四十二两——这种事码头人尽皆知。我也是听说的。我跟赌坊没有任何来往。" **（矛盾）**
   - **反驳证据**：evidence_shen_connection（赌坊中间人）
   - **替代证据**：evidence_gambling_iou（赌债字据）
3. "阿贵？我甚至不认识他。一个商人的仆从——我为什么要跟他说话？"
   - **追加选项**：追问后承认"就算我跟他说过话——在码头碰见聊两句而已"
   - **反驳证据**：evidence_dock_timing（码头时间矛盾）
   - **替代证据**：evidence_float_bladder（牛皮浮囊）, evidence_dismissal_note（遣散字据）

#### shen_testimony_3：你没有证据（3条）
1. "就算我在码头待到深夜。盯着自己的债务人——合情合理。这不叫犯罪。"
2. "你有的只是：一个赌鬼的指认、一个杀人犯的攀咬、和一个老渔翁在黑夜里看到的模糊身影。这些——够判死刑吗？" **（矛盾）**
   - **反驳证据**：evidence_dock_timing（码头时间矛盾）
   - **替代证据**：evidence_father_ledger（沈父药账）
3. "就算……就算那笔账说得通。'有动机'和'做了'是两回事。你没有亲眼看到我教阿贵凿船——你永远证明不了。"

### 20. 胜利剧情（victory_dialogue 0-50）
- **BGM**：cornered（最终对峙）
- **内容**：
  1. 沈清月认罪："……你赢了。"
  2. 揭露动机：
     - 父亲病重，需要八十两药钱
     - 周德茂欠三十八两不还
     - 周德茂散播谣言，毁了沈家生意
     - 父亲气得吐血，起不了床
  3. 沈清月："阿贵恨了他十二年。老范被他逼到走投无路。我——我只是那个不愿意再忍了的人。"
  4. 陆昭："你把阿贵当棋子用。一个被克扣了十二年的人——你利用了他的恨。"
  5. 沈清月："……我知道。我对不起阿贵。但我不后悔周德茂的死。"
  6. 陆昭："法不容情。周德茂该受制裁——但不是这种制裁。你选择了杀人。这是你的罪。"
  7. 陆昭决定："她父亲的药费……从查没的货银中扣出治病的钱，转交沈家。"
  8. 沈清月被带走前："……陆昭。你是个好官。可惜我遇到你——晚了三个月。"
  9. **悬念**：沈清月最后问："你有没有想过——为什么你恰好也在那条船上？"
  10. 发现匿名字条："周德茂腊月十七走石矶渡。五十两货银。夜船。船上会有一个南京来的读书人。他会活着上岸。"
  11. **悬念**：写纸条的人——才是真正的幕后

### 21. 失败剧情（defeat_dialogue 0-3）
- **内容**：
  1. 沈清月嘲笑："大人。你手里所有的证据加在一起——也只够定阿贵的罪。跟我有什么关系？"
  2. 凌瑶提示："直接证据确实不够。得把她时间线上的矛盾砸在她脸上！"
  3. 需要重新收集证据

## 第七阶段：结局

### 标准结局：「舟覆人明」

**结局文案**：
```
你揭破了全部真相。

周德茂之死并非暗礁意外——是一场精心策划的谋杀。沈清月利用阿贵十二年的积怨和老范的赌债，一手导演了凿船沉舟。

执行者阿贵、工具人老范被押往县衙。真正的主谋沈清月——也没有逃脱。

你从她的房间搜出了打捞上来的五十两货银。铁证如山。

周氏终于得到了完整的交代。沈家老父的药钱从货银中拨出——法有法度，情有情理。

石矶渡恢复了平静。渡口立了新规：不再接独行客的夜船。

——这是你办的第一桩案子。但不会是最后一桩。
```
