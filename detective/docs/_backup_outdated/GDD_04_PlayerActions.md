# GDD 04 — 玩家操作与可执行行为

> 定义玩家在游戏中的所有可执行操作

---

## 1. 双界面模式

```
┌──────────────────────────────────────────────┐
│                 游戏界面                       │
├─────────────────────┬────────────────────────┤
│   探索模式 (Tab 1)   │   推演模式 (Tab 2)      │
│   - 场景探索         │   - 笔记本系统          │
│   - NPC 交互         │   - 推理面板            │
│   - 证据收集         │   - 指认系统            │
│   - 隐秘行动         │                        │
└─────────────────────┴────────────────────────┘
         随时可按 Tab 切换
```

---

## 2. 探索模式 — 五大行为类别

### 2.1 移动导航

| 操作 | 说明 | 消耗 |
|------|------|------|
| 移动至地点 | 点击地图上的可达地点 | 5-15 min（取决于距离） |
| 查看小地图 | 打开当前区域俯视图 | 0 |
| 快速移动 | 已到访地点可快速传送 | 固定 5 min |

**特殊规则**:
- 部分地点在特定时段不可进入（如夜间的商店）
- 部分地点需要钥匙或解锁条件
- 移动过程中可能触发随机事件

### 2.2 观察调查

| 操作 | 说明 | 消耗 |
|------|------|------|
| 环顾 | 查看当前场景描述，发现可交互物品高亮 | 2 min |
| 检查物品 | 点击高亮物品查看详细描述 | 3 min |
| 搜索 | 对区域进行仔细搜索（发现隐藏物品） | 10 min |
| 收集证据 | 将发现的物品加入线索板 | 1 min |
| 拍照记录 | 对场景/物品拍照留存 | 1 min |

**特殊规则**:
- 搜索同一区域多次收益递减
- 部分证据需要特定工具才能采集
- 有人在场时搜索可能被发现（增加警觉度）

### 2.3 NPC 交互

| 操作 | 说明 | 消耗 |
|------|------|------|
| 对话 | 进入对话界面，从选项列表选择 | 5-15 min/次 |
| 送礼 | 消耗金币提升信任度 | 5 min + 金币 |
| 跟踪 | 远距离跟随 NPC 观察其行为 | 30 min |
| 偷听 | 在 NPC 对话时偷听（需在隐蔽位置） | 10-20 min |

**对话详见**: [GDD_03_DialogueSystem.md](GDD_03_DialogueSystem.md)

### 2.4 隐秘行动

| 操作 | 说明 | 消耗 | 风险 |
|------|------|------|------|
| 潜入 | 进入非公开区域（需要特定条件） | 15 min | 被发现则信任度大减 |
| 撬锁 | 打开锁着的门/柜子（需工具） | 5 min | 失败则发出声响 |
| 翻找 | 在 NPC 不在时搜索其私人区域 | 10 min | 被发现则警觉度+20 |
| 安装窃听 | 在某地点放置窃听道具 | 3 min | 可被 NPC 发现并销毁 |

**特殊规则**:
- 隐秘行动有**发现概率**，受时段、场景人数、NPC 警觉度影响
- 被发现后该 NPC 信任度降至 0，且全局警觉度提升
- 夜间隐秘行动成功率更高但认知负荷消耗加倍

### 2.5 自我管理

| 操作 | 说明 | 效果 |
|------|------|------|
| 休息（旅馆） | 回旅馆睡觉 | 认知负荷 -15，消耗至次日早晨 |
| 小憩（咖啡馆） | 去咖啡馆休息 | 认知负荷 -5，消耗 30 min |
| 购买道具 | 在商店消费 | 获得工具/道具 |
| 用餐 | 在餐厅吃饭 | 认知负荷 -3，可能遇到 NPC |

## 3. 推演模式 — 笔记本四页签

按 **Tab** 键或点击笔记本图标进入推演模式。

### 3.1 人物档案页

| 功能 | 说明 |
|------|------|
| NPC 列表 | 显示所有已知 NPC 的头像和基本信息 |
| 关系图谱 | 可视化展示 NPC 间的关系连线 |
| 信任度指示 | 每个 NPC 当前对玩家的信任度 |
| 标记嫌疑 | 可手动标记某 NPC 为嫌疑人/证人/排除 |
| 备注 | 玩家可为每个 NPC 添加自由文字备注 |

### 3.2 线索板页

| 功能 | 说明 |
|------|------|
| 物证列表 | 所有收集到的物证，可查看详情 |
| 证词列表 | 所有获得的证词，标注来源 NPC |
| 矛盾标记 | 系统自动高亮存在矛盾的证词对 |
| 线索关联 | 玩家可手动拖拽连线，建立线索间的关联 |
| 分类筛选 | 按类型/来源/时间筛选线索 |

### 3.3 时间线页

| 功能 | 说明 |
|------|------|
| 案件时间线 | 可视化展示已知的事件时间线 |
| 空白时段 | 高亮未知时段，提示调查方向 |
| NPC 行踪 | 按 NPC 筛选，查看特定人的时间线 |
| 矛盾标记 | 时间线上的矛盾点以红色标记 |

### 3.4 指认页

| 功能 | 说明 |
|------|------|
| 指认凶手 | 选择一个 NPC 作为凶手 |
| 指认动机 | 从选项中选择犯罪动机 |
| 指认手法 | 从选项中选择犯罪手法 |
| 关键证据 | 选择 3 件最关键的证据支撑推理 |
| 信心度 | 系统根据证据充分度显示推理信心百分比 |
| 提交推理 | **不可撤回**，提交后进入结局判定 |

**重要规则**:
- 指认仅可在 **D7（最后一天）** 进行
- D1-D6 可以在指认页「草拟」但不能正式提交
- 提交前会有确认弹窗，明确告知不可撤回
- 信心度仅作参考，不影响实际判定
