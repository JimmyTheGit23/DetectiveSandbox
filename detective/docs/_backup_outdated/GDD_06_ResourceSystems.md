## 2. 时间系统

### 基本参数

| 参数 | 值 |
|------|-----|
| 总游戏天数 | 7 天 |
| 1 天 = 现实时间 | ~25 分钟 |
| 1 天 = 游戏时间 | 24 小时 (6:00-次日6:00) |
| 时间推进方式 | 基于行为消耗，非实时流逝 |

### 行为时间消耗

| 行为 | 消耗（游戏内分钟） |
|------|---------------------|
| 移动至相邻地点 | 5 min |
| 移动至较远地点 | 10-15 min |
| 快速移动 | 5 min |
| 环顾场景 | 2 min |
| 检查物品 | 3 min |
| 深度搜索 | 10 min |
| 普通对话 | 5-10 min |
| 施压/质问 | 10-15 min |
| 跟踪 NPC | 30 min |
| 偷听 | 10-20 min |
| 隐秘行动 | 5-15 min |
| 小憩 | 30 min |
| 休息（过夜） | 至次日 6:00 |

### 时间压力曲线

```
紧迫感
  ▲
  │        ╱─── D5-D6 高压
  │      ╱
  │    ╱─── D3-D4 中压
  │  ╱
  │╱─── D1-D2 低压
  └──────────────────→ 天数
```

## 3. 认知负荷系统

### 参数

| 参数 | 值 |
|------|-----|
| 初始值 | 0 |
| 上限 | 100 |
| 每日自然恢复 | 过夜后 -15 |

### 增加因素

| 因素 | 增量 |
|------|------|
| 恐怖/惊吓场景 | +5 |
| NPC 谎言（被识破时） | +3 |
| 错误推理（提交错误关联） | +8 |
| 夜间行动 | +2 / 10 min |
| 施压对话 | +8 |
| 质问对话 | +5 |
| 试探对话 | +2 |
| 检查恐怖物品 | +3 |
| 推理陷阱（未识破） | +15 |

### 减少因素

| 因素 | 减量 |
|------|------|
| 旅馆休息（过夜） | -15 |
| 咖啡馆小憩 | -5 |
| 正确推理（建立正确关联） | -3 |
| 用餐 | -3 |
| 闲聊（放松型对话） | -1 |

### 阈值效果

| 阈值 | 效果 |
|------|------|
| 50+ | 画面轻微失真，文字偶尔模糊 |
| 70+ | 线索描述变得模糊，选项减少 |
| 90+ | 出现幻觉（虚假线索提示），严重画面扭曲 |
| 100 | **昏迷**，损失当天剩余时间，次日认知负荷恢复至 60 |

### 昏迷后果
- 当天剩余时间全部浪费
- 次日认知负荷从 60 开始（而非 0）
- 累计昏迷 2 次 → 触发「侦探陨落」结局

## 4. 对话次数系统

| 参数 | 值 |
|------|-----|
| 每日总对话次数 | 10-15 次 |
| 同一 NPC 每日上限 | 3 次 |
| 施压/质问每日上限 | 共 3 次 |

### 对话次数的策略意义
- 迫使玩家**规划**每天要找谁谈话
- 不能暴力穷举所有选项
- 施压次数有限，需精准使用

## 5. NPC 信任度系统

### 参数

| 参数 | 值 |
|------|-----|
| 初始信任度 | 30（中立） |
| 范围 | 0 – 100 |
| 自然衰减 | 无 |

### 信任度变化

| 行为 | 变化量 |
|------|--------|
| 闲聊 | +3~+5 |
| 送礼 | +5~+15（取决于礼物价值） |
| 帮助 NPC | +10~+20 |
| 试探 | -1~+2 |
| 质问 | -5~-10 |
| 施压 | -10~-15 |
| 被发现隐秘行动 | **降至 0** |
| 出示无关证据 | -3 |
| 出示关键证据 | 视 NPC 反应 |

### 信任度阈值

| 阈值 | 效果 |
|------|------|
| 0-10 | NPC 拒绝交谈，仅基础选项 |
| 11-30 | 基础对话可用 |
| 31-50 | 标准对话 + 部分试探选项 |
| 51-70 | 深入话题解锁 |
| 71-90 | 私密信息可获取 |
| 91-100 | NPC 主动提供关键线索 |

## 6. 金币系统

### 参数

| 参数 | 值 |
|------|-----|
| 初始金币 | 100 |
| 每日收入 | 0（无被动收入） |

### 消费项

| 项目 | 花费 |
|------|------|
| 旅馆住宿 | 10 / 晚 |
| 咖啡馆小憩 | 5 |
| 用餐 | 5-10 |
| 送礼（普通） | 10-20 |
| 送礼（贵重） | 30-50 |
| 购买工具（撬锁器等） | 15-30 |
| 购买特殊道具 | 20-50 |
| 行贿获取信息 | 30-80 |

### 金币策略
- 总预算 100，7 天内需合理分配
- 部分关键信息只能通过金币获取
- 过度送礼会导致后期缺乏工具购买能力

## 7. 凶手警觉度系统（隐藏）

### 参数

| 参数 | 值 |
|------|-----|
| 初始值 | 0% |
| 范围 | 0% – 100% |
| 玩家可见 | **否**（隐藏值） |
| 间接提示 | 有（NPC 行为变化、环境暗示） |

### 增加因素

| 行为 | 增量 |
|------|------|
| 直接质问凶手 | +10~+15 |
| 搜索凶手相关区域 | +5~+10 |
| 向凶手出示关键证据 | +10~+15 |
| 向其他 NPC 施压（消息传到凶手耳中） | +3~+5 |
| 在凶手面前表现出「接近真相」 | +5 |

### 阈值效果

| 阈值 | 凶手行为 |
|------|----------|
| 0-29% | 正常表现 |
| 30% | 开始销毁次要证据 |
| 60% | 制造假线索，收买证人改口 |
| 80% | 触发推理陷阱场景 |
| 100% | **凶手逃跑** / 制造新事件，若玩家未识破推理陷阱 → Game Over |

### 间接提示（玩家察觉线索）

| 警觉度范围 | 玩家可观察到的变化 |
|------------|---------------------|
| 30%+ | 某物品「失踪了」 |
| 60%+ | 某 NPC 突然改变证词 |
| 80%+ | 收到匿名威胁信 / 场景出现不明痕迹 |

## 8. 数值平衡原则

| 原则 | 说明 |
|------|------|
| 资源紧张但不窒息 | 玩家应该总觉得时间/对话次数不太够，但不至于完全无法推进 |
| 多路径可解 | 不存在唯一必须路径，任何一个资源耗尽都有替代方案 |
| 隐藏值有提示 | 虽然警觉度不直接显示，但行为变化可让敏锐玩家察觉 |
| 昏迷可恢复 | 单次昏迷不致命，两次才会 Game Over |
| 金币不可续 | 刻意设计为不可回补，训练玩家规划能力 |
