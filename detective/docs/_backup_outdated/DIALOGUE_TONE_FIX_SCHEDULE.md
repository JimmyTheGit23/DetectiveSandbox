1. CSV 中的文本包含逗号时需要用双引号包裹，修改时注意保持格式
2. emotion 标签必须是 DialogueManager 支持的值（cold/serious/worried/anxious/determined/shocked/angry 等）
3. 新增行需要保持 npc_id 和 node_id 与同节点其他行一致
4. 修改后需要检查 dialogue_nodes.csv 的 end 字段是否指向正确的最后一行
