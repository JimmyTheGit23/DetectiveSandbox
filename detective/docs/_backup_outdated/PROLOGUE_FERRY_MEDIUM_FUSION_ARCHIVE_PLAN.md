# 《渡口沉舟》中度融合方案归档与实施计划

> 归档时间：2026-06-01  
> 方案档位：B 档 / 中度融合  
> 目标：在不推倒现有可玩流程的前提下，把《万历河弊》设定融合进序章，使案件从“地方骗财命案”升级为“市井骗保掩护朝堂灭口”的主线开端。  
> 相关旧文档：`PROLOGUE_FERRY_OPTIMIZED_FLOW.md`、`PROLOGUE_REWRITE_FUSION_PLAN.md`、`PROLOGUE_FERRY_IMPLEMENTATION_GAP_ANALYSIS.md`

## 1. 归档结论

当前序章已经具备融合基础：

- 陆昭已是巡按御史，官印沉江；
- 沈清月已是终局真凶，并具备草药、讼师、操盘者属性；
- 阿贵、老范已有凿船、浮囊、赌债、被利用等结构；
- 王大爷伪证、周氏控诉、沈清月终局脱身已经接近逆转式序章败局；
- 现有数据表已支持证据、证词、击破台词、对峙、尾声等分层改写。

因此不建议重度重写。最佳方案是采用中度融合：

> 保留当前序章的可玩结构和数据表框架，强化三层真相、四轮对峙、沈清月双层动机、毒理法理终局翻盘。

## 2. 中度融合核心设定

### 2.1 三层真相

| 层级 | 玩家表面认知 | 实际作用 |
|---|---|---|
| 第一层：沉船骗保 | 阿贵、老范凿船制造触礁假象，意图骗保 / 诈财 | 保留现有调查和对峙证据链 |
| 第二层：灭口杀局 | 沈清月利用骗保计划，追加草药、细线、救生物缺失等杀局 | 升级沈清月反派强度 |
| 第三层：朝堂黑幕 | 周德茂并非普通布商，陆昭也非偶然乘船 | 连接后续漕运贪腐主线 |

### 2.2 沈清月动机双层化

现有“父亲药钱 / 周家旧债”不删除，改为表层动机：

- 表层动机：周德茂欠债、货银、父亲药钱；
- 深层动机：陆昭南下暗查漕运贪腐，周德茂掌握账据，沈家为利益网核心节点，必须借民间骗保事故一石二鸟。

序章不应直接说满深层动机，只在尾声通过湿信、账据残页、官印被动过、沈清月知道陆昭身份等碎片埋伏笔。

### 2.3 阿贵、老范罪责重定

不洗白二人，但降低他们对“定向杀人”的知情程度：

- 他们明知会沉船，有重大罪责；
- 他们以为只是骗保 / 诈财 / 让周德茂吃亏；
- 他们不知道沈清月另设草药和细线杀局；
- 他们既是从犯，也是沈清月预备好的替罪羊。

### 2.4 终局从“单证翻盘”升级为“双重败局”

终局保留现有香囊赝品翻盘，同时增加毒理法理对决：

1. 陆昭出示香囊，沈清月指出香囊被调包，物证失效；
2. 陆昭转向尸体线索：脚踝细线勒痕、舌根草药残留；
3. 沈清月以专业压制：草药遇淡水数分钟失活，残留只是植物纤维；细线市面可购，无法唯一指向她；
4. 陆昭提出“油脂锁住舌根药渣”的终极异议，逼出沈清月瞬间破绽；
5. 审判官仍以证据不足驳回指控，形成序章败局。

## 3. 四轮对峙结构归档

### 第一轮：王大爷 / 王老伯

目标：洗清陆昭“水中行凶”的直接嫌疑。

推荐结构：

- 王大爷声称夜里能看见陆昭靠近周德茂；
- 陆昭用朔月、乌云、风雨、距离、视线条件击破；
- 沈清月第一次介入：证人年迈，月色细节有误不代表核心目击事实为假；
- 结果：伪证动摇，但公堂没有完全采信陆昭。

### 第二轮：老范

目标：揭穿“触礁意外”。

推荐结构：

- 老范咬死船只老旧触礁；
- 陆昭用船底人工破洞、航道异常、钉眼新旧、赌债等证明人为沉船；
- 老范濒临崩溃，暴露骗保意图；
- 沈清月第二次介入：骗保沉船只能证明有人谋财，不能证明周德茂被谁杀死。

### 第三轮：阿贵

目标：揭穿“无准备落水”和“只是意外失踪”。

推荐结构：

- 阿贵声称落水时人人自顾不暇；
- 陆昭用浮囊购买记录、里衣干湿、提前逃生路线等击破；
- 阿贵崩溃，承认与老范合谋沉船，但强调“她说不会死人”；
- 沈清月第三次介入：杀人从犯的攀咬不足为证，主观体感不可作为物证。

### 第四轮：沈清月

目标：不是立即定罪，而是逼出她第一次失态。

推荐结构：

- 沈清月以终局证人身份出庭，称船老触礁、人溺天意；
- 陆昭连续指出香囊、细线勒痕、草药残留；
- 沈清月用赝品、孤证、市面可购、草药失活等规则拆解证据链；
- 陆昭用“油脂锁药渣”逼出破绽；
- 审判官判证据不足，沈清月脱身。

## 4. 实施计划

### P0：冻结范围与兼容原则

目标：避免中度融合演变成重度重写。

- 不重写整个序章；
- 不废弃船舱探索、王大爷对峙、现有证据表；
- 不在序章明说完整朝堂黑幕；
- 不把沈清月写成当场认罪；
- 所有新增信息优先落在 CSV 表格中，少改系统代码。

产出：以本文档为准，后续改动围绕 B 档方案执行。

### P1：世界观与动机改写

目标：先把“万历河弊”和“双层动机”嵌入现有文本。

优先文件：

- `data/case_tables/prologue_ferry/case_meta.csv`
- `data/case_tables/prologue_ferry/prologue_lines.csv`
- `data/case_tables/prologue_ferry/epilogue_lines.csv`
- `data/case_tables/prologue_ferry/characters.csv`

改动要点：

- 开场补入江南漕运、沉船骗保成风；
- 陆昭南下目的从“途经”强化为“隐秘查案”；
- 周德茂从普通布商升级为疑似账据中间人，但不明说；
- 沈清月表层动机仍保留药钱，尾声露出她另有所图；
- 尾声增加“南京 / 漕 / 账 / 官印被动过”等主线碎片。

### P2：证据链补强

目标：为终局毒理法理对决提前埋公平线索。

优先文件：

- `data/case_tables/prologue_ferry/evidence_items.csv`
- `data/case_tables/prologue_ferry/search_points.csv`
- `data/case_tables/prologue_ferry/search_results.csv`
- `data/case_tables/prologue_ferry/progression_unlocks.csv`

新增或调整证据建议：

| 证据 ID 建议 | 用途 |
|---|---|
| `evidence_fine_fishing_line` | 指向水下细线陷阱，但不能唯一指向沈清月 |
| `evidence_ankle_ligature_mark` | 尸检脚踝细痕，终局用于反驳意外溺亡 |
| `evidence_tongue_herb_residue` | 舌根草药残留，终局毒理争点 |
| `evidence_greasy_meal_trace` | 油腻酒菜 / 油脂残留，终极异议伏笔 |
| `evidence_account_fragment` | 周德茂非普通布商的尾声伏笔 |

注意：细线不要写成“深海鱼线”，建议改为“极细鱼线 / 蚕丝钓线 / 蜡封细线”，更贴合江南河道。

### P3：四轮对峙重排

目标：将现有对峙升级为王大爷 → 老范 → 阿贵 → 沈清月的四段压迫结构。

优先文件：

- `data/case_tables/prologue_ferry/confrontations.csv`
- `data/case_tables/prologue_ferry/testimony_sets.csv`
- `data/case_tables/prologue_ferry/testimony_statements.csv`
- `data/case_tables/prologue_ferry/testimony_break_lines.csv`
- `data/case_tables/prologue_ferry/confrontation_lines.csv`

改动顺序：

1. 先整理现有 `confrontation_wang`，让它成为第一轮伪证击破；
2. 再把普通 `confrontation` 拆成老范与阿贵两段，不一定新增系统，只需在证词集和台词节奏中形成两轮；
3. 最后强化 `confrontation_final`，让沈清月亲自作证并完成双重败局；
4. 每轮都给沈清月一次“把陆昭推理压回证据规则”的介入台词。

### P4：对话与角色反应统一

目标：让调查、质询、伙伴提示和公堂文本口径一致。

优先文件：

- `data/case_tables/prologue_ferry/dialogue_lines.csv`
- `data/case_tables/prologue_ferry/dialogue_options.csv`
- `data/case_tables/prologue_ferry/day_event_lines.csv`
- 相关 NPC 对话 JSON / CSV（如当前项目实际接入文件）

改动要点：

- 凌瑶只提示疑点，不替玩家给现成推理；
- 周氏仍可被悲痛和暗示推动，但不要写成主动阴谋者；
- 王大爷是被收买 / 被引导伪证者，不是主谋；
- 阿贵、老范台词体现“骗保从犯”和“没想到会死人”；
- 沈清月始终冷静，只有“油脂锁药渣”处出现极细微失态。

### P5：流程接入与回归确认

目标：确认表格改动能跑通，不引入流程断点。

关注点：

- 船舱开场是否接入实际播放链；
- 王大爷对峙是否仍能直接触发；
- 证据解锁是否满足四轮对峙需要；
- 终局失败是否进入序章败局尾声，而非普通 bad ending；
- 新增证据是否有搜索点、获得文本、显示名、描述和解锁条件。

---

## 5. 推荐执行顺序

1. 先改开场和尾声：快速确立“万历河弊 + 朝堂黑幕伏笔”；
2. 再补证据：细线、舌根草药、油脂酒菜、账据残页；
3. 再重排对峙：王大爷、老范、阿贵、沈清月四轮；
4. 最后统一 NPC 对话和凌瑶提示；
5. 每完成一阶段，运行现有表格校验，避免 CSV 引用断裂。

---

## 6. 验收标准

中度融合完成后，应达到以下效果：

- 玩家能理解阿贵、老范为何凿船；
- 玩家能看出沈清月不是单纯为钱杀人，而是在借局灭口；
- 每轮对峙都有明确破绽、证据、沈清月压制点；
- 终局不是“玩家没查到”，而是“玩家推到真相但证据规则不够”；
- 沈清月脱身后仍保留可追查火种：官印、账据、南京、漕运；
- 序章结尾自然引向后续主线，而不是封闭式地方案件。

---

## 7. 暂缓事项

以下内容暂不进入本轮中度融合：

- 完整重写所有序章台词；
- 新增大规模系统机制；
- 在序章明示全部贪腐集团名单；
- 让沈清月当庭认罪或被定罪；
- 重新生成或替换大量美术资源；
- 改成全新案件结构。
