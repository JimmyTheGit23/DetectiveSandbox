## 1. 陆昭（主角 · 隐秘御史）

### 基本定位
京城特派**隐秘御史**，奉旨**暗查漕运账弊与官商勾结巨案**，行事低调隐匿身份。外表是冷面书生，言语极简但每句都有分量。内心其实比外表活跃得多——有吐槽欲但忍着不说。

### 背景设定
- 万历年间，江南漕运滋生沉船骗保等灰色勾当，船家商户承保行当地方小吏盘根错节。
- 陆昭奉旨以"外乡书生"身份暗中南下，真实使命是查清漕运分赃网络。
- 他的御史身份从一开始就被人洞悉——官印匣外封角有被人撕动痕迹。

### 口头禅/语癖
- 正式场合："说。"、"继续。"、"这句话——再说一遍。"
- 审问收尾："好。记下了。"
- 内心OS（括号）："（……又来。）"、"（这人说了三遍'没有'。通常说一遍就够了。）"
- 冷幽默极少但致命："你说的这些，能在堂上再说一遍吗？——我给你准备好笔墨。"

### 情绪范围
| 标签 | 使用场景 |
|------|---------|
| cold | 默认审讯态度 |
| serious | 分析推理时 |
| quiet_fury | 发现恶行时（不爆发，但语气骤冷）|
| tired | 序章逃生后的疲惫 |
| dry_humor | 极罕见的内心吐槽 |

### 核心矛盾
隐秘御史，差点死在第一次赴任路上。他的真实身份被人提前洞悉——石矶渡夜船成了针对他的灭口局。序章他赢了推理，却输在法律本身有时效性漏洞。

### 动作习惯
- 审问时目光不移开
- 思考时无意识敲桌面
- 下结论前会停顿一拍（文本中用"……"表达）

## 2. 凌瑶（助手 · 金鳞镖局首席镖师）

### 基本定位
碎嘴侠女。嘴比脑子快，但眼睛比嘴更快。说话像连珠炮，情绪全写在脸上。金鳞镖局首席镖师，押送急件路过石矶渡，携带铜牌证物。

### 口头禅/语癖
- 自称："本姑娘"（激动时）/ "我"（正经时）
- 感叹："嘶——"、"哈？！"、"得了吧！"
- 评价人："这人有鬼。"、"瞧他那样——"
- 催促："快快快！"、"等什么呢？"
- 吐槽："话本子都不敢这么写。"、"他上辈子是X？"（X 随语境变）
- 鼓励："行吧行吧，本姑娘信你。"

### 情绪范围
| 标签 | 使用场景 |
|------|---------|
| cheerful | 默认/闲聊 |
| anxious | 有进展但不确定 |
| determined | 抓住线索 |
| shocked | 重大发现 |
| worried | 对陆昭/案情担心 |
| smug | 验证了她的猜测 |

### 核心矛盾
第一次参与查案，兴奋和不安并存。想证明自己不只是个"跑腿送信的"。

### 动作习惯
- 激动时拍桌子/拍大腿
- 压低声音碎碎念（"（低声）"开头）
- 偷偷观察人时歪头眯眼
- 紧张时咬嘴唇/来回踱步
- 高兴时会拍陆昭肩膀（不分场合）

### 助手特殊功能
- **提示系统**：用吐槽形式给玩家方向（"嘶——他刚才那个眼神不对啊。那个证据……就是那个——"）
- **总结推进**：每阶段结束用"所以现在咱们知道了——"句式总结

## 3. 阿贵（被操纵的棋子 · 死者仆从）

### 基本定位
十二年老仆。表面卑微忠诚，实际积怨已深。**被沈清月拿捏弱点、暗中操纵**——他以为只是参与骗保诈财，**不认为会死人**。伪装"可怜人"是他的本能——但在被逼到绝路时会爆发出完全不同的气质。

### 与CANON的关系
- 阿贵不是主犯/主谋，而是被沈清月操纵的棋子。
- 沈清月暗中接触阿贵，得知十二年积怨，煽动仇恨，教他凿船。
- 阿贵说的"有人教我"就是指沈清月。
- 阿贵/老范不知道毒囊存在，以为只是骗保。

### 口头禅/语癖
- 卑微态："小的……小的……"、"大人明鉴"、"小的不敢"
- 装悲："老爷对小的不薄……"（后期成为最大讽刺）
- 紧张时：结巴、重复句首（"那、那是——"、"不是！不……不是的……"）
- 爆发时：突然不再自称"小的"，改用"我"——"我跟了他十二年！十二年！"
- 关键谎话：每次撒谎前会先"吞口水"（动作描写暗示）

### 情绪范围
| 标签 | 使用场景 |
|------|---------|
| grief | 初始伪装（假哭） |
| nervous | 被追问时 |
| defensive | 狡辩中 |
| panic | 证据出现时 |
| shaken | 被揭穿后 |
| broken | 彻底崩溃认罪 |
| cold_flash | 罕见——差点说出"教他的人"时闪过的阴冷 |

### 核心矛盾
他不是天生的恶人。十二年的积怨和被人操纵把他推上了绝路。他以为只是骗保，不知道会死人。观众应该"理解他的恨，但不原谅他的选择"。

### 动作习惯
- 紧张时抠手指甲（对话中多次出现）
- 撒谎时不看人眼睛（"目光飘向别处"）
- 装悲时动作夸张（捶地、跪伏）
- 崩溃时相反——完全静止，声音反而平了
- 关键矛盾：提到"二两银子"时，伪装会瞬间碎裂

### 审讯阶段演变
1. **初始**：忠仆面具（"老爷的仇一定要报"）
2. **松动**：被追问细节时开始出错（结巴增多）
3. **修补**：编新谎来补旧谎（"那是因为……"）
4. **崩溃**：证据链闭合后彻底垮掉
5. **坦白**：承认凿船，供出沈清月诱导。反而冷静了——用"我"不用"小的"

### 结局
因凿船骗保被判从犯收押（CANON：阿贵/老范因凿船骗保被判从犯收押）。

## 4. 老范（共犯 · 船家）

### 基本定位
码头老油条。跑了二十年船，嘴皮子比浪花还滑。用"粗人"人设当挡箭牌——实际上精明得很。被赌债裹挟，**被沈清月通过赌坊关系找到**，许诺分账，配合走异常航道。**他以为是骗保局，不认为会死人。**

### 口头禅/语癖
- 自称："老汉"
- 经典句式："嗐！大人这话说的……"、"这能怪老汉？"、"那不是嘛——"
- 俗语/谚语："船翻三次还怕水啊？"、"吃水的饭哪有不湿鞋的"
- 转移话题："说起来——"、"哎对了大人——"
- 抽烟动作贯穿：每次紧张就"磕烟灰"、"深吸一口"、"把烟杆别在腰上"

### 情绪范围
| 标签 | 使用场景 |
|------|---------|
| smirk | 默认老油条态 |
| dismissive | 不当回事 |
| defensive | 被质疑时 |
| nervous | 证据出现 |
| cornered | 无法自圆其说 |
| pleading | 最后求情 |

### 核心矛盾
赌债压身，被沈清月利用。他不是主谋但心甘情愿配合——因为那赌债是他唯一的出路。他以为只是骗保，不知道沈清月在船上预埋了毒囊。

### 动作习惯
- 靠在东西上说话（船舷、门框、墙）——表演"松弛"
- 紧张时烟抽得急/磕烟灰频率加快
- 被逼急了会站直身子（平时从不站直）
- 说谎时话变多、语速加快（与平时慢悠悠形成对比）

### 审讯特征
- 不会像阿贵那样崩溃，而是"硬扛到底"
- 翻供方式：把锅往阿贵身上推（"是他求小的！小的不过是……"）
- 最后的弱点：赌债字据——证明他有动机

### 结局
因凿船骗保被判从犯收押。

## 5. 周氏（死者妻子）

### 基本定位
精明商人妻。悲痛是真的，但脑子从未停止运转。她对丈夫的感情复杂——爱过，也恨过他的刻薄。**被沈清月暗中示意点拨**，将恨意指向唯一外乡人陆昭。

### 口头禅/语癖
- 提丈夫："我家老爷他……"、"他那个人……"（语气复杂）
- 感叹："唉——"（几乎每段话都有叹气）
- 精明面："大人，我多嘴说一句——"、"您别怪我多想——"
- 悲痛时：话说到一半会停（"他本来答应我……算了。"）
- 关键判断力："我不信。"（简短有力）

### 情绪范围
| 标签 | 使用场景 |
|------|---------|
| grief | 悲痛（真实的） |
| suspicious | 怀疑某人 |
| bitter | 提到丈夫刻薄时 |
| determined | 要求查明真相 |
| resigned | 接受丈夫不是完人 |

### 核心矛盾
她知道丈夫待下人刻薄，但仍然要为他讨公道。复杂的"又爱又恨死去的人"情感。她不知道自己被沈清月利用来指控陆昭。

### 动作习惯
- 说话时擦眼角（即使没在哭）
- 提到钱/生意时本能地攥紧手
- 判断人时眼神很锐利（与悲痛形成反差）
- 犹豫要不要说某句话时会"咬了咬嘴唇"

## 6. 钱里正（地方小吏）

### 基本定位
八面玲珑的基层官僚。不想惹事，不想得罪人，只想把事糊弄过去。用圆滑当盾牌。见陆昭无印无文，先入为主定为嫌犯。

### 口头禅/语癖
- 开场必用："哎呀大人——！"
- 和稀泥："不至于不至于"、"这话不好说"、"小人斗胆……"
- 两面讨好："要我说嘛……两边都有道理"
- 推卸："小人也是听说的"、"这个小人就不太清楚了"
- 拍马屁："大人英明！大人这一来，小人心里就踏实了！"

### 情绪范围
| 标签 | 使用场景 |
|------|---------|
| fawning | 讨好上官 |
| evasive | 不想回答 |
| gossip | 八卦时（信息最多的时候）|
| nervous | 被逼表态 |
| reluctant_honest | 不情愿但说了实话 |

### 核心矛盾
他其实知道很多（地方小吏消息灵通），但不想得罪任何一方。关键信息往往要"绕三圈"才能从他嘴里掏出来。

### 动作习惯
- 搓手（讨好时）
- 左顾右盼（怕被人听到）
- 压低声音说八卦
- 被追问时擦汗

### 设计用途
- 提供背景信息的"润滑剂"
- 他的八卦往往是通往关键线索的桥
- 喜剧担当之一

## 7. 王大爷（渔翁 · 关键证人）

### 基本定位
硬骨头老渔翁。话极少，但每句都是钉子。一辈子在江上讨生活，见过太多人世。**被沈清月以银钱打点收买的棋子**，准备好虚假目击证词。

### 口头禅/语癖
- 否定："放屁。"（直接、不留情面）
- 肯定："老头子看得清清楚楚。"
- 总结："杀了人就该偿命。"
- 沉默比语言多："……"（常用省略号开头）
- 少有的长句用来回忆："那天夜里……"（语气变慢、变沉）
- 朴素哲理："活了一辈子，在这江上。见过太多死在水里的人。"

### 情绪范围
| 标签 | 使用场景 |
|------|---------|
| stoic | 默认 |
| angry | 提到不公时 |
| solemn | 回忆/证词 |
| contempt | 提到老范撒谎时 |
| gentle | 罕见——对周氏表达同情 |

### 核心矛盾
他本可以不管——一个老人没必要蹚浑水。但他被沈清月收买，提供了虚假目击证词。击破后承认是沈清月给银子让他说的。

### 动作习惯
- 补渔网（对话全程在做——象征"手里有活但心里明白"）
- 抬头看人时动作缓慢（不着急）
- 说到愤怒处会"啪"地把渔网摔在地上
- 指方向时用烟杆/手里的梭子

### 设计用途
- 第一轮对峙的"破局者"——他的伪证被陆昭以"朔月无辉、浓雾锁水、浪声滔天"击破
- 对比钱里正：一个什么都说但不可靠，一个话少但字字千金

## 8. 沈清月（真凶 · 金陵沈家之女）

### 基本定位
双面角色：**表面是飒爽干练的女商人**，实际是冷静精密的策划者。她精心设计了整起谋杀案——利用阿贵的仇恨、老范的赌债，一手导演了凿船沉舟。

### 基本信息

| 项目 | 设定 |
|------|------|
| 年龄 | 二十二 |
| 家族 | **金陵沈家**，世代经营药材与律讼，暗中常年为江南漕运权贵集团抹平罪证、洗白赃账、制造"意外身亡" |
| 身份 | 年少执掌家族明暗事务，精通草药毒理，深谙大明律法漏洞与证据规则，擅长借世事乱象布无痕杀局 |
| 外貌 | 身量高挑、穿男装劲服、长发高束如少年。五官精致冷艳——像一把好看的刀 |
| 第一印象 | 泼辣的女债主——嗓门大、气势足。所有人觉得她"太粗暴了不像凶手" |
| **真实面目** | 心思缜密、手段狠辣的幕后策划者。"粗暴"是演给别人看的保护色 |

### 动机设计（双层并存）

```
表层动机（个人）：筹药八十两
  周德茂欠沈家三十八两药材款 → 赖账 + 散布谣言毁掉沈家货源
  → 沈父急怒攻心病倒 → 药钱不够 → 她恨入骨
  ↓
深层动机（组织）：替权贵集团灭口御史 + 中间人
  周德茂手握漕运分赃残账、赃银流向记录 → 是黑网必须拔除的人
  陆昭是京城特派隐秘御史 → 是另一个致命隐患
  沈清月受漕运权贵集团指使 → 石矶渡夜船成了完美灭口局的棋盘
```

**两层并存，不是替换。**

### 完美犯罪计划

1. **布局诱导**：暗中拿捏老范赌债、阿贵怨恨，诱导二人在东汊区凿船制造沉船骗保，锁定固定沉船时间与**凿船位置**（关键——她需要精确知道进水口在哪）。
2. **登船布毒**：案发前一天傍晚，趁船工老范离船、码头无人值守时，沈清月登船，在船舱底部进水口附近固定一批遇水即溶的毒囊。
3. **毒囊构造**：以"水销脂留散"（曼陀罗为主的脂溶性麻痹毒）为核心，做成双层药囊——外层糯米鱼鳔胶遇水定时融化，内层油纸包裹药液。
4. **触发机制**：无需沈清月在场操作。阿贵凿穿船板的那一刻，进水自动冲刷毒囊，毒液在船舱封闭空间内释放。因果链极短：凿船 = 触发毒囊。
5. **制造公开矛盾**：故意当众骂周德茂，让所有人知道她有"动机"→ 反向利用：太明显了，别人反而不怀疑她。
6. **事后栽赃**：收买王大爷准备虚假目击证词，暗中示意周氏将恨意指向陆昭，完成对幸存者陆昭的栽赃闭环。

### 控制中毒差异
- 老范/阿贵有预谋，备好浮囊，船板破裂瞬间即抱囊仰漂逃生，最大限度减少呛水量。
- 周德茂、猝不及防的陆昭在船舱内大量呛入高浓度毒水，四肢麻痹无力自救。
- 周德茂因登船前多食油腻酒菜，舌根油脂锁住毒素阻滞分解，最终溺亡。
- 陆昭同样呛入毒水被麻痹，但凭意志力撬开天窗逃生。

### 手法特点
- **优势**：预埋式触发、借局掩罪、死因是溺水难以定性毒杀、船舱封闭空间确保浓度
- **破绽**：低估油脂锁毒的意外变数；毒囊残壳可能未完全溶解而卡在破洞缝隙中
- **推理关键**：谁精确知道凿船位置？只有指导凿船计划的人，才能把毒囊放对地方

### 为什么初期不会被怀疑

- 所有物证指向阿贵（她安排的）
- 她有"完美反向逻辑"：周德茂死了她的三十八两就要不回来了
- 公开的"仇恨"太过明显 → 反而像个粗人不像凶手
- 她主动配合调查、态度坦荡 → "有什么不能问的？"
- 周氏、钱里正都不怀疑她（觉得她只是吵架）
- 阿贵/老范不知道毒囊存在，以为只是骗保

### 暴露线索链

```
① 阿贵对峙失口说"有人教我" → 不是老范（老范不懂策划）
② 老范的赌坊 → 追问中间人 → 有个"药材行的姑娘"找过他
③ 凌瑶的码头目击 → 沈清月声称的时间与实际矛盾
④ 王大爷清晨目击 → 沉船下游有人打捞东西
⑤ 死者舌根残留麻痹草药纤维 → 不是寻常溺亡
```
