# GDD 05 — 游戏基本流程（七日节奏）

> 定义从开局到结局的完整流程

---

## 1. 整体节奏

```
序章 → D1-D2(破冰) → D3-D4(分叉) → D5-D6(博弈) → D7(决战) → 结局
```

| 阶段 | 天数 | 核心目标 | 预计时长 |
|------|------|----------|----------|
| 序章 | 开局 | 引入案件，教学引导 | ~10 min |
| 破冰期 | D1-D2 | 认识 NPC，收集基础线索 | ~50 min |
| 分叉期 | D3-D4 | 发现矛盾，锁定嫌疑范围 | ~50 min |
| 博弈期 | D5-D6 | 突破关键证词，与凶手博弈 | ~50 min |
| 决战 | D7 | 最终调查，提交指认 | ~25 min |
| 结局 | — | 结局演出 | ~5 min |

---

## 2. 序章

### 触发条件
新局开始

### 流程
1. **过场动画**: 侦探收到委托信，乘车前往小镇
2. **案发现场**: 到达时警方已封锁现场，获得初始信息
   - 受害者身份
   - 死亡方式（表面）
   - 发现时间和地点
3. **警长对话**: 教学关卡，引导玩家学习基本操作
   - 如何移动
   - 如何对话（选项制）
   - 如何收集证据
   - 如何使用笔记本
4. **初始物品**: 获得侦探工具包、笔记本、少量金币
5. **自由行动开始**: 序章结束，进入 D1 下午

### 序章获得的信息
- 受害者姓名和身份
- 初始物证 1-2 件
- 小镇地图（部分地点标记）
- 嫌疑人名单（警方提供）

---

## 3. D1-D2 破冰期

### 目标
- 与所有主要 NPC 建立初步接触
- 收集基础线索和证词
- 了解小镇人物关系网

### 典型行为
| 行为 | 目的 |
|------|------|
| 拜访各个 NPC | 了解基本信息，建立信任 |
| 探索开放场景 | 收集散落的初始证据 |
| 听取多方说法 | 建立事件基本时间线 |
| 闲聊/送礼 | 为后续深入对话铺垫信任度 |

### 特殊事件
- **D1 黄昏**: 镇上举行受害者追悼会，所有 NPC 聚集，可观察互动
- **D2 晚间**: 某 NPC 深夜外出，玩家可选择跟踪

### 凶手行为
- 警觉度低，凶手表现正常
- 不会主动破坏证据

---

## 4. D3-D4 分叉期

### 目标
- 发现至少 1-2 个关键矛盾
- 将嫌疑范围缩小到 2-3 人
- 获取深层线索

### 典型行为
| 行为 | 目的 |
|------|------|
| 质问有疑点的 NPC | 追问矛盾细节 |
| 对比证词差异 | 在笔记本中标记矛盾 |
| 搜索私人区域 | 寻找隐藏证据 |
| 跟踪可疑 NPC | 发现异常行为 |

### 分叉点
此阶段玩家的调查方向将**分叉**，不同选择导致不同信息获取路径：

```
           ┌─ 路线A: 重点追查 NPC-X 的不在场证明
玩家选择 ──┤
           ├─ 路线B: 重点追查物证链
           │
           └─ 路线C: 重点挖掘人物关系
```

### 凶手行为（警觉度 30%+）
- 开始销毁次要证据
- 某些证据搜索窗口关闭

---

## 5. D5-D6 博弈期

### 目标
- 突破关键证人的核心证词
- 找到决定性证据
- 应对凶手的反制行动

### 典型行为
| 行为 | 目的 |
|------|------|
| 出示证据施压 | 逼迫嫌疑人松口 |
| 隐秘行动 | 最后机会获取隐藏证据 |
| 安抚关键证人 | 修复可能破裂的信任 |
| 推演梳理 | 在笔记本中整理完整推理链 |

### 凶手行为（警觉度 60%+）
- 制造假线索（误导性物证出现）
- 收买某 NPC 改变证词
- 触发推理陷阱场景

### 推理陷阱
当凶手警觉度达到 80%，触发推理陷阱事件：
1. **场景描述**: 出现高度可疑的新「证据」
2. **玩家选择**: 
   - 采信 → 被误导，浪费大量时间
   - 识破 → 获得反制线索，凶手警觉度不再上升
3. **识破条件**: 玩家在笔记本中已建立足够完善的推理链

---

## 6. D7 决战

### 特殊规则
- **所有对话次数 +5**（最后的机会）
- **笔记本指认页解锁正式提交**
- **凶手行为达到最激烈**

### 流程

```
D7 早晨 → 最后调查 → 黄昏前必须提交指认 → 结局判定
```

| 时段 | 可做事项 |
|------|----------|
| 早晨 | 最后的证据搜集、最后的对话 |
| 白天 | 整理推理、补全漏洞 |
| 黄昏 | **提交指认（截止时间）** |
| 夜晚 | 结局演出 |

### 未提交指认
如果 D7 黄昏前未提交指认 → 自动进入「未解之谜」结局

---

## 7. 结局分支

| 结局 | 条件 | 描述 |
|------|------|------|
| **完美破案** | 正确指认凶手 + 动机 + 手法 + 3 件关键证据全部正确 | 凶手认罪，真相大白 |
| **基本破案** | 正确指认凶手，但动机/手法/证据有部分错误 | 凶手被捕但翻供，部分真相仍成谜 |
| **冤假错案** | 错误指认凶手 | 无辜者被捕，真凶逍遥法外 |
| **未解之谜** | D7 前未提交指认 / 凶手警觉度达 100% 未识破 | 案件悬而未决，侦探离开小镇 |
| **侦探陨落** | 认知负荷达到 100 昏迷超过 2 次 | 侦探精神崩溃，被送离小镇 |

### 结局评分

即使同一结局类型，评分也会有差异：

| 评分维度 | 权重 |
|----------|------|
| 指认正确性 | 40% |
| 收集线索完整度 | 20% |
| 发现矛盾数 | 15% |
| 剩余时间 | 10% |
| 认知负荷控制 | 10% |
| 隐秘行动成功率 | 5% |

## 8. 一天内时间节奏

```
┌────────┬────────┬────────┬────────┐
│  早晨  │  白天  │  黄昏  │  夜晚  │
│ 6-9    │ 9-17   │ 17-20  │ 20-6   │
│ ~5min  │ ~12min │ ~4min  │ ~4min  │
└────────┴────────┴────────┴────────┘
         ← 1天 ≈ 25min →
```

| 时段 | 现实时长 | 特点 |
|------|----------|------|
| 早晨 (6:00-9:00) | ~5 min | 商店未开，可在旅馆/户外行动 |
| 白天 (9:00-17:00) | ~12 min | 主要活动时段，所有地点开放 |
| 黄昏 (17:00-20:00) | ~4 min | 部分商店关闭，NPC 行为变化 |
| 夜晚 (20:00-6:00) | ~4 min | 大部分地点关闭，隐秘行动时段 |

### 时段对游戏的影响

| 影响 | 说明 |
|------|------|
| NPC 位置变化 | NPC 按日程在不同地点出现 |
| 场景可达性 | 部分场景仅在特定时段开放 |
| 认知负荷衰减 | 夜间行动认知负荷消耗 ×2 |
| 隐秘行动 | 夜间成功率更高但风险更大 |
| 特殊事件 | 特定时段触发特定事件 |

---

## 9. 重玩性保障

| 机制 | 说明 |
|------|------|
| 随机剧本 | 每局生成不同案件 |
| 分叉路线 | D3-D4 的调查方向影响后续信息获取 |
| 隐藏线索 | 部分线索有多种获取路径，一局难以全部发现 |
| NPC 反应差异 | 不同信任度/施压度下 NPC 给出不同信息 |
| 速通挑战 | 完美破案后解锁速通模式 |
| 成就系统 | 特殊行为触发隐藏成就 |
