# 序章完整案件升级排期

归档日期：2026-06-03

目标：不把它当“教学序章”，而是按一个完整《逆转裁判》式短案来提升。重点看台词、节奏、逻辑、物证链和玩法，不包含语音制作。

## 制作原则

1. 物证必须保持物证身份。浮囊、破洞、官印木匣、赌债字据、遣散字据等关键证据不能合并成“预谋逃生”“幕后操控”这类抽象事实。
2. 可并行存在三层信息：物证、证言记录、推理札记。推理札记负责解释，不能替代物证本身。
3. 玩家每推进一段，都要经历“看见异常、追问人、整理矛盾、用证据击破”的小循环。
4. 沈清月终局要保留双重反转：玩家赢得事实真相，但在法理层面暂时输掉定罪。
5. 船舱阶段是第一段可玩侦探循环，不只是开场氛围展示。

## P0：可玩闭环与证据链稳定

预计 2-3 个制作日。优先级最高。

### P0-1 船舱阶段改造

目标：让玩家在船沉前主动形成疑点，而不是被剧情直接带走。

- 将船舱目标从“为什么非走东汊”改成“确认这趟夜船哪里不对”，降低剧透感。
- 舱内四个热点保留为物理观察：官印木匣、行程简记、雨夜小窗、异常湿斗篷。
- 舱内线索反向解锁 NPC 追问：
  - 行程简记解锁对老范/周德茂的路线追问。
  - 异常湿斗篷解锁对阿贵的舱门/走动追问。
  - 官印木匣强化后续官印丢失的打击。
- 三人都聊过后，不应立刻自动入睡。先触发“整理疑点”事件，由玩家选择最不对劲的一点。
- 选择结果写入推理札记或 flag，用于后续回忆文本差异，不直接生成抽象物证。
- 在入睡前加入船身异动、门外低语、灯火晃动等升级节拍。

### P0-2 证据分类整理

目标：证据列表更像法庭游戏的武器库。

- 保持浮囊、船底破洞、赌债字据、遣散字据、官印相关物件为独立物证。
- 将“老范时间矛盾”等证言性质内容从 evidence 类型改为 testimony/record 或 clue，避免和物件混在一起。
- 为每个关键物证补“获得地点、可举证场景、后续更新文案”。
- 浮囊不做成“预谋逃生”结论。浮囊先是阿贵包袱里的牛皮浮囊，后续通过阿贵供词、缝线细节、沈清月联系改变意义。

### P0-3 全案三段式节奏

目标：完整案子的推进要有三次胜利和一次失败。

- 第一段：自证清白。击破“陆昭杀人”的伪证。
- 第二段：拆穿意外和共犯。用航道、破洞、浮囊、赌债、遣散字据锁定阿贵/老范。
- 第三段：追到沈清月。用货银、打捞时间线、中间人、毒囊残壳等物证逼近幕后。
- 终局：沈清月用法理或证物有效性翻盘，留下下一章官印暗线。

## P1：逆转感与角色攻防

预计 3-5 个制作日。

- 王大爷：伪证型，证词要明显但不粗糙。玩家用天气、距离、逃生时间拆穿。
- 老范：滑头型，先推给暗礁，再被路线常识和船底痕迹逼退。
- 阿贵：情绪崩溃型，浮囊、遣散字据、干湿细节依次压垮。
- 沈清月：逻辑反击型，会把每个物证重新解释成“不足以定罪”。
- 为核心错误举证补专属反应，尤其浮囊、破洞、赌债、官印相关。
- 对话做压缩和回环控制，减少重复“继续询问”后的冷启动感。

## P2：完整案件质感

预计 3-6 个制作日。

- 钱里正强化为临时裁判位，负责施压、确认规则、给出“证据不足”的现实边界。
- 结尾不做多结局评价层，改为固定收束并过渡到下一章节。
- 对探索重复点击做阶段化文案：第一次观察、重点复查、剧情变化后的再解释。此项暂缓。
- 补充关键场景的伴随提示，提示只指出“该看哪里”，不直接给答案。

## 探索玩法改进方案

### 当前问题

- 热点容易变成清单点击，线索获得后对问话影响不足。
- 一些结论性 clue 承担了太多推理，削弱了物证的存在感。
- 阶段结束条件偏系统化，玩家缺少“我想明白了”的主动收束。

### 目标结构

每个探索阶段按以下节奏设计：

1. 初看：发现异常物件或环境不协调。
2. 追问：用初看线索解锁 NPC 额外选项。
3. 复查：同一物件在新信息后更新描述。
4. 整理案情：用选择题或小推理确认玩家理解。
5. 推进：只在玩家完成整理后进入下一阶段。

### 船舱阶段样板

- 地点数量保持少而集中：自己的舱室、阿贵舱角、船尾甲板、周老板货舱。
- 船舱目标是“哪里不对劲”，不是提前点明东汊答案。
- 关键物证和疑点：
  - 官印木匣：身份保障，后续丢失造成危机。
  - 行程简记：路线和推荐人疑点。
  - 雨夜小窗：天气与夜渡风险。
  - 异常湿斗篷：有人进出或动过舱门的暗示。
- 小结题建议：
  - 最值得警惕的是路线、天气、舱门湿痕、还是周德茂提到的朋友。
  - 任何选项都可继续，但最佳选项给后续回忆或问话奖励。

## 验收标准

- 玩家在船沉前至少完成一次“观察物件 -> 解锁追问 -> 整理疑点”的闭环。
- 关键证据栏中没有把浮囊、破洞、官印等物件抽象合并。
- 阿贵/老范/沈清月三段攻防有不同防御风格。
- 每次案情推进都能回答三个问题：我刚发现了什么，它反驳了谁，它让我下一步去哪里。
- 表格校验通过，运行时从 `data/case_tables/prologue_ferry` 可编译。

## 当前执行顺序

4. 最后做 P0-3 中后段对峙节奏和沈清月终局强化。
