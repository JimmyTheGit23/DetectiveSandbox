# 逆转裁判式交互体验升级方案

归档日期：2026-05-21

## 1. 总体目标

当前游戏的问题不是内容不足，而是玩家的主动推理参与度不足。现有流程偏向：

> 点地点 → 点选项 → 获得证据 → 对话直接提交证据 → NPC 解释或认罪

目标应升级为：

> 调查阶段发现疑点、记录证词、复核现场；对峙阶段逐句检视证词，抓住破绽，出示证据击破谎言。

核心体验目标：

1. 玩家主动发现矛盾，而不是被选项提示答案。
2. 普通对话不再直接出示证据击破嫌疑人。
3. NPC 有防守、狡辩、改口和崩溃过程。
4. 对峙阶段像法庭攻防，而不是简单证据选择题。
5. 探索阶段像现场勘查，而不是点击领取线索。
6. 助手角色只提示异常，不直接给答案。
7. 视觉、音效、UI 反馈强化“发现”“记录”“击破”的爽感。

---

## 2. 普通调查阶段改造方向

普通调查阶段的职责应从“给答案”改为“制造问题”。

调查阶段不应直接让嫌疑人认罪，而应让玩家积累之后对峙要用的“弹药”。

### 2.1 调查阶段应产出五类信息

| 类型 | 说明 |
|---|---|
| 物证 | 可在对峙中出示的实物证据 |
| 证词 | NPC 说过的关键句子 |
| 疑点 | 尚未形成证据的异常 |
| 时间线 | 案发前后事件顺序 |
| 人物关系 | 动机、关系、利益冲突 |

### 2.2 台词原则

普通调查阶段应遵循：

- 给事实，不给结论。
- 给异常，不给答案。
- 给多种解释，让玩家排除。
- 助手只提出问题，不直接推理。

不推荐：

> 这肯定是人为的！

推荐：

> 这处裂口边缘太齐了，不像江石撞出来的。可若不是撞的，又是谁会在船底动手脚？

## 3. 探索行为表现改造

探索行为不应只是“搜索点弹文本”，而应细分为更有动作感的调查行为。

### 3.1 探索行为分类

| 行为 | 作用 | 表现重点 |
|---|---|---|
| 观察 | 看表面异常 | 镜头推进、热点发光、发现疑点 |
| 翻找 | 主动搜查物件 | 翻动物件音效、可能无果、可能发现隐藏层 |
| 比对 | 拿已知信息对照现场 | 左右证据对照、墨圈标记、复核结论 |
| 复查 | 第二次调查出现新发现 | 条件满足后热点重新发光 |
| 求证 / 鉴定 | 找第三方确认客观事实 | 证据描述更新，不击破嫌疑人 |
| 现场复原 | 把碎片拼成过程 | 选择推理路径，答错给非致命反馈 |

### 3.2 探索反馈分级

| 等级 | 反馈 |
|---|---|
| 普通观察 | 无异常，仅补充环境信息 |
| 可疑细节 | 发现轻微异常 |
| 疑点记录 | 记录可疑点 |
| 证词记录 | 写入笔录 |
| 正式证据 | 获得可呈堂物证 |

### 3.3 热点状态建议

| 状态 | 表现 |
|---|---|
| 未调查 | 微弱呼吸光 |
| 已调查 | 变暗或打勾 |
| 有新条件可复查 | 金色闪烁 |
| 暂不可调查 | 灰色，点击给理由 |
| 关键异常 | 悬停时轻微震动 / 墨圈 |
| 已确认成证据 | 显示小证物标记 |

### 3.4 关键发现表现

- 获得物证：证物卡放大、盖章、落入笔记本。
- 记录证词：卷宗纸条展开，关键句被墨线圈住。
- 发现疑点：屏幕出现红色墨圈或“此处有疑”。
- 更新时间线：时间轴新增一格。
- 关键现场：背景暗化、局部放大、逐个圈注细节。

## 4. 对话行为表现改造

普通对话应从“问答菜单”升级为“审讯前奏”。

### 4.1 对话行为分类

| 行为 | 作用 |
|---|---|
| 问话 | 获取基础信息 |
| 追问 | 深挖细节 |
| 观察 | 看 NPC 反应 |
| 试探 | 抛出模糊信息观察反应 |
| 沉默 | 让 NPC 自行补话 |
| 记录 | 将关键句写入笔录 |

### 4.2 对话表现原则

- 对话选项不再出现“出示证据击破嫌疑人”。
- 可以保留向第三方“求证 / 鉴定”的证据展示。
- 嫌疑人被追问时应狡辩、转移、改口，而不是认罪。
- NPC 应有状态变化：正常、警觉、紧张、防备、恼怒、露怯。
- 关键台词应触发“记录证词”演出。

### 4.3 选项类型化

| 类型 | 前缀 | 用途 |
|---|---|---|
| 普通问话 | 问 | 获取基础信息 |
| 追问 | 追问 | 深挖细节 |
| 观察 | 观察 | 看反应 |
| 试探 | 试探 | 诱导破绽 |
| 整理 | 记录 | 写入笔录 |
| 告辞 | 离开 | 结束对话 |

---

## 5. 探索与对话的闭环

探索和对话不能割裂，应形成循环：

> 现场观察 → 发现疑点 → 询问 NPC → 记录证词 → 回到现场复查 → 获得物证 → 找第三方求证 → 形成对峙攻击点

以序章案为例：

1. 搜残船，发现船底破损异常。
2. 问老范，他说是撞礁。
3. 回残船复查，发现钉眼和断面异常。
4. 问王大爷，得知老范熟悉航道。
5. 再问老范，他改口或辩解。
6. 记录老范说法矛盾。
7. 对峙时用船底破洞击破“撞礁说”。

---

## 6. 对峙阶段改造方向

当前对峙不应继续停留在：

> 显示一句谎言 → 玩家选证据 → 判断对错

应升级为：

> 嫌疑人陈述一组证词 → 玩家逐句切换 → 追问 → 选择某句出示证据 → 正确击破推进，错误扣信心。

### 6.1 对峙核心流程

1. 嫌疑人给出一组证词。
2. 玩家切换上一句 / 下一句。
3. 玩家可追问某一句。
4. 玩家选择当前句并出示证据。
5. 判断当前句 + 证据是否匹配。
6. 正确则播放击破演出。
7. 错误则扣信心并被 NPC 反击。
8. 多轮击破后进入结局。

### 6.2 推荐数据结构

```json
{
  "id": "round_1",
  "title": "阿贵的生还经过",
  "statements": [
    {
      "id": "stmt_1",
      "text": "那夜雨大，江面上什么都看不清。"
    },
    {
      "id": "stmt_2",
      "text": "船翻以后，我抱着一块木板才侥幸活下来。"
    },
    {
      "id": "stmt_3",
      "text": "那种事来得突然，谁也不可能提前准备。"
    }
  ],
  "solution": {
    "statement_id": "stmt_3",
    "evidence": "evidence_float_bladder"
  }
}
```

## 7. 交互博弈设计

NPC 应从“信息盒子”变成“对手”。每个关键 NPC 应有心理防线：

| 防线层级 | 表现 |
|---|---|
| 第一层：敷衍 | “我不清楚”“当时太乱” |
| 第二层：转移 | “你该去问别人” |
| 第三层：反咬 | “大人凭什么怀疑我？” |
| 第四层：露怯 | 语气变乱、改口、细节不一致 |
| 第五层：崩溃 | 被连续证据击破后失控 |

### 7.1 错误反馈类型

| 错误类型 | 反馈 |
|---|---|
| 证据完全无关 | NPC 嘲讽，扣 1 |
| 证据相关但句子选错 | 提示“这句话还没矛盾”，扣 1 |
| 证据接近正确 | 少扣或不给直白提示 |
| 关键证据但时机太早 | NPC 暂时圆过去，稍后可再次使用 |

### 7.2 多段击破

对峙不应总是“一证到底”，而应支持：

1. 先指出矛盾。
2. NPC 狡辩。
3. 玩家追加证据。
4. NPC 改口。
5. 玩家指出新矛盾。
6. 才进入下一轮。

---

## 8. 剧本节奏改造方向

每个案件建议形成五幕结构：

1. 表面真相。
2. 第一个异常。
3. 错误嫌疑人 / 红鲱鱼。
4. 公堂对峙。
5. 最终反转。

好的误导不是废线索，而是：

> 它确实解释一部分事实，但解释不了全部事实。

例如序章案中老范可以高度可疑：他有赌债、熟悉航道、能动船、也活了下来。但他解释不了阿贵为什么有浮囊、为什么被遣散、为什么说不清生还过程。最终结论可变为“老范是共犯，阿贵是主谋”。

## 9. 视觉和演出升级方向

### 9.1 探索阶段

- 热点呼吸光。
- 可复查热点闪烁。
- 获得证据时证物卡弹出。
- 记录证词时卷宗纸条写入。
- 发现疑点时墨圈标记。
- 时间线更新时补上一格。

### 9.2 对话阶段

- 追问时 NPC 轻微抖动。
- 观察反应时镜头或立绘轻微推进。
- 试探时 BGM 降低。
- 关键证词记录时暂停半秒并弹出纸条。
- NPC 根据压力切换正常、警觉、紧张、防备、恼怒、露怯状态。

### 9.3 对峙阶段

- 专属公堂构图。
- 嫌疑人多状态立绘。
- 证据卡飞入。
- “异议！”特效分普通击破、关键击破、最终击破三档。
- BGM 根据局势切换。

## 10. 序章案优先改造建议

序章案适合做成完整教学样板。

### 10.1 普通调查阶段需要删除

- 阿贵普通对话中的“出示遣散字据”。
- 阿贵普通对话中的“出示浮囊”。
- 阿贵普通自白。
- 老范普通对话中的“出示船底破洞”。
- 老范普通对话中的“出示赌债字据”。
- 老范提前供出阿贵的台词。

### 10.2 替换为

- 问话。
- 追问。
- 观察。
- 记录证词。
- 发现疑点。
- 复查现场。
- 第三方求证。

### 10.3 对峙阶段三轮

| 轮次 | 主题 | 破绽 | 证据 |
|---|---|---|---|
| 第一轮 | 阿贵如何生还 | 他说无人能提前准备 | 牛皮浮囊 |
| 第二轮 | 沉船原因 | 他说船是撞礁 | 船底破洞 |
| 第三轮 | 杀人动机 | 他说老爷待他不薄 | 遣散字据 / 赌债字据 |

## 11. GM 指令需求

设置面板已有 GM 区：

- 解锁全部案件

建议新增：

- GM：直接进入本案对峙

行为：

1. 解锁本案所有阶段。
2. 解锁指证 / 对峙入口。
3. 自动补齐本案关键证据。
4. 直接打开 `ConfrontationPanel`。
5. 若本案没有对峙数据，则提示“本案尚未配置对峙”。

---

## 12. 实施优先级

### P0：核心交互

1. `ConfrontationPanel` 支持多句证词。
2. 支持上一句 / 下一句。
3. 支持追问。
4. 支持当前句出示证据。
5. 错误扣信心，正确推进。
6. 修复嫌疑人选择被忽略的问题。

### P1：序章案逆转化

1. 删除普通对话中的直接证据提交。
2. 阿贵和老范不再普通对话自白。
3. 重写序章案对峙数据。
4. 降低凌瑶提示直白度。
5. 增加证词 / 疑点记录。

### P2：探索阶段表现

1. 搜索结果类型化。
2. 热点支持复查状态。
3. 关键发现卡片化。
4. 对话选项类型化。
5. NPC 情绪状态表现。

### P3：演出增强

1. 公堂对峙专属布局。
2. 多状态立绘。
3. BGM 状态切换。
4. 证据飞入动画。
5. 最终击破演出。

---

## 13. 最终体验目标

玩家理想体验应是：

> 我在调查中记录了阿贵说自己抱木板活下来。后来在他的包袱里发现牛皮浮囊。普通对话中他一直狡辩，不肯认。到公堂上，他说“没人能提前准备”。我抓住这句话，出示浮囊。BGM 停止，异议切入，阿贵动摇。他改口推给老范。我继续用船底破洞、遣散字据和赌债字据一层层击破。最后他才崩溃。

这才是目标中的逆转式交互体验。
