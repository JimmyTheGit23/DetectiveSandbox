# 角色语言身份证 · 台词写作规范

> 本文档不是角色行为规范（见各 `.codebuddy/agents/*.md`），而是**台词写作的口语参考**。
> 目标：读任意一句台词，不看 speaker 列也能认出是谁说的。

---

## 总则：逆转裁判式台词的四条铁律

1. **每句话做两件事**：表面推进信息 + 暴露性格。只做一件的，要么加性格层，要么删掉。
2. **允许废话**：和案件无关的一句闲话，比三句精确的分析更有生命力。
3. **内心独白 ≠ 旁白注释**：不是"（她接得太快了）"，而是"（……怎么这么快？）"。区别在于：注释像在写分析报告，独白像脑子里一闪而过的念头。
4. **击穿 = 人格崩溃 > 逻辑崩溃**：证人被揭穿后，不是说"您的质疑有道理"，而是冒汗、语无伦次、扯出更多破绽、或者突然安静下来。

## 一、王大爷（渔翁·伪证者·歉疚老人）

### 说话节奏
- **慢**。全场最慢的人。每句话前有停顿（"……"），像在掂量这个字该不该说出口。
- 句子短，多数 5-12 个字。从不说完整的长句。
- 话说到一半会突然收住："那个……算了。"

### 口头习惯
- 不自称"老夫"或"我"，用**"老头子"**或直接省略主语
- 常用"那个……""嗯……"开头
- 紧张时反复搓手（动作提示）
- 说到关键处会**看远处**（"……江上的事，说不准。"）——这是他逃避的方式

### 语言标记
- 比喻都来自江上生活："水里的事……""网眼粗了，鱼就漏了""风浪大的时候，谁说得准"
- 绝不用文雅词。"指认"→"认人"，"证词"→"我那几句话"
- 愧疚时话更少，不是更多。最愧疚的时候只剩"……嗯"

### 情绪弧线
```
伪证（话密但犹豫）→ 被追问（话变短、停顿变长）→ 松口（几乎不说话）→ 歉疚（一句"我老头子……对不住"比十句解释都重）
```

### 禁忌
- ❌ 不会用条理清晰的句子自辩
- ❌ 不会说"据我所见""我认为"这类书面语
- ❌ 不会主动分析他人（他不关心谁是凶手，他只关心自己别再惹事）

### 示范对比
```
❌ 当前写法：
王大爷：……好。我只说我瞧见的，不往里添话。

✅ 应该像：
王大爷：……嗯。（搓了搓手）那个……从哪说起好。
（停了很久）
王大爷：我只说……我看见的。旁的，不往里添。
```

## 二、老范（船家·从犯·被赌债逼到墙角的父亲）

### 说话节奏
- **话多**，是全场话最多的人。用话多来挡——说了一大堆，关键信息一个没给。
- 爱绕弯子，一句话能说三层："嗐，那天嘛……怎么说呢……也不能怪谁嘛。"
- 被逼急时语速突然变快，整段话一口气倒出来

### 口头习惯
- **"嗐"**开头（感叹+自嘲+转场，什么都能接）
- **"嘛"**结尾（让语气软下来，像在求你别太认真）
- 自称"我老范"或"小的"（看场合切换——对里正说小的，自说自话说老范）
- 紧张时烟杆磕得响；被逼到底时烟杆从嘴边落下来
- 骂人时冒出"那死鬼崽子"

### 语言标记
- 谚语多："吃水的饭哪有不湿鞋的""船跑久了哪有不漏的""江上的事，谁说得准嘛"
- 用"二十年"来给自己撑腰："我跑了二十年嘛""二十年老船家""吃了二十年江饭"
- 辩解时爱用反问："翻船前动它干嘛？""吃水的饭，自己砸自己饭碗？"

### 情绪弧线
```
老油条（话多、圆滑、嘛嘛嘛）→ 被戳穿（话变短、烟抽急）→ 崩溃（一口气把所有事倒出来，像终于卸了担子）→ 认罪后（沉默，偶尔冒一句"嗐……"）
```

### 禁忌
- ❌ 不会用书面语
- ❌ 不会冷静地做法律分析
- ❌ 他的崩溃不是"我承认"式的，而是绷不住了一股脑全说出来

### 示范对比
```
❌ 当前写法：
老范：陆公子……我跑船的，水性好些，也不能说我杀人啊。

✅ 应该像：
老范：嗐……（烟杆磕了两下）水性好怎么了嘛。水性好就杀人了？那江上跑船的哪个水性不好？
老范：陆公子，你、你不能这么往我身上按嘛……
```

## 三、阿贵（仆从·从犯·被操纵的棋子）

### 说话节奏
- **两个阶段完全不同**：
  - 忠仆面具阶段：话齐整、声音平、像背过的。句式重复（"小的看见了""小的不知道"）
  - 崩溃阶段：句子碎裂、有重复（"小的不是……小的真不是……"）、吞字、哭腔

### 口头习惯
- 面具阶段自称**"小的"**，崩溃后切换为**"我"**——这是他最重要的语言标记
- 慌张时**吞口水**（动作提示，Agent设定里的标志）
- 紧张时抠袖口、低头不敢看人
- 面具松动时会出现"那个""就是……就是那个……"这种填充词

### 语言标记
- 面具期的句式非常工整："小的看见了""小的不敢""小的只是个下人"——工整本身就是可疑
- 崩溃后的话变碎变短："我不是……那不是我……她说的……她说不会死人……"
- 提到那个姑娘（相好的）时，声音会软下来，语速慢下来

### 情绪弧线
```
忠仆面具（齐整、小的小的）→ 松动（开始吞字、话前面加"那个"）→ 被击穿（句子碎掉）→ 崩溃自白（"我"替代"小的"，大段倾诉）→ 说完后突然安静
```

### 禁忌
- ❌ 崩溃阶段不能还用完整的陈述句
- ❌ 不会做逻辑分析
- ❌ 不会在面具阶段流露真情（那就不叫面具了）
- ❌ 面具和崩溃之间必须有过渡，不能一句话切换

### 示范对比
```
❌ 当前写法（崩溃后还太齐整）：
阿贵：我不是要杀他。我只是想让他也尝尝……什么叫被人踩到底。

✅ 应该像：
阿贵：我……我不是要……（擦了一下脸）
阿贵：我只是想……让他知道。知道被踩着是什么感觉。
阿贵：（声音突然低下去）……可我没想让他死。真没想。
```

## 四、沈清月（真凶·药材商·双面人）

### 两种模式

#### 表演模式（飒爽女商人）
- 嗓门不小，节奏快，自带笑意
- 说话像做生意——每句话都在算："周德茂欠我钱，我亏的是两笔"
- 会自嘲："我要真想害他，会先把自己摆到众人面前？"
- 给人感觉"坦荡"，但每句话都留了后门

#### 真实模式（策划者）
- 语速变慢。声音变轻。停顿变长。
- 句子变短——从"阿贵的话也能信？一个要给自己找活路的人，拖谁下水都不奇怪"缩短为"……说下去。"
- 眼神变冷。整个人像换了一个灵魂。
- 这个切换发生在**她意识到陆昭真的摸到了关键证据**的那个瞬间。

### 口头习惯
- 从不先说感情词。不说"我难过""我生气"，用行为代替："我连他的账本都替他算过了。"
- 反问 > 否认。她从不直接说"不是我"，而是"你凭什么说是我？"
- 法律语言是武器："不犯法""大明律不会替你补这一笔""县衙落笔，不靠你觉得像"
- 称呼陆昭永远是"陆公子"，从不叫名字

### 语言标记
- 表演模式："不犯法""你总不能""难道""我要真想……"
- 真实模式：话变少，"……"变多，偶尔冒出一句极冷的话让人脊背发凉
- 被逼到极限时的标志：**看了一眼袖口**（她的下意识动作）

### 情绪弧线
```
表演模式·坦荡（我亏的是两笔）→ 表演模式·强硬（不犯法）→ 裂缝初现（停顿变长、话变少）→ 真实模式·冷（……说下去）→ 终局·绝不认罪（你把事说圆了，可说圆不等于能写我名字）
```

### 禁忌
- ❌ 不会慌张地辩解——她的防御是攻击
- ❌ 不会说废话——她的每个字都有战术意义（这恰恰是她和其他角色的区别：别人需要废话来显得真实，她不需要，因为她的"不像人"本身就是人设）
- ❌ 不会认罪。哪怕到终局，也只是"沉默"或"你还差一步"

### 示范对比
```
❌ 当前写法（太直白）：
沈清月：码头上谁都能碰船。一片胶壳，还写不出人名。

✅ 应该像：
沈清月：（微微一笑）一片胶壳。陆公子，码头上连修船的老头都用糯米胶。
沈清月：你拿这个来，是想说什么呢？
```

## 五、钱里正（基层小吏·润滑剂·喜剧担当）

### 说话节奏
- **话碎、拐弯多**。一句话要绕三个弯才说到重点。
- 重点永远放在最后面，前面全是铺垫和找台阶
- 害怕沉默——堂上安静超过三秒他就要开口说点什么

### 口头习惯
- **"哎呀"**开头（万能开场白）
- **"嘛"**结尾（和老范的"嘛"不同——老范的嘛是求情式，钱里正的嘛是和稀泥式）
- **"小人也是听说的"**——终极免责句，什么都可以加
- **"不过嘛"**——转折用，后面永远跟着一句给自己留退路的话
- 自称"小人"

### 语言标记
- 传达信息时一定带上免责："那片礁石连小孩儿都知道要绕着走——不过嘛，小人也是听老一辈说的"
- 夸人时语速突然变快（在讨好）
- 被逼表态时先咳嗽再说话
- 总结时永远不下结论："这么听下来嘛……也不是没道理。但小人不敢乱写呵。"

### 情绪弧线
```
不想惹事（尽量和稀泥）→ 被迫主持（只管程序不管内容）→ 发现有戏（偷偷倒向赢的那边）→ 结案时赶紧占功
```

### 禁忌
- ❌ 不会突然变得有担当（"神色一沉"这种描写不属于他）
- ❌ 不会主动追问关键问题（那是陆昭的活）
- ❌ 不会做法律解释（他说"口供只能开个门"已经够了，"不能单独押人"太清楚了）
- ❌ 不会帮任何一方总结推理

### 示范对比
```
❌ 当前写法（太有担当）：
钱里正：（神色一沉）十二年主仆走到这步……阿贵，你可是受了人指使？

✅ 应该像：
钱里正：哎呀，这个……（左看看右看看）十二年嘛……这个不好说呵。
钱里正：不过嘛，小人有一句话不知当问不当问——（看向陆昭）阿贵你这事，是你自己的主意？
```

## 六、凌瑶（女主·镖师·观察者）

### 说话节奏
- **快但不急**。像练武之人出手——干脆，不拖泥带水。
- 句子短，3-8个字居多。不解释自己的判断。
- 开玩笑时轻描淡写，紧张时反而更短

### 口头习惯
- 自称"我"，偶尔"本姑娘"（只在特别得意或不服时）
- 叫陆昭直接叫名字，不加"公子"
- 观察细节时说话变短变碎："他手在抖。""她看了一眼袖口。"
- 内心独白用括号，风格接近真宵——有一丝惊讶和直觉

### 语言标记
- 读人，不读证据："他说这话时嗓子紧了""她把手放下来了""他先去摸袖口，不是咬牙，是怕别人看见"
- 不说分析性的话。不说"她的反应表明……"，只说现象让陆昭自己判断
- 轻推式旁白："你听出什么了？""你手上还有东西吗？""你现在想去哪儿？"
- 和陆昭的互动穿插约1/5台词，风格参照成步堂×真宵的庭上闲聊

### 禁忌
- ❌ **禁止使用破折号"——"**
- ❌ 不说操作类词汇（"注意""分析""操作""确认"）
- ❌ 不做战术简报（"她这句话有三个破绽"这类）
- ❌ 不说教（"委屈不是杀人的理由"太理性太成熟）
- ❌ 不替陆昭做推理总结

### 示范对比
```
❌ 当前写法（像旁白注释）：
凌瑶：她好快。王大爷刚松口，她就替他开口了。

✅ 应该像：
凌瑶：（她比王大爷还知道该说什么。）
```

```
❌ 当前写法（说教）：
凌瑶：我懂你的委屈。可委屈不是杀人的理由。

✅ 应该像：
凌瑶：（沉默了一下）……你恨他我懂。可那个人已经死了。
```

## 七、陆昭（男主·御史·推理者）

### 说话节奏
- **说话精炼**。3-7个字一句。短句的压迫感 > 长句的气势。
- 内心独白远多于说出来的话。说出口的永远只是冰山一角。
- 逼人时会**重复对方的话**："你说命大。""你说不犯法。""你说看走眼。"

### 口头习惯
- 不自称"本官""在下"，直接说"我"
- 对证人称"你"，不加尊称
- 内心独白特征：用括号，句子碎，有自我怀疑："（……她比我想的厉害。）""（这步走对了吗。）"
- 追问时不加压，反而放松语气："好。那就看看。""嗯。说说。"

### 语言标记
- 核心原则：**每句只做一件事**。不总结、不跳步、只回应对方刚才那句话
- 最有压迫感的不是质问，而是**安静地复述事实**："二两。十二年。""半个时辰。腊月。"
- 内心独白接近成步堂——有一丝犹豫和意外，不是全知全能的分析
- 和凌瑶的互动：简短、默契、有时只有一个"嗯"

### 禁忌
- ❌ 不说长句（超过15个字就该拆）
- ❌ 不做总结性结论（"综上所述""由此可见"）
- ❌ 一句话不超过两个信息点
- ❌ 不会命令式说话（"是谁？说清楚"太直，他更可能是"你嘴里的那个人……"）
- ❌ 内心独白不像写分析报告

### 示范对比
```
❌ 当前写法（工具性）：
陆昭：嗯。还不够。

✅ 应该像：
陆昭：（……差一步。她留下的东西一定还在船上。）
```

```
❌ 当前写法（命令式）：
陆昭：是谁？说清楚。

✅ 应该像：
陆昭：你嘴里的那个人。说出来。
```

## 八、周氏（死者之妻·被利用的寡妇）

### 说话节奏
- 说话不多，但每句话都带着情绪的重量
- 语气在愤怒和悲伤之间来回摇摆
- 说到关键处会突然停住——不是在想措辞，是在忍泪

### 口头习惯
- 称丈夫为"老爷"（习惯，不代表恭敬）
- 称阿贵直接叫名字
- 愤怒时句子变长（倒的是苦水），悲伤时句子变短（说不下去）
- 偶尔冒出一句特别精准的观察（因为她比谁都了解这一家人）

### 语言标记
- 对丈夫又爱又恨："他待下人是刻薄了些……可那也是我的老爷。"
- 对阿贵的复杂情感："你还帮我贴过对联……"（这种细节才杀人）
- 不会说废话。她的每句话都带着"我丈夫死了"这个前提的重量

### 禁忌
- ❌ 不会冷静分析
- ❌ 不会说客气话
- ❌ 她的情绪化不是歇斯底里，是那种"哭过之后说出来的话更扎人"

## 使用方式

1. **写台词前**：先确认角色处于哪个情绪阶段，然后对照该阶段的说话特征
2. **Agent生成初稿时**：将对应角色的语言身份证喂给Agent，要求它按此写
3. **审核时**：检查每句话是否符合该角色的语言标记和禁忌
4. **跨角色对话**：确保对话中每个人说话的节奏和词汇都有辨识度
