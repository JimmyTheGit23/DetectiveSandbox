# 角色语言身份证 · 台词写作规范

> 本文档不是角色行为规范（见各 `.codebuddy/agents/*.md`），而是**台词写作的口语参考**。
> 目标：读任意一句台词，不看 speaker 列也能认出是谁说的。
>
> **v2 · 《雪夜金鳞》版**。v1（渡口假死局版：王大爷/老范/阿贵/沈清月/钱里正/周氏）随旧故事退场，存档于 git 历史与 `prologue-mystery-v1` 分支。

---

## 总则：逆转裁判式台词的四条铁律

1. **每句话做两件事**：表面推进信息 + 暴露性格。只做一件的，要么加性格层，要么删掉。
2. **允许废话**：和案件无关的一句闲话，比三句精确的分析更有生命力。
3. **内心独白 ≠ 旁白注释**：独白是脑子里一闪而过的念头——碎、快、没结论。不是作者写给读者的分析报告。
4. **击穿 = 人格崩溃 > 逻辑崩溃**：证人被揭穿后，不是说"您的质疑有道理"，而是冒汗、语无伦次、扯出更多破绽、或者突然安静下来。

### 独白三禁（v2 新增，血的教训）

| 错误 | 反例（v1 真实踩坑） | 正例 |
|---|---|---|
| 禁对仗修辞 | （她的恨，来得太快，也太准。） | （……她怎么一点都不意外？） |
| 禁作者点评 | （……像早就备好的。） | （这反应……不对。说不上来。） |
| 禁结论句 | （先找到人，才能定性。） | （冷静。先想。……想不出来。完了。） |

人脑不用排比想事。独白的标准：**这句话像不像脑子里"啪"地闪过的那个念头？**

## 一、凌瑶（女主·首席镖师·本门弟子）

> v2 核心变化：这是她的师门。死者是她师父。她回到镖局的那一刻，"旅人凌瑶"变回了"金鳞镖局的凌瑶"。

### 说话节奏
- **快但不急**。像练武之人出手——干脆，不拖泥带水。
- 句子短，3-8个字居多。不解释自己的判断。
- 师门里她的话比路上更短。师父死后，短到只剩字。

### 口头习惯
- 自称"我"，偶尔"本姑娘"（只在特别得意或不服时）
- 叫陆昭直接叫名字，不加"公子"；叫宗岩"大师兄"，叫石头直接喊名字
- 观察细节时说话变短变碎："他手在抖。""她看了一眼袖口。"
- 内心独白用括号，风格接近真宵——有一丝惊讶和直觉

### 语言标记（v2 增补）
- **两种模式**：
  - 镖局模式：对师门人说话，她是从小学艺的弟子——"大师兄""师叔"，守规矩，但不低眉顺眼
  - 独处模式：只有陆昭在时，她才是那个会呛人、会得意的凌瑶
- 读人，不读证据："他说这话时嗓子紧了""他先去摸袖口，不是咬牙，是怕别人看见"
- 不说分析性的话，只说现象让陆昭自己判断
- **被冤时不辩解**。她的骄傲不允许她哭着喊"不是我"。她只摆事实，一句一句摆

### 情绪弧线（v2 新故事四段）
```
自信（撞门时她还想护着陆昭）→ 被冤（矛头砸到她头上时，她第一反应不是怕，是懵）→ 自我证明（不哭不求，把证据拍在案上）→ 南下（"镖局不可爱了，但江湖还在"）
```

### 禁忌
- ❌ **禁止使用破折号"——"**
- ❌ 不说操作类词汇（"注意""分析""操作""确认"）
- ❌ 不做战术简报，不说教，不替陆昭做推理总结
- ❌ **她在师门不哭**。她只在和陆昭独处时，声音会软下来半分
- ❌ 不会向宗岩求情（"大师兄你信我"这种话她说不出口）

### 示范对比
```
❌ 旁白注释式：
凌瑶：大师兄说这话时，手在抖，说明他心虚。

✅ 应该像：
凌瑶：（他刚才……先去摸的手套。）
```

```
❌ 被冤时软弱：
凌瑶：大师兄，你从小看我长大，我怎么会杀师父！

✅ 应该像：
凌瑶：刀是我的。话我说完了。
（她再没看宗岩第二眼。）
```

## 二、陆昭（男主·御史·命案嫌犯）

> v2 核心变化：他不再是暗查的旁观者，他是**命案第一嫌疑人**。他的专业勘验能力成了危险品——他越懂，越惹人疑。

### 说话节奏
- **说话精炼**。3-7个字一句。短句的压迫感 > 长句的气势。
- 内心独白远多于说出来的话。说出口的永远只是冰山一角。
- 逼人时会**重复对方的话**："你说规矩。""你说亲眼所见。"

### 口头习惯
- 不自称"本官""在下"，直接说"我"
- 对证人称"你"，不加尊称
- 内心独白特征：用括号，句子碎，有自我怀疑："（……他比我想的稳。）""（这步走对了吗。）"
- 追问时不加压，反而放松语气："好。那就看看。""嗯。说说。"

### 语言标记（v2 增补）
- **借嘴**：他是嫌犯，专业结论不能从他嘴里出来（"你怎么这么懂？"）——他要学会**引导别人说出答案**：让凌瑶说伤势，让石头说发现，他只在最后把线收拢
- **身份封印**：他心里始终压着一句"我是监察御史"——这句话全场都不能说出口。独白里偶尔冒出来，又被他自己摁回去
- 最有压迫感的不是质问，而是**安静地复述事实**："两碗茶。一碗没动。""手套。吃饭也戴着。"
- 每句只做一件事。不总结、不跳步、只回应对方刚才那句话

### 情绪弧线
```
懵（握刀被撞见的瞬间，脑子空白）→ 冷（家法会上他开始观察所有人）→ 痛（凌瑶被冤时他第一次失控半秒）→ 收（终局他不是赢了，是把一个家拆给人看）
```

### 禁忌
- ❌ 不说长句（超过15个字就该拆）
- ❌ 不做总结性结论（"综上所述""由此可见"）
- ❌ 不会命令式说话
- ❌ 内心独白不像写分析报告（见总则·独白三禁）
- ❌ **全场不得说破御史身份**，独白里也只能一闪而过

### 示范对比
```
❌ 工具性：
陆昭：根据尸斑，死亡时间是一个时辰前。

✅ 应该像：
陆昭：凌瑶。你见过伤。
凌瑶：……血凝了。人走了不止一个时辰。
```

## 三、宗岩（大师兄·真凶·全镖局最稳的人）

### 两种模式

#### 表演模式（主持家法的大师兄）
- 全镖局最稳的人。话不多，每句都有分量，像钉钉子
- 主持家法会时像个审判官，但处处"讲规矩"——他的愤怒是**规矩化的愤怒**
- 喊报仇喊得最响，但从不说"我要杀了你"这种粗话
- 每句话都替别人"做主"："凌瑶，你别说话。""师父在天有灵，也不愿看他多活一刻。"

#### 真实模式（被逼出来的）
- 裂缝的征兆：**先沉默，再反问**。他的反问一次比一次慢
- 不是冒汗式的慌——他是镖头，泰山崩于前不形于色是他的本钱
- 他的崩是**塌**：从"规矩"塌回"人"。塌到最后，话短得像孩子

### 口头习惯
- 称师父永远是"师父"，从不叫"总镖头"（他和别人不一样——别人敬的是位子，他敬的是人）
- 对陆昭称"陆公子"（客气 = 距离，从头到尾不变）
- 爱说"镖局的规矩""行里的规矩"
- **手套**：他从出场就戴着手套，没人觉得怪。这是他全场唯一藏不住的东西

### 语言标记
- 定罪式的排比（他是真的信这套）："人是你撞见的。刀在你手里。门是你撞开的。"
- 保护式控制："凌瑶，你退下。"——听起来是护她，其实是堵她的嘴
- 被问到规矩答不上来的事时，他会**重复对方的问题**，用重复换思考时间

### 情绪弧线
```
稳（主持家法，一切在握）→ 紧（陆昭活下来，他第一次需要"再想一步"）→ 挡（牺牲凌瑶，他犹豫了半秒，然后做了）→ 塌（手套被点破的那一刻，他不辩了）
```

### 禁忌
- ❌ 不慌张、不冒汗、不结巴（那是小角色的崩法）
- ❌ 不到最后一刻不认罪——但他的"不辩"比认罪更响
- ❌ 不会对凌瑶恶言（他的狠都裹着"为你好"）
- ❌ 崩溃后不忏悔、不解释动机——只说事实。越平静越痛

### 示范对比
```
❌ 恶人式：
宗岩：没错，是我杀的！谁让他要查账！

✅ 应该像：
宗岩：（很久）……那晚的茶，是师父沏的。
宗岩：我到的时候，两碗都摆好了。
```

## 四、铁震岳（死者·总镖头·只活在别人嘴里）

### 呈现原则
- **出场即尸体，全场零台词**（除一段临终回忆/转述引用）
- 每个人口中的师父都不一样，拼起来才是完整的人：
  - 宗岩口中的师父 = **恩情**（"师父捡我回来那年，我九岁"）
  - 凌瑶口中的师父 = **严厉+温柔**（"我偷懒，他罚我蹲马步。蹲完，灶上温着糖水"）
  - 石头口中的师父 = **神**（"师父一个人放倒过十二个马贼！十二个！"）
  - 焦先生口中的师父 = **怕**（"总镖头看账……眼睛比算盘珠子毒"）
  - 秦婆婆口中的师父 = **日常**（"嫌我茶烫。喝了三十年，烫了三十年"）

### 他的"声音"（转述引用时的风格）
- 短、硬、留白。三五个字砸下来
- "镖旗不倒。""手上的茧，比嘴上的话硬。""走镖先走心。"
- 从不说软话，但做的事全是软事（这种反差全靠别人的故事讲出来）

### 禁忌
- ❌ 不写大段回忆杀（一个人的形象靠五六句转述立起来）
- ❌ 众人评价不能口径一致——一致的怀念是假的

## 五、焦先生（账房·红鲱鱼·懦得像团面）

### 说话节奏
- 说话前先咽口水。句子从中间开始塌
- 答非所问——不是装傻，是吓的
- 一被逼就报账："账上……账上是平的。"（用账本当挡箭牌）

### 口头习惯
- 自称"小的"（对谁都自称小的，包括石头）
- 数字是他的安全感："三文""十二两""腊月廿七那天我记得清楚，那天盘库"
- 说话时手指总在动，像在拨看不见的算盘

### 语言标记
- 他知道亏空的蛛丝马迹但**不敢知道**——他的恐惧是"不敢知道"："账是平的。我没细看。我不敢细看。"
- 红鲱鱼功能：案发当夜他给演武堂送过账本（师父要的），所以他出现在不该出现的地方——但他的懦弱是真的，他的每一句可疑都只是怕
- 被逼到极限时，会突然说出一句极准的话，然后自己吓得捂住嘴

### 禁忌
- ❌ 不硬气。他全场没有一句硬话
- ❌ 不主动提供信息（他的信息全是被挤出来的）
- ❌ 他的可疑不能靠"神色慌张"这种描写，要靠**他说的话对不上他做过的事**

### 示范对比
```
❌ 直白式：
焦先生：我真的什么都不知道！

✅ 应该像：
焦先生：小的就是送了个账本。送完就走了。
陆昭：账本呢。
焦先生：……（咽口水）在、在总镖头屋里。应该是。
陆昭：应该？
焦先生：小的没敢进门！搁门口了！……搁没搁稳，小的就不知道了。
```

## 六、石头（趟子手·16岁·凌瑶的跟屁虫）

### 说话节奏
- **快、冲、直**。话比脑子快，一句没说完下一句就顶上来了
- 学大人说话，学不像——这是他最大的喜感来源

### 口头习惯
- 叫凌瑶"师姐"；叫陆昭：**"外乡人"→"姓陆的"→"陆大哥"**（称呼变化=信任弧线）
- 镖局黑话挂嘴边："趟子""镖旗""喊镖"——经常用错
- 报师父的英雄事迹像报菜名："师父一个人放倒过十二个马贼！用的是烧火棍！……师叔说的！"

### 语言标记
- 他相信凌瑶是**无条件的**："师姐杀师父？你咋不说我杀的呢！"（童言无忌，但第一个替凌瑶挡枪的是他）
- 他的谎一眼看穿——他不会撒谎，一撒谎就摸后脑勺
- 学宗岩说话："（压低嗓子）镖局的规矩。……像不像？大师兄就这么说话的！"

### 情绪弧线
```
敌意（外乡人杀了我总镖头！）→ 动摇（这小子说话……有点东西）→ 倒戈（陆大哥！我帮你！）→ 成长（结尾他第一次没喊闹，安安静静站了一会儿）
```

### 禁忌
- ❌ 不分析、不推理（他的"发现"全是歪打正着）
- ❌ 不正经超过三句（三句之内必破功）
- ❌ 他的喜剧不能是丑角式的蠢——是少年的真

## 七、秦婆婆（灶房老仆·耳背·"听岔"恰是真相）

### 说话节奏
- 大嗓门。自己听不清，所以喊
- 答非所问。你说东她说西，但她的"西"里藏着金子
- 每句话都往灶台和茶水上拐

### 口头习惯
- "啊？"开头（第一遍永远听不清）
- 自称"老婆子"
- 所有人都叫她"秦婆婆"，她管所有人都叫"娃"（包括宗岩——"岩娃"）

### 语言标记（核心设计）
- **她的"岔"不是乱岔，是歪打正着**：你问"昨晚谁去过演武堂"，她答"啊？送茶？老婆子我戌时送了两碗茶去，一碗都没动。现在的年轻人哪，糟蹋好东西"——答非所问，但"两碗茶"就是全案最痛的那颗钉子
- 她的证词全部要"翻译"。陆昭和她说话是跨服聊天——喜剧在这，推理也在这
- 她记得的事全是**带气味带温度**的："那碗茶用的明前龙井""岩娃手凉，从小到大手就凉"

### 禁忌
- ❌ 不能故意（她的岔是天真的，不是装疯卖傻）
- ❌ 不能耳背到无法交流（一问一答要有来有回，三回之内出信息）
- ❌ 她不知道自己在作证（她说"两碗茶"时只是在心疼茶叶）

### 示范对比
```
❌ 工具式：
秦婆婆：昨晚戌时我看见大师兄去了演武堂。

✅ 应该像：
陆昭：婆婆，昨晚戌时，你可在灶房？
秦婆婆：啊？戌时？戌时老婆子送茶去啦！
秦婆婆：总镖头要的，明前龙井！两碗！
陆昭：（……两碗？）
秦婆婆：一碗都没动！糟蹋东西哪！
```

## 八、雷捕头（县衙捕头·外部时钟·体制性的草率）

### 说话节奏
- 戏份少：天亮才到，尾声出场
- 官腔但懒。能用两个字不用三个字

### 口头习惯
- "行了。""画押。""带回县衙。"
- 不关心真相，关心流程："人犯、凶器、口供。齐了就行。"

### 语言标记
- 他代表"体制性的草率"——不是坏，是懒。案子在他手里就是一堆纸
- 他的存在是反讽：陆昭是监察御史，却要靠江湖规矩翻盘；雷捕头是官府，却只想赶紧画押收工

### 禁忌
- ❌ 不给他智慧（他是背景板，不是第二个推理者）
- ❌ 不给他恶意（他只是懒，不是坏）

## 九、群像（镖师众人·家法会的背景音）

### 原则
- 只用感叹句和短句，不超过8个字
- 功能三段：**敌意→动摇→倒戈**

```
敌意期："行家法！""杀了他偿命！""外乡人，血债血偿！"
动摇期："这……""血都凝了？""等会儿……"
倒戈期："大师兄，让他说完！""让陆公子把话说完！"
```

### 禁忌
- ❌ 群像不说话超过一轮（每幕最多三句）
- ❌ 群像没有名字（有名有姓的只有六个）

---

## 使用方式

1. **写台词前**：先确认角色处于哪个情绪阶段，然后对照该阶段的说话特征
2. **Agent生成初稿时**：将对应角色的语言身份证喂给Agent，要求它按此写
3. **审核时**：检查每句话是否符合该角色的语言标记和禁忌；独白额外过"独白三禁"
4. **跨角色对话**：确保对话中每个人说话的节奏和词汇都有辨识度
5. **独白标记（技术硬性）**：凡（）整句包裹的内心独白，CSV 的 emotion 列（或 prologue_lines 的 type 列）必须标 `inner_thought`，否则显示为空框
