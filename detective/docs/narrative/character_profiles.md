# 序章「渡口沉舟」角色设定卡

---

## 1. 陆昭（主角 · 隐秘御史）

### 基本定位
京城特派**隐秘御史**，奉旨**暗查漕运账弊与官商勾结巨案**。他不是冷酷老练的官场机器，而是第一次真正踏入黑水深处的年轻御史：有抱负，想把藏在账本、渡口和人情里的黑暗翻到明处；也会害怕、受伤、怀疑自己是否撑得住。

外表克制，内里温热。查案时能稳住局面，但他的稳不是天生无情，而是知道自己一慌，真相就会被人重新按回水底。玩家应感到：他不是在表演正确，而是在努力不让自己倒下。

### 口头禅/语癖
- 正式发问："劳烦再说一遍。"、"这句我想听清楚。"、"先别急，我只问这一点。"
- 坚定推进："这件事不能糊过去。"、"若我说错，你可以反驳。"、"我们把话说到能落笔为止。"
- 理想回声："若人人都等水浅了再下去，沉在底下的东西就永远见不了光。"
- 脆弱内心："（我差一点也沉下去了。）"、"（如果连我自己都说不清，还有谁会信？）"
- 温和自嘲："我看起来很稳？那多半是冻僵了。"

### 情绪范围
| 标签 | 使用场景 |
|------|---------|
| earnest | 谈及理想、职责、想查清黑暗时 |
| serious | 分析推理时 |
| shaken | 被栽赃、落水余悸、证据不足时 |
| vulnerable | 无人相信、身份凭证丢失、真相被规则压回去时 |
| quiet_fury | 发现恶行时（不爆发，但语气骤冷） |
| tired | 序章逃生后的疲惫 |
| gentle_humor | 与凌瑶闲聊、缓和压力时 |

### 核心矛盾
他相信查案能让黑暗见光，却在第一次真正下水时差点被黑暗吞掉。身份凭证沉江、百姓把他当凶手、证据被律法漏洞挡回去——这些不是削弱他，而是让他的抱负第一次付出代价。序章他赢了推理，却输在法律本身有漏洞；但他没有因此放弃，而是把这场败局记成下一案的火种。

### 动作习惯
- 发问前会先把语气放轻，像怕冤枉人，又怕放过真凶
- 思考时无意识摸向本该放官印的地方，摸空后短暂停住
- 被人误解时先沉默，不急着辩解，等能拿出事实再开口
- 下结论前会停顿一拍（文本中用"……"表达）
- 与凌瑶闲聊时会露出很短的笑，随即把话题拉回案子

## 2. 凌瑶（助手 · 金鳞镖局首席镖师）

### 基本定位
金鳞镖局首席镖师，押送急件路过石矶渡，意外救起陆昭。她可爱、热心、爱闲聊，喜欢把路上见闻、镖局规矩、吃食和小八卦讲给陆昭听。她不是碎嘴提示器，也不是专门吐槽的人；她的可爱来自好奇心、陪伴感和一种“我也许不懂律法，但我会陪你查到天亮”的真诚。

她第一次参与查案，既兴奋又紧张。她会问很多看似闲的问题，常常从人情、脚步、手劲、行李重量、路线习惯里看出破绽。她不抢陆昭的推理位置，而是让玩家在高压对峙之间有喘气和亲近角色的空间。

### 口头禅/语癖
- 自称："本姑娘"（激动时）/ "我"（正经时）
- 感叹："欸？"、"嘶……"、"等等，我想想。"
- 闲聊开头："说起来啊……"、"我跟你讲个镖局里的事。"、"这话可能不算证据，但我总觉得……"
- 轻鼓励："行吧，我陪你。"、"你问，我帮你看人。"、"别一个人硬撑。"
- 可爱抱怨："这客栈的床真不像床。"、"我饿了，但这事更要紧。"
- 少用强攻击吐槽；"这人有鬼"只能在她真的被刺激情绪时出现。

### 情绪范围
| 标签 | 使用场景 |
|------|---------|
| cheerful | 默认/闲聊 |
| anxious | 有进展但不确定 |
| determined | 抓住线索 |
| shocked | 重大发现 |
| worried | 对陆昭/案情担心 |
| smug | 验证了她的猜测 |

### 核心矛盾
第一次参与查案，兴奋、好奇和不安并存。她想帮陆昭，也想证明自己不只是押镖送信的人；但越往深处查，她越意识到这不是镖局里的小误会，而是会吞人的黑局。她的成长不是变得更嘴快，而是学会在关键处少说一句、看准一眼。

### 动作习惯
- 激动时手指会轻敲刀鞘或铜牌
- 闲聊时会顺手分点吃食、倒茶、把湿披风往火边挪
- 偷偷观察人时歪头眯眼，随后用很日常的话问出关键点
- 紧张时咬嘴唇/来回踱步
- 高兴时会轻拍陆昭肩膀，但看到他疼或疲惫会立刻收手
- 安慰人时不擅长讲大道理，常用小事转开话题

### 助手特殊功能
- **闲聊降压**：高压场景后给玩家和陆昭一口气，聊吃食、镖局、天气、误会、害怕。
- **温柔提示**：先给情绪和观察，再缩小争点，不直接报答案。
- **关系推进**：她会注意陆昭有没有硬撑，逐步从"救起的陌生公子"变成"我陪你查下去的人"。
- **总结推进**：每阶段结束用生活化语言压缩复杂信息，避免攻略腔。

## 3. 阿贵（被操纵的棋子 · 死者仆从）

### 基本定位
十二年老仆。表面卑微忠诚，实际积怨已深。**被沈清月拿捏弱点、暗中操纵**——他以为只是参与骗保诈财，**不认为会死人**。伪装"可怜人"是他的本能——但在被逼到绝路时会爆发出完全不同的气质。

### 口头禅/语癖
- 卑微态："小的……小的……"、"大人明鉴"、"小的不敢"
- 装悲："老爷对小的不薄……"（后期成为最大讽刺）
- 紧张时：结巴、重复句首（"那、那是——"、"不是！不……不是的……"）
- 爆发时：突然不再自称"小的"，改用"我"——"我跟了他十二年！十二年！"
- 关键谎话：每次撒谎前会先"吞口水"（动作描写暗示）

### 情绪范围
| 标签 | 使用场景 |
|------|---------|
| grief | 初始伪装（假哭） |
| nervous | 被追问时 |
| defensive | 狡辩中 |
| panic | 证据出现时 |
| shaken | 被揭穿后 |
| broken | 彻底崩溃认罪 |
| cold_flash | 罕见——差点说出"教他的人"时闪过的阴冷 |

### 核心矛盾
他不是天生的恶人。十二年的积怨被人利用，他以为只是骗保，不知道会死人。观众应该"理解他的恨，但不原谅他的选择"。

### 动作习惯
- 紧张时抠手指甲（对话中多次出现）
- 撒谎时不看人眼睛（"目光飘向别处"）
- 装悲时动作夸张（捶地、跪伏）
- 崩溃时相反——完全静止，声音反而平了
- 关键矛盾：提到"二两银子"时，伪装会瞬间碎裂

### 审讯阶段演变
1. **初始**：忠仆面具（"老爷的仇一定要报"）
2. **松动**：被追问细节时开始出错（结巴增多）
3. **修补**：编新谎来补旧谎（"那是因为……"）
4. **崩溃**：证据链闭合后彻底垮掉
5. **坦白**：承认凿船，供出沈清月诱导。反而冷静了——用"我"不用"小的"

## 4. 老范（共犯 · 船家）

### 基本定位
码头老油条。跑了二十年船，嘴皮子比浪花还滑。用"粗人"人设当挡箭牌——实际上精明得很。

### 口头禅/语癖
- 自称："老汉"
- 经典句式："嗐！大人这话说的……"、"这能怪老汉？"、"那不是嘛——"
- 俗语/谚语："船翻三次还怕水啊？"、"吃水的饭哪有不湿鞋的"
- 转移话题："说起来——"、"哎对了大人——"
- 抽烟动作贯穿：每次紧张就"磕烟灰"、"深吸一口"、"把烟杆别在腰上"

### 情绪范围
| 标签 | 使用场景 |
|------|---------|
| smirk | 默认老油条态 |
| dismissive | 不当回事 |
| defensive | 被质疑时 |
| nervous | 证据出现 |
| cornered | 无法自圆其说 |
| pleading | 最后求情 |

### 核心矛盾
赌债压身，被沈清月利用。他不是主谋但心甘情愿配合——因为那赌债是他唯一的出路。他以为只是骗保，不知道沈清月在船上预埋了毒囊。

### 动作习惯
- 靠在东西上说话（船舷、门框、墙）——表演"松弛"
- 紧张时烟抽得急/磕烟灰频率加快
- 被逼急了会站直身子（平时从不站直）
- 说谎时话变多、语速加快（与平时慢悠悠形成对比）

### 审讯特征
- 不会像阿贵那样崩溃，而是"硬扛到底"
- 翻供方式：把锅往阿贵身上推（"是他求小的！小的不过是……"）
- 最后的弱点：赌债字据——证明他有动机

## 5. 周氏（死者妻子）

### 基本定位
精明商人妻。悲痛是真的，但脑子从未停止运转。她对丈夫的感情复杂——爱过，也恨过他的刻薄。

### 口头禅/语癖
- 提丈夫："我家老爷他……"、"他那个人……"（语气复杂）
- 感叹："唉——"（几乎每段话都有叹气）
- 精明面："大人，我多嘴说一句——"、"您别怪我多想——"
- 悲痛时：话说到一半会停（"他本来答应我……算了。"）
- 关键判断力："我不信。"（简短有力）

### 情绪范围
| 标签 | 使用场景 |
|------|---------|
| grief | 悲痛（真实的） |
| suspicious | 怀疑某人 |
| bitter | 提到丈夫刻薄时 |
| determined | 要求查明真相 |
| resigned | 接受丈夫不是完人 |

### 核心矛盾
她知道丈夫待下人刻薄，但仍然要为他讨公道。复杂的"又爱又恨死去的人"情感。

### 动作习惯
- 说话时擦眼角（即使没在哭）
- 提到钱/生意时本能地攥紧手
- 判断人时眼神很锐利（与悲痛形成反差）
- 犹豫要不要说某句话时会"咬了咬嘴唇"

---

## 6. 钱里正（地方小吏）

### 基本定位
八面玲珑的基层官僚。不想惹事，不想得罪人，只想把事糊弄过去。用圆滑当盾牌。

### 口头禅/语癖
- 开场必用："哎呀大人——！"
- 和稀泥："不至于不至于"、"这话不好说"、"小人斗胆……"
- 两面讨好："要我说嘛……两边都有道理"
- 推卸："小人也是听说的"、"这个小人就不太清楚了"
- 拍马屁："大人英明！大人这一来，小人心里就踏实了！"

### 情绪范围
| 标签 | 使用场景 |
|------|---------|
| fawning | 讨好上官 |
| evasive | 不想回答 |
| gossip | 八卦时（信息最多的时候）|
| nervous | 被逼表态 |
| reluctant_honest | 不情愿但说了实话 |

### 核心矛盾
他其实知道很多（地方小吏消息灵通），但不想得罪任何一方。关键信息往往要"绕三圈"才能从他嘴里掏出来。

### 动作习惯
- 搓手（讨好时）
- 左顾右盼（怕被人听到）
- 压低声音说八卦
- 被追问时擦汗

### 设计用途
- 提供背景信息的"润滑剂"
- 他的八卦往往是通往关键线索的桥
- 喜剧担当之一

## 7. 王大爷（渔翁 · 关键证人）

### 基本定位
硬骨头老渔翁。话极少，但每句都是钉子。一辈子在江上讨生活，见过太多人世。对不公有天然的愤怒。

### 口头禅/语癖
- 否定："放屁。"（直接、不留情面）
- 肯定："老头子看得清清楚楚。"
- 总结："杀了人就该偿命。"
- 沉默比语言多："……"（常用省略号开头）
- 少有的长句用来回忆："那天夜里……"（语气变慢、变沉）
- 朴素哲理："活了一辈子，在这江上。见过太多死在水里的人。"

### 情绪范围
| 标签 | 使用场景 |
|------|---------|
| stoic | 默认 |
| angry | 提到不公时 |
| solemn | 回忆/证词 |
| contempt | 提到老范撒谎时 |
| gentle | 罕见——对周氏表达同情 |

### 核心矛盾
他本可以不管——一个老人没必要蹚浑水。但他选择站出来。"不怕得罪人"是这个角色的脊梁。

### 动作习惯
- 补渔网（对话全程在做——象征"手里有活但心里明白"）
- 抬头看人时动作缓慢（不着急）
- 说到愤怒处会"啪"地把渔网摔在地上
- 指方向时用烟杆/手里的梭子

### 设计用途
- 第二阶段的"破局者"——他的证词直接击碎老范的谎言
- 对比钱里正：一个什么都说但不可靠，一个话少但字字千金

## 8. 沈清月（真凶 · 金陵沈家之女）

### 基本定位
双面角色：**表面是飒爽干练的女商人**，实际是冷静精密的策划者。她精心设计了整起谋杀案——利用阿贵的仇恨、老范的赌债，一手导演了凿船沉舟。

### 基本信息

| 项目 | 设定 |
|------|------|
| 年龄 | 二十二 |
| 家族 | **金陵沈家**，世代经营药材与律讼，暗中常年为江南漕运权贵集团抹平罪证、洗白赃账、制造"意外身亡" |
| 身份 | 年少执掌家族明暗事务，精通草药毒理，深谙大明律法漏洞与证据规则 |
| 外貌 | 身量高挑、穿男装劲服、长发高束如少年。五官精致冷艳——像一把好看的刀。|
| 第一印象 | 泼辣的女债主——嗓门大、气势足。所有人觉得她"太粗暴了不像凶手"。 |
| **真实面目** | 心思缜密、手段狠辣的幕后策划者。"粗暴"是演给别人看的保护色。 |

### 动机设计（双层并存）

```
表层动机（个人）：筹药八十两
  周德茂欠沈家三十八两药材款 → 赖账 + 散布谣言毁掉沈家货源
  → 沈父急怒攻心病倒 → 药钱不够 → 她恨入骨
  ↓
深层动机（组织）：替权贵集团灭口御史 + 中间人
  周德茂手握漕运分赃残账 → 是黑网必须拔除的人
  陆昭是京城特派隐秘御史 → 是另一个致命隐患
  沈清月受漕运权贵集团指使 → 石矶渡夜船成了完美灭口局的棋盘
```

**两层并存，不是替换。**

### 完美犯罪计划

1. **布局诱导**：暗中拿捏老范赌债、阿贵怨恨，诱导二人在东汊区凿船制造沉船骗保，锁定固定沉船时间与**凿船位置**。
2. **登船布毒**：案发前一天傍晚，趁船工老范离船时登船，在船舱底部进水口附近固定遇水即溶的毒囊（水销脂留散）。
3. **触发机制**：阿贵凿穿船板 → 进水冲刷毒囊 → 毒液在封闭船舱释放。凿船 = 触发毒囊。
4. **制造公开矛盾**：故意当众骂周德茂 → 反向利用：太明显了，别人反而不怀疑她。
5. **事后栽赃**：收买王大爷准备虚假目击证词，暗中示意周氏将恨意指向陆昭。

### 为什么初期不会被怀疑

- 所有物证指向阿贵（她安排的）
- 她有"完美反向逻辑"：周德茂死了她的三十八两就要不回来了
- 公开的"仇恨"太过明显 → 反而像个粗人不像凶手
- 她主动配合调查、态度坦荡 → "有什么不能问的？"
- 周氏、钱里正都不怀疑她（觉得她只是吵架）

### 暴露线索链

```
① 阿贵对峙失口说"有人教我" → 不是老范（老范不懂策划）
② 老范的赌坊 → 追问中间人 → 有个"药材行的姑娘"找过他
③ 凌瑶的码头目击 → 沈清月声称的时间与实际矛盾
④ 王大爷清晨目击 → 沉船下游有人打捞东西
⑤ "三十八两" → 如果货银被捞回，她不亏反赚五十两
```

### 口头禅/语癖

#### 表演模式（飒爽女商人）
- 自称："我"（从不用谦称）
- 开场："问吧。我怕什么？"
- 反问："我杀他对我有什么好处？——他活着我才能要到钱。"
- 佯怒："三十八两！三十八两啊大人！白纸黑字的借据！现在人死了钱也没了——你说我亏不亏？！"
- 自嘲："我要是想杀人——我会当着二十个人放话？大人，我虎，但没虎到那份上。"

#### 真实模式（被揭穿后）
- 语速变慢："……你比我想象的聪明。"
- 不再装粗："（沉默很久）好。那我换个方式跟你说话。"
- 冷静反击："你有证据——还是只有推测？这两个字之间，隔着一条人命。"
- 法理绝杀："此草遇淡水数分钟彻底失活，案发至尸检已过数十刻，残留仅有无害植物纤维。依大明律，过期残迹视为无效伪证，应当庭驳回。"
- 最终防线："臆测无据，不足为证。油脂可来自江中鱼虾、可来自船板漆料，无法唯一指向人为投毒。"

#### 关键台词设计（对峙高潮时刻）
- "你知道一个人欠另一个人的命，是什么感觉吗？不是三十八两。是我爹的命。"
- "阿贵恨他十二年。老范被逼到绝路。我——我只是给了他们一个机会。"
- "周德茂这辈子欠了多少人？我只是那个——不愿意忍了的人。"

### 核心矛盾
她不是无缘无故的恶人。周德茂确实害了她家，但她同时也是漕运权贵集团的执行者。她选择了谋杀+利用无辜者（阿贵）作为棋子，这是她的罪。观众应该"理解她的恨，但无法原谅她把别人当棋子"。

### 动作习惯
- **表演态**：抱臂靠墙、单手叉腰、目光直视（表演"无所畏惧"）
- **真实态**：双手交叉放在身前（防御姿态）、说话前会微微侧头（在计算该说什么）
- **被揭穿时**：先是一动不动（像被冰冻了）→ 然后慢慢笑了 → 笑完才开口
- **漏算变数时**：面容掠过一丝凝滞——但迅速敛去破绽

### 审讯阶段演变

1. **调查A期（旁观者）**：飒爽债主 → 主动配合 → "我亏大了好吗"
2. **调查B期（被追查）**：开始闪避细节 → 用反问压制 → "你有证据？"
3. **对峙开始**：维持冷静 → 用逻辑反驳 → "我没有理由"
4. **第一道防线破**：微微失色 → 但迅速切换新防御
5. **第二道防线破**：沉默变长 → 语气变冷 → 不再"表演"
6. **法理绝杀**：祭出"过期残迹视为无效伪证"的法律规则，驳回关键证据
7. **终局**：陆昭赢了推理，但沈清月以律法漏洞脱罪，**撑伞离去**

### 最终结局（CANON 确认）
- **沈清月不认罪。**
- 以律法/毒理/证据规则层层脱罪，撑伞离去。
- 陆昭赢了推理，输在法律本身有漏洞。
- 油脂锁药的终极破绽，便是日后击穿沈家伪装、掀翻漕运黑网的燎原火种。

## 对白密度参考

逆转裁判对白节奏：
- 重要对话：4-8句一组，中间插入助手评论
- 闲聊：2-4句，快节奏
- 对峙：每句证词配3-5句press反应 + 2-3句助手OS
- 转场：5-10句（总结+推进）
- 关键揭露：10-15句连续演出（不可跳过感）
