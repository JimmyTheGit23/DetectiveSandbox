## 2. 角色塑造方法

### 2.1 主角不是“最聪明的人”，而是玩家的临场神经

成步堂的高发言占比说明，主角承担的不只是推理。他需要在同一场景里完成四件事：

1. 把玩家的疑惑说出来。
2. 把规则压力转成情绪压力。
3. 在关键处用短句推进逻辑。
4. 在失误、慌张、被噎住时保持可爱的人味。

对陆昭的落地要求：

- 陆昭可以冷，但不能全程正确、全程稳。
- 每个大阶段至少给一次“他也被局面压住”的内心反应。
- 正式发问保持短句，内心 OS 可以更有人味。
- 关键反击要从“我知道真相”改成“我终于找到能站得住的说法”。

陆昭原创台词基准：

```text
[陆昭]
说。

[陆昭]
这句先别急着圆。你刚才说的是“看见”，不是“听见”。

[陆昭]
（他答得太快了。快得像早把错话背熟了。）
```

### 2.2 助手不是提示按钮，而是玩家情绪的扩音器

真宵和小茜的作用不是替玩家解谜，而是在节奏上完成三件事：

- 紧张时先替玩家惊讶。
- 卡住时用生活化角度重新看问题。
- 每个大段落结束时，把复杂信息压缩成一句可行动目标。

对凌瑶的落地要求：

- 提示前先有角色反应，不直接说攻略。
- 她的镖局经验要进入判断，比如看人脚步、手劲、货物重量、押运路线。
- 她的吐槽要带感情，不只是“好笑”。

凌瑶原创台词基准：

```text
[凌瑶]
嘶。这个人不怕你问银子，怕你问船底。

[凌瑶]
我押镖见过躲债的，眼神都往门口飘。他刚才往水边看。

[凌瑶]
所以现在不是“谁恨周老板”，是“谁早知道船会破”。对吧？
```

### 2.3 对手要攻击“证明方式”，不是只说“不可能”

御剑、狩魔、岩徒一类对手的压迫感来自三层攻击：

1. 攻击事实：你说的事没有发生。
2. 攻击证据：你拿出的东西不能证明。
3. 攻击规则：即便事实成立，法庭也不能采纳。

对沈清月的落地要求：

- 她不是等玩家举证的木桩，而是主动重写争点。
- 她每次反击都要逼玩家补全证明链。
- 她的强大不在音量，而在“承认局部事实，再否定结论”。

沈清月原创台词基准：

```text
[沈清月]
这只能证明船破过，不能证明是谁凿的。

[沈清月]
陆公子，你把“可疑”说成“有罪”，中间少了一座桥。

[沈清月]
若证据只能在你心里成立，那它就不该出现在堂上。
```

### 2.4 证人靠“表演面具”被记住，靠“面具裂缝”推进剧情

逆转式证人通常不是普通信息点，而是一个小型舞台装置：夸张口癖、固定姿态、荒唐自尊、职业偏见或逃避习惯先抓住玩家，然后在追问中慢慢暴露裂缝。

可执行公式：

```text
社会脸谱 + 隐藏欲望 + 固定动作 + 语言节奏 + 一处自相矛盾
```

对本项目 NPC 的使用：

| 角色 | 社会脸谱 | 隐藏欲望 | 固定动作 | 裂缝 |
| --- | --- | --- | --- | --- |
| 阿贵 | 卑微忠仆 | 想让十二年委屈被看见 | 抠手指、吞口水 | 从“小的”滑到“我” |
| 老范 | 码头老油条 | 想用赌债压力换脱身 | 磕烟灰、靠门框 | 话越多越不像老船家 |
| 钱里正 | 和稀泥小吏 | 只想保住自己 | 搓手、擦汗 | 八卦时突然诚实 |
| 周氏 | 悲伤商人妻 | 要公道，也不想揭家丑 | 攥账本、擦眼角 | 提钱时比提人更冷静 |
| 沈清月 | 体面女商人/讼师 | 想让规则替她杀人 | 扣算盘、轻笑 | 被问到毒理细节时停半拍 |

## 3. 剧本结构拆解

### 3.1 逆转式案件的基础循环

```text
悬念开场
-> 休息室/事务所建立情绪目标
-> 法庭或调查给出表层事实
-> 证人证言形成看似完整的叙述
-> 追问让细节变多
-> 举证让细节变向
-> 对手重新定义争点
-> 休庭或转场总结当前缺口
-> 调查补足缺口
-> 新证言推翻旧假设
-> 终局证据改变某个旧物的意义
-> 情绪收束与后续钩子
```

重点不是“更多反转”，而是每次反转都改变玩家对旧信息的理解。好证据第一次出现时像普通道具，第二次出现时变成矛盾，第三次出现时成为角色选择的证明。

### 3.2 推荐五幕结构

| 幕 | 目标 | 玩家感受 | 剧作动作 |
| --- | --- | --- | --- |
| 第一幕：钩子 | 让案件有一个无法忽视的异常 | “这事不对” | 用短场景抛出死亡、诬陷或不可能现象 |
| 第二幕：锁嫌 | 让一个嫌疑解释看似成立 | “好像只能是他” | 给时间、地点、动机三点闭环 |
| 第三幕：破口 | 让一个小矛盾撬开大叙述 | “等等，这句话有问题” | 追问和举证只推翻局部，不急着揭真相 |
| 第四幕：换图 | 让案件地图、时间线或规则整体变形 | “原来问题不是这里” | 新地点、新证人、新规则进入 |
| 第五幕：代价 | 真相成立，但角色要付代价 | “赢了，但不轻松” | 真凶裂面、对手反扑、情绪后果落地 |

对序章《渡口沉舟》的适配：

1. 第一幕：夜船沉没与官印丢失，陆昭从幸存者变嫌犯。
2. 第二幕：地方证言把陆昭锁成外乡凶手。
3. 第三幕：船底破洞、航线异常、仆从口供出现裂缝。
4. 第四幕：骗保局成立，但毒囊与律法时效把真相推向沈清月。
5. 第五幕：陆昭证明“她做得到”，却不能证明到足以定罪，沈清月离场。

### 3.3 每个场景的微结构

一个好场景不要只问“提供了什么线索”，还要问“场景前后玩家的判断改变了什么”。

推荐微结构：

```text
进入场景：一句情绪或环境反应
立场声明：NPC 给出自我版本
第一次追问：抓住具体词，不问抽象动机
防守动作：NPC 用口癖、职业身份或情绪挡开
助手反应：把异常翻译给玩家
新信息：得到线索，或旧线索变得可疑
出口钩子：指向下一个人、地点或证物
```

场景验收标准：

- 开场 3 句内知道此人此刻想躲什么。
- 8 句内必须出现新信息、新情绪或新问题。
- 结束时玩家要知道下一步去哪，或者知道自己缺哪一块。
- 如果 NPC 只负责给信息，至少给一个行为记忆点。

## 4. 台词设计规范

### 4.1 自然台词的四条硬规则

1. 一句台词只做一件事。解释、反应、质问、吐槽不要全塞进同一句。
2. 先反应，再推理。人在现场不会直接说结论。
3. 少说抽象词，多抓具体词。用“船底”“油灯”“左手袖口”替代“可疑之处”。
4. 紧张时变短，撒谎时变长，崩溃时变乱，认命时变平。

对比改写方向：

| 弱台词 | 问题 | 改写方向 |
| --- | --- | --- |
| “这个证据说明你的证言存在矛盾。” | 攻略腔 | “你说没靠岸。那船底这枚新钉眼，是在水里自己长出来的？” |
| “我们应该继续调查船夫。” | 功能提示 | “老范刚才避开了航线。押镖绕路的人，心里都有第二张地图。” |
| “我很震惊，你居然撒谎。” | 情绪直白 | “……你刚才还叫他老爷。现在怎么不叫了？” |

### 4.2 追问的三拍

追问不是重复问一遍，而是逼证人补细节。

```text
第一拍：抓词
第二拍：逼具体
第三拍：让防守变形
```

原创示例：

```text
[陆昭]
你说“差不多三更”。差多少？

[老范]
嗐，江上人看天吃饭，哪能跟更夫似的敲锣报点。

[凌瑶]
他不肯报点。那就问灯，问潮，问谁还醒着。

[陆昭]
那晚渡口还有灯吗？
```

### 4.3 举证成功的五拍

```text
提出矛盾
-> 对手压回“这不能证明”
-> 指出证据细节
-> 重解释旧叙述
-> 证人面具裂开
```

原创示例：

```text
[陆昭]
你说船破之后才乱。可这张采买单在三日前。

[沈清月]
采买木料的人很多。陆公子，别把木头说成凶器。

[陆昭]
我说的是鱼鳔胶。它只用来封水口，而且怕热。

[凌瑶]
所以那晚船舱里的火盆，不是取暖，是让胶先软。

[阿贵]
不……不是小的买的。那东西、那东西是别人让小的去取的！
```

### 4.4 举证失败也要塑造角色

失败反馈不要写成“证据不对”。它应该同时完成角色表现和轻提示。

| 角色 | 错证反应方向 |
| --- | --- |
| 陆昭 | 自我收束，承认这条链不够 |
| 凌瑶 | 先吐槽，再把玩家拽回争点 |
| 沈清月 | 礼貌羞辱，强调证明责任 |
| 阿贵 | 过度松一口气，暴露他怕的是另一个点 |
| 老范 | 借题发挥，话变多，烟杆动作变急 |
| 钱里正 | 立刻和稀泥，试图让话题翻篇 |

原创示例：

```text
[沈清月]
这件东西很有意思，可惜只是有意思。

[凌瑶]
她没否认船底。她只是在笑你这张牌打早了。
```

### 4.5 助手提示的正确形状

不要直接说“出示某证据”。按这个顺序写：

```text
情绪反应
-> 角色经验
-> 争点缩小
-> 行动暗示
```

原创示例：

```text
[凌瑶]
哈？！他说自己没进船舱，可鞋边全是舱底灰。
我押镖时最烦这种灰，沾上就甩不掉。
陆昭，别问他见没见人，问他踩没踩过那块地。
```

## 5. 让角色被记住的设计清单

每个主要角色进入剧本前，必须写清以下 8 项：

1. 第一印象：玩家第一次见他，3 秒内记住什么。
2. 表层目标：他此刻公开想要什么。
3. 隐藏目标：他真正想保护什么。
4. 口癖：至少 3 个，但不能每句硬塞。
5. 动作锚点：紧张、得意、撒谎时各有什么动作。
6. 语言节奏：短句、长句、绕圈、反问、命令、碎碎念。
7. 关系按钮：谁能让他失控，谁能让他软化。
8. 崩裂方式：被击中时是愤怒、沉默、胡说、求饶，还是突然冷静。

角色写作验收：

- 遮住 speaker，只看台词，主要角色仍能猜出 70%。
- 同一角色不能只有口癖，还要有“怕被问到的事”。
- 喜剧角色也必须有真实恐惧，否则只会变成段子机器。
- 反派必须有可理解的逻辑，但不必被原谅。

## 6. 本项目剧本节奏模板

### 6.1 调查节点模板

```text
地点反应 1-2 句
助手观察 1 句
NPC 自我版本 2-3 句
玩家追问 1 句
NPC 防守 2-4 句
证据/线索进入 1 句
助手总结 1-2 句
下一步钩子 1 句
```

### 6.2 对峙节点模板

```text
证词标题
4-6 句证词
每句 press：
  陆昭抓具体词
  证人补细节或躲避
  凌瑶用角色经验提示
  可选：新增一条证词或获得线索
举证成功：
  陆昭指出矛盾
  对手反压
  陆昭补证据细节
  证人裂面
  更新证物/线索
```

### 6.3 转场模板

转场必须降噪，不要继续堆信息。

```text
情绪落点：刚才最危险/最荒唐/最痛的一点
事实整理：现在确定了什么
缺口确认：还缺什么才能推进
行动目标：下一步去哪或问谁
人物余味：一句角色关系或主题回声
```

原创示例：

```text
[凌瑶]
刚才差点被钱里正绕进沟里。

[陆昭]
至少确定了两件事。船不是自然破的，航线也不是临时改的。

[凌瑶]
还缺谁把这两件事接到一起。

[陆昭]
去找老范。他嘴里那根烟，快比他本人诚实了。
```

## 7. 审稿清单

### 7.1 台词自然度

- 是否有人在“说设定”而不是“回应现场”？
- 是否连续三句以上都是抽象判断？
- 是否每个人都说同一种书面长句？
- 紧张段落有没有变短、变乱、变急？
- 助手提示是否先有情绪，再有方向？

### 7.2 剧本节奏

- 每 8 句是否有新信息、新情绪或新问题？
- 每个场景结束是否留下明确行动目标？
- 证据是否至少经历“普通物件 -> 可疑细节 -> 关键解释”三次变义？
- 喜剧是否出现在紧张前后，而不是打断终局揭露？
- 转场是否负责整理，而不是继续塞新设定？

### 7.3 角色记忆点

- 主要 NPC 是否有固定动作？
- 口癖是否服务身份和压力，而不是贴标签？
- 被揭穿时，角色反应是否与其隐藏目标一致？
- 反派是否会主动改变争点？
- 玩家是否能说出“这个人怕什么”？

### 7.4 对峙可玩性

- 每句证词是否有可追问的具体词？
- 正确证据是否击中“细节”，而不是泛泛击中“谎言”？
- 错证反馈是否能保留一点方向感？
- 对手反击是否迫使玩家补证明链？
- 破局后是否更新证言、证据或角色状态？

## 8. 对《神探沙盒》的直接结论

1. 陆昭要保留冷面，但必须增加临场狼狈、疲惫和内心自嘲。玩家需要陪他一起推，而不是看他表演正确。
2. 凌瑶的提示要从“攻略说明”改成“镖师经验 + 情绪反应 + 行动暗示”。
3. 沈清月的压迫感来自法理和证据规则。她应主动承认小事实、否定大结论。
4. 阿贵、老范、钱里正这类 NPC 要有稳定口癖，更要有被追问时的变形轨迹。
5. 每个证据至少设计三次意义变化。只出现一次的证据很难制造逆转感。
6. 终局不要只追求大喊反转。最强的反转是旧证据突然解释了角色为什么这样活。
