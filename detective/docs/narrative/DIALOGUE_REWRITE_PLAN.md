# 台词改写执行计划

## 目标

在不改动证据链、节点 ID、条件解锁和对峙流程的前提下，把序章台词从“逻辑清楚”推进到“角色一开口就有辨识度”。新版方向见 [序章台词重构蓝图](PROLOGUE_DIALOGUE_RESTRUCTURE_BLUEPRINT.md)：陆昭从“冷面推理者”调整为有抱负、会脆弱、温热坚定的年轻御史；凌瑶从“嘴快提示器”调整为可爱、爱闲聊、有镖师观察力的同行者。

## 对比诊断

当前序章已经能和《逆转裁判》对比的部分，是证据链层层推进、最终对手会反击、助手会在关键时刻提示玩家。但差距也很明确：原台词有时太像“攻略说明”，角色不看 speaker 时辨识度不够；陆昭太稳，像证明机器，缺少青年抱负被现实撞痛后的脆弱；凌瑶有活力，但承担了太多直接提示，嘴碎感压过了可爱闲聊和陪伴感；普通 NPC 的口癖系统还不够稳定。

改写目标不是照搬现代法庭喜剧，也不是逐句微调旧台词，而是按场景任务整组重写：一拍角色反应，二拍逻辑推进，三拍情绪代价。最终对峙保持严肃，让沈清月像会拆证据的 Boss，而不是等着玩家出示答案的木桩。

## 硬规则

1. 先保流程，再改语气。不得改 `npc_id`、`node_id`、`statement_id`、`evidence_id`、`requires`、`record_id`。
2. 每个主要 NPC 至少有 3 个可复用的口癖、动作或比喻系统。
3. 凌瑶不能连续多句只做攻略提示。提示要先有闲聊/情绪/观察，再轻轻缩小方向。
4. 陆昭不能永远冷静无损。每个大阶段至少保留一次抱负受挫、落水余悸、被误解后的沉默或证据不足时的自责。
5. 动作描写归旁白或内心，不挂在角色 speaker 下，避免角色“说出自己的动作”。
6. 最终对峙不硬塞笑点。沈清月的压迫感优先，喜剧只做边缘反衬。
7. 若一段台词只是旧句换词，退回重写；必须先写清本场戏剧任务。
8. 对白要说人话：短、明白，少比喻和抽象大词；保留轻微古代语境，但避开网络梗、现代流行词和文言堆砌。

## 角色发动机

| 角色 | 发动机 | 改写方向 |
| --- | --- | --- |
| 陆昭 | 青年抱负、温热坚定、被现实撞痛但不退 | 少用冷硬命令，增加“想让黑暗见光”的理想、落水余悸、被误解后的脆弱 |
| 凌瑶 | 可爱闲聊、镖局经验、陪伴感 | 错证反应先情绪/闲聊/观察，再轻提示；减少直接报答案 |
| 阿贵 | “小的”面具、假哭、怨气爆裂 | 前期卑微，证据击中后逐步露出“我”的裂缝 |
| 老范 | 烟杆、船话、江上俗语 | 撒谎时话变多，烟杆动作变急，借水路俗语绕开问题 |
| 钱里正 | 基层免责、公文腔、和稀泥 | 每次说话都像在给自己留退路，八卦时才漏真话 |
| 王大爷 | 短句、渔网、硬骨头 | 少解释，多钉子句，关键回忆才放长句 |
| 周氏 | 账本、家计、旧物 | 悲伤与精明并存，用商人妻视角讲复杂感情 |
| 沈清月 | 法理、算盘、冷笑 | “指向/证明”是核心武器，动作描写移出她的台词 |

## 执行顺序

1. `prologue_lines.csv` + 船舱阶段 `dialogue_lines.csv`：先建立陆昭抱负与凌瑶救命/闲聊关系。
2. `companion_banter.csv` / `companion_discussions.csv`：给凌瑶建立可爱闲聊、降压和陪伴感。
3. `testimony_wrong_reactions.csv`：让失败反馈先角色化，再提示，减少攻略腔。
4. `testimony_press_lines.csv` / `testimony_break_lines.csv`：按王大爷、老范、阿贵三轮重写中段对峙。
5. 最后重写沈清月终局对峙，让陆昭的抱负受挫与法理失败落地。
6. 最后跑 CSV/JSON 解析检查，再进游戏走一轮重点节点。

## 验收标准

- 错证反应中，纯攻略提示不超过一半。
- 凌瑶至少 40% 的出场用于闲聊、降压、关系推进或生活观察，而不是直接提示。
- 陆昭每个大阶段至少有一次抱负、脆弱或温热坚定的表达。
- 沈清月、阿贵、老范、钱里正、王大爷、周氏不看 speaker 也大致能分辨。
- 每个主要阶段至少有一个“可截图”的角色反应。
- 最终对峙仍然严肃，沈清月的法理压迫不被削弱。
- CSV 可解析，嵌套 JSON 字段可解析。
