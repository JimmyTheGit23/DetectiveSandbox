# 台词改写执行计划

## 目标

在不改动证据链、节点 ID、条件解锁和对峙流程的前提下，把序章台词从“逻辑清楚”推进到“角色一开口就有辨识度”。方向是古风逆转感：严肃推理保留，失败反馈、助手吐槽和 NPC 怪味加强。

## 对比诊断

当前序章已经能和《逆转裁判》对比的部分，是证据链层层推进、最终对手会反击、助手会在关键时刻提示玩家。但差距也很明确：原台词有时太像“攻略说明”，角色不看 speaker 时辨识度不够；陆昭太稳，少了成步堂式的狼狈自嘲；凌瑶有活力，但部分提示缺少她自己的镖局经验；普通 NPC 的口癖系统还不够稳定。

改写目标不是照搬现代法庭喜剧，而是拿它的节奏：一拍角色反应，二拍逻辑推进，三拍可截图的反击或吐槽。最终对峙保持严肃，让沈清月像会拆证据的 Boss，而不是等着玩家出示答案的木桩。

## 硬规则

1. 先保流程，再改语气。不得改 `npc_id`、`node_id`、`statement_id`、`evidence_id`、`requires`、`record_id`。
2. 每个主要 NPC 至少有 3 个可复用的口癖、动作或比喻系统。
3. 凌瑶不能连续多句只做攻略提示。提示要先有角色反应，再给方向。
4. 陆昭不能永远冷静无损。每个大阶段至少保留一次疲惫、尴尬、被噎住或被误解后的冷幽默。
5. 动作描写归旁白或内心，不挂在角色 speaker 下，避免角色“说出自己的动作”。
6. 最终对峙不硬塞笑点。沈清月的压迫感优先，喜剧只做边缘反衬。

## 角色发动机

| 角色 | 发动机 | 改写方向 |
| --- | --- | --- |
| 陆昭 | 冷推理、官场克制、落水后狼狈 | 保持短句，但增加被冤、失印、寒水记忆带来的冷幽默 |
| 凌瑶 | 镖局经验、嘴快、护短 | 错证反应先吐槽再提示，闲聊多给无用但可爱的个人反应 |
| 阿贵 | “小的”面具、假哭、怨气爆裂 | 前期卑微，证据击中后逐步露出“我”的裂缝 |
| 老范 | 烟杆、船话、江上俗语 | 撒谎时话变多，烟杆动作变急，借水路俗语绕开问题 |
| 钱里正 | 基层免责、公文腔、和稀泥 | 每次说话都像在给自己留退路，八卦时才漏真话 |
| 王大爷 | 短句、渔网、硬骨头 | 少解释，多钉子句，关键回忆才放长句 |
| 周氏 | 账本、家计、旧物 | 悲伤与精明并存，用商人妻视角讲复杂感情 |
| 沈清月 | 法理、算盘、冷笑 | “指向/证明”是核心武器，动作描写移出她的台词 |

## 执行顺序

1. `testimony_wrong_reactions.csv`：让失败反馈更像角色交锋。
2. `dialogue_lines.csv` / `confrontation_lines.csv`：修正动作描写归属。
3. `companion_banter.csv` / `companion_discussions.csv`：给凌瑶增加更多非功能性回调。
4. `dialogue_lines.csv`：逐个 NPC 加强口癖和行为梗。
5. `testimony_press_lines.csv` / `testimony_break_lines.csv`：把按压和击破写成三拍节奏。
6. 最后跑 CSV/JSON 解析检查，再进游戏走一轮重点节点。

## 验收标准

- 错证反应中，纯攻略提示不超过一半。
- 沈清月、阿贵、老范、钱里正、王大爷、周氏不看 speaker 也大致能分辨。
- 每个主要阶段至少有一个“可截图”的角色反应。
- 最终对峙仍然严肃，沈清月的法理压迫不被削弱。
- CSV 可解析，嵌套 JSON 字段可解析。
