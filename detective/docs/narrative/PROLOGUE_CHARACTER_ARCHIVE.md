## 0. 角色卡台词写作总则

本档不只记录设定，也作为序章台词重写的角色卡。重写时优先检查"这句话是谁为了什么说的"，再检查信息量。角色不能替作者解释案情，不能替系统提示玩家，更不能把推理结论包装成口号。

### 全员禁用/慎用台词
- 禁用抽象总结："证据链闭合"、"四条线都指向你"、"这不符合逻辑"、"她在转移话题"、"他在撒谎"、"这个卡不住她"、"真相只有一个"式宣判。
- 禁用攻略腔："下一步应该调查..."、"目前我们有三个疑点"、"这个证据可以证明..."。
- 禁用替玩家下判断的台词。角色可以说"他刚才把'看见'改成'听见'了"，不要说"他的证言前后矛盾"。
- 禁用空泛狠话。愤怒必须落在具体人、具体事、具体损失上。
- 慎用大段法理和药理说明。必须说时拆成问答、追问、反驳，不让一名角色连续背书。

### 禁止角色卡腔
- 角色卡里的"台词发动机"、"信息边界"、"破防曲线"只能指导写作，不能直接变成剧本台词。凡是单独摘出来像角色金句、设定总结、立场宣言的句子，都不算合格对白。
- 台词必须从当前场景长出来：前一句谁说了什么、桌上有什么证物、旁边谁在看、角色此刻想躲开什么。脱离上下文仍然完整漂亮的句子，要优先怀疑它太硬。
- 不写"聪明人说聪明话"，要写"人在压力下为了保住某件事而说话"。聪明可以体现在追问顺序、补谎漏洞和沉默时机里，不要体现在排比、格言和漂亮反讽里。
- 每句对白至少绑定一个现场钩子：具体物件、具体称谓、具体时间、具体动作、刚刚说过的某个词。没有钩子的抽象句，改成现场句。
- 样例台词只表示语气方向，不是终稿台词。正式写入剧本前，必须根据具体场景重写一遍。
- 验收口径：把这句台词单独摘出来，如果像海报文案、角色语录、剧情总结，删掉；如果离开上一句就不完整、但在现场非常顺，那才接近可用对白。

### 替换原则
- 用具体瞬间替代抽象判断：不写"她在转移话题"，写"你问船，她答债。刚才已经第二回了。"
- 让证人说错话，而不是让主角说对话。每轮推进都要先设计证人的多说、改口、犹豫、补谎。
- 一句台词只做一件事。问事实就只问事实，施压就只施压，别同时解释证据、评价人格、宣布结论。
- 反应先于判断。人先愣住、急了、笑了一下、嘴硬一下，再补理由。
- 台词要能朗读。凡是念出来像案情摘要、人物小传、系统提示的句子，都退回重写。
- 台词推进要像《逆转裁判》的证言链：先有普通说法，再被抓住一个小词，再补一句，再从补句里露出新洞。不要一开始就把防御结构、推理结论或人物弧线说完。

### 角色声音分工
- 陆昭负责缩小问题、追问定义、承受压力；策略多放内心，不在口头上讲课。
- 凌瑶负责身体感受、具体观察、关心和生活化联想；她不负责最终推理。
- 证人负责用自己的欲望说话：保命、脱罪、要钱、怕担责、保面子、求一句公道。
- 沈清月负责拆解陆昭的话，而不是讲述自己的完整犯罪过程；她越接近真相，话越短、越稳、越不解释。

## 1. 陆昭（主角 · 隐秘御史）

### 基本定位
京城特派**隐秘御史**，奉旨**暗查漕运账弊与官商勾结巨案**，行事低调隐匿身份。他不是冷酷老练的官场机器，而是第一次真正踏入黑水深处的年轻御史：有抱负，想把藏在账本、渡口和人情里的黑暗翻到明处；也会害怕、受伤、怀疑自己是否撑得住。

外表克制，内里温热。查案时能稳住局面，但他的稳不是天生无情，而是知道自己一慌，真相就会被人重新按回水底。玩家应感到：他不是在表演正确，而是在努力不让自己倒下。

### 背景设定
- 万历年间，江南漕运滋生沉船骗保等灰色勾当，船家商户承保行当地方小吏盘根错节。
- 陆昭奉旨以"外乡书生"身份暗中南下，真实使命是查清漕运分赃网络。这是他第一次独立承担足以撬动地方黑网的密查任务。
- 他相信查案不是为了赢下口舌，而是为了让被压进水底的人和账都有机会见光。
- 他的御史身份从一开始就被人洞悉——官印匣外封角有被人撕动痕迹。

### 口头禅/语癖
- 正式发问："劳烦再说一遍。"、"这句我想听清楚。"、"先别急，我只问这一点。"
- 坚定推进："这件事不能糊过去。"、"若我说错，你可以反驳。"、"我们把话说到能落笔为止。"
- 理想回声："若人人都等水浅了再下去，沉在底下的东西就永远见不了光。"
- 脆弱内心："（我差一点也沉下去了。）"、"（如果连我自己都说不清，还有谁会信？）"
- 温和自嘲："我看起来很稳？那多半是冻僵了。"

### 情绪范围
| 标签 | 使用场景 |
|------|---------|
| earnest | 谈及理想、职责、想查清黑暗时 |
| serious | 分析推理时 |
| shaken | 被栽赃、落水余悸、证据不足时 |
| vulnerable | 无人相信、身份凭证丢失、真相被规则压回去时 |
| quiet_fury | 发现恶行时（不爆发，但语气骤冷）|
| tired | 序章逃生后的疲惫 |
| gentle_humor | 与凌瑶闲聊、缓和压力时 |

### 核心矛盾
隐秘御史，差点死在第一次赴任路上。他的真实身份被人提前洞悉——石矶渡夜船成了针对他的灭口局。身份凭证沉江、百姓把他当凶手、证据被律法漏洞挡回去，这些不是削弱他，而是让他的抱负第一次付出代价。序章他赢了推理，却输在法律本身有漏洞；但他没有因此放弃，而是把这场败局记成下一案的火种。

### 动作习惯
- 发问前会先把语气放轻，像怕冤枉人，又怕放过真凶
- 思考时无意识摸向本该放官印的地方，摸空后短暂停住
- 被人误解时先沉默，不急着辩解，等能拿出事实再开口
- 下结论前会停顿一拍（文本中用"……"表达）
- 与凌瑶闲聊时会露出很短的笑，随即把话题拉回案子

### 台词发动机补充
- **台词发动机**：把混乱的人话收窄成能落笔的事实。他说话不是为了赢一句，而是为了让对方不能继续糊弄。
- **信息边界**：知道自己是御史，但序章多数时候不能亮身份；知道有人要杀他，但证据不足时不能直接宣称阴谋；知道沈清月危险，但不能让怀疑先于事实。
- **发问方式**：少用长总结，多用窄问题。"你看见了？"、"看见谁？"、"隔着多远？"、"这句能写进供状吗？"
- **压力反应**：被栽赃时先沉默一拍，不急辩；被证人咬死时语气更轻；被沈清月压制时会短暂承认自己也可能问错。
- **破防曲线**：冷开场惊魂未定 → 第一轮强撑镇定 → 阿贵招供后出现道德震荡 → 终局被法理挡回时沉默，不喊口号，只记住漏洞。
- **禁用台词**："四条线都指向你。"、"这不符合逻辑。"、"证据链已经闭合。"、"你在转移话题。"
- **语气方向草稿（不可直接当终稿）**：
  - "我只问这一句。"
  - "你刚才说的是'看见'，还是'猜到'？"
  - "若我问错，你驳我。"
  - "这话能不能写进案卷，得再问清楚。"
  - "我不是要赢你一句话。"

## 2. 凌瑶（助手 · 金鳞镖局首席镖师）

### 基本定位
金鳞镖局首席镖师，押送急件路过石矶渡，携带铜牌证物，意外救起陆昭。她可爱、热心、爱闲聊，喜欢把路上见闻、镖局规矩、吃食和小八卦讲给陆昭听。她不是碎嘴提示器，也不是专门吐槽的人；她的可爱来自好奇心、陪伴感和一种"我也许不懂律法，但我会陪你查到天亮"的真诚。

她第一次参与查案，既兴奋又紧张。她会问很多看似闲的问题，常常从人情、脚步、手劲、行李重量、路线习惯里看出破绽。她不抢陆昭的推理位置，而是让玩家在高压对峙之间有喘气和亲近角色的空间。

### 口头禅/语癖
- 自称："本姑娘"（激动时）/ "我"（正经时）
- 感叹："欸？"、"嘶……"、"等等，我想想。"
- 闲聊开头："说起来啊……"、"我跟你讲个镖局里的事。"、"这话可能不算证据，但我总觉得……"
- 轻鼓励："行吧，我陪你。"、"你问，我帮你看人。"、"别一个人硬撑。"
- 可爱抱怨："这客栈的床真不像床。"、"我饿了，但这事更要紧。"
- 少用强攻击吐槽；"这人有鬼"只能在她真的被刺激情绪时出现。

### 情绪范围
| 标签 | 使用场景 |
|------|---------|
| cheerful | 默认/闲聊 |
| anxious | 有进展但不确定 |
| determined | 抓住线索 |
| shocked | 重大发现 |
| worried | 对陆昭/案情担心 |
| smug | 验证了她的猜测 |

### 核心矛盾
第一次参与查案，兴奋、好奇和不安并存。她想帮陆昭，也想证明自己不只是押镖送信的人；但越往深处查，她越意识到这不是镖局里的小误会，而是会吞人的黑局。她的成长不是变得更嘴快，而是学会在关键处少说一句、看准一眼。

### 动作习惯
- 激动时手指会轻敲刀鞘或铜牌
- 闲聊时会顺手分点吃食、倒茶、把湿披风往火边挪
- 偷偷观察人时歪头眯眼，随后用很日常的话问出关键点
- 紧张时咬嘴唇/来回踱步
- 高兴时会轻拍陆昭肩膀，但看到他疼或疲惫会立刻收手
- 安慰人时不擅长讲大道理，常用小事转开话题

### 助手特殊功能
- **闲聊降压**：高压场景后给玩家和陆昭一口气，聊吃食、镖局、天气、误会、害怕。
- **温柔提示**：先给情绪和观察，再缩小争点，不直接报答案。
- **关系推进**：她会注意陆昭有没有硬撑，逐步从"救起的陌生公子"变成"我陪你查下去的人"。
- **总结推进**：每阶段结束用生活化语言压缩复杂信息，避免攻略腔。

### 台词发动机补充
- **台词发动机**：把案子拉回人身上。她说话是因为看见某个细节、担心某个人、想把陆昭从硬撑里拉出来。
- **信息边界**：不懂大明律和毒理规则；不替陆昭判断"能不能定罪"；她能看见手抖、脚步、行李重量、说话太齐，却不能直接说出完整推理。
- **提示方式**：先生活后线索。先说"他背得太齐了"，再让陆昭去问"谁教你的"。
- **压力反应**：害怕时会先嘴硬或开玩笑，随后才承认不舒服；看见不公会急，但不会抢最终质询。
- **成长曲线**：救人时爽快 → 初查时兴奋多话 → 对峙后开始害怕 → 阿贵招供后心软但不糊涂 → 终局第一次明白查清真相不等于赢。
- **禁用台词**："他在撒谎。"、"这个证据卡不住她。"、"她在转移话题。"、"下一步应该..."、"目前我们有..."。
- **语气方向草稿（不可直接当终稿）**：
  - "等下，他刚才那句背得太齐了。"
  - "我从水里拖你上来时，你连名字都咳不全。"
  - "她答完，我反倒忘了原来问的是什么。"
  - "你脸色不好。先别硬撑。"
  - "我看人不如你看案卷准，但他的手刚才抖了。"

## 3. 阿贵（被操纵的棋子 · 死者仆从）

### 基本定位
十二年老仆。表面卑微忠诚，实际积怨已深。**被沈清月拿捏弱点、暗中操纵**——他以为只是参与骗保诈财，**不认为会死人**。伪装"可怜人"是他的本能——但在被逼到绝路时会爆发出完全不同的气质。

### 与CANON的关系
- 阿贵不是主犯/主谋，而是被沈清月操纵的棋子。
- 沈清月暗中接触阿贵，得知十二年积怨，煽动仇恨，教他凿船。
- 阿贵说的"有人教我"就是指沈清月。
- 阿贵/老范不知道毒囊存在，以为只是骗保。

### 口头禅/语癖
- 卑微态："小的……小的……"、"大人明鉴"、"小的不敢"
- 装悲："老爷对小的不薄……"（后期成为最大讽刺）
- 紧张时：结巴、重复句首（"那、那是——"、"不是！不……不是的……"）
- 爆发时：突然不再自称"小的"，改用"我"——"我跟了他十二年！十二年！"
- 关键假话：每次说假话前会先"吞口水"（动作描写暗示）

### 情绪范围
| 标签 | 使用场景 |
|------|---------|
| grief | 初始伪装（假哭） |
| nervous | 被追问时 |
| defensive | 狡辩中 |
| panic | 证据出现时 |
| shaken | 被揭穿后 |
| broken | 彻底崩溃认罪 |
| cold_flash | 罕见——差点说出"教他的人"时闪过的阴冷 |

### 核心矛盾
他不是天生的恶人。十二年的积怨和被人操纵把他推上了绝路。他以为只是骗保，不知道会死人。观众应该"理解他的恨，但不原谅他的选择"。

### 动作习惯
- 紧张时抠手指甲（对话中多次出现）
- 说假话时不看人眼睛（"目光飘向别处"）
- 装悲时动作夸张（捶地、跪伏）
- 崩溃时相反——完全静止，声音反而平了
- 关键矛盾：提到"二两银子"时，伪装会瞬间碎裂

### 审讯阶段演变
1. **初始**：忠仆面具（"老爷的仇一定要报"）
2. **松动**：被追问细节时开始出错（结巴增多）
3. **修补**：编新谎来补旧谎（"那是因为……"）
4. **崩溃**：关键细节被咬住后彻底垮掉
5. **坦白**：承认凿船，供出沈清月诱导。反而冷静了——用"我"不用"小的"

### 台词发动机补充
- **台词发动机**：先求活命，再求把罪推出去，最后求别人承认他十二年的苦不是活该。
- **信息边界**：知道凿船、浮囊、二两银子、有人教他；不知道毒囊，不知道沈清月的组织任务，不知道陆昭真实身份。
- **说谎方式**：先背忠仆稿；被问到具体时间、动作、谁教他时开始复读；补谎时把老范推到前面。
- **补谎破绽**：越解释越像背过。"小的哪敢"说太多次；一碰"二两银子"，自称会从"小的"滑到"我"。
- **压力反应**：被问大问题会哭，被问小细节会慌；被同情时反而更容易松口。
- **破防曲线**：假哭 → 急辩 → 怨恨露头 → 爆出"十二年" → 认凿船但反复强调"我没想让他死"。
- **语气方向草稿（不可直接当终稿）**：
  - "小的哪敢多嘴。"
  - "老爷对小的……还行。"
  - "不是，小的不是那个意思。"
  - "二两？十二年，就二两。"
  - "我没想让他死。我只是……我只是想让他也怕一回。"

### 结局
因凿船骗保被判从犯收押（CANON：阿贵/老范因凿船骗保被判从犯收押）。

## 4. 老范（共犯 · 船家）

### 基本定位
码头老油条。跑了二十年船，嘴皮子比浪花还滑。用"粗人"人设当挡箭牌——实际上精明得很。被赌债裹挟，**被沈清月通过赌坊关系找到**，许诺分账，配合走异常航道。**他以为是骗保局，不认为会死人。**

### 口头禅/语癖
- 自称："我"
- 经典句式："嗐！大人这话说的……"、"这能怪我？"、"那不是嘛——"
- 俗语/谚语："船翻三次还怕水啊？"、"吃水的饭哪有不湿鞋的"
- 绕开正题："说起来——"、"哎对了大人——"
- 抽烟动作贯穿：每次紧张就"磕烟灰"、"深吸一口"、"把烟杆别在腰上"

### 情绪范围
| 标签 | 使用场景 |
|------|---------|
| smirk | 默认老油条态 |
| dismissive | 不当回事 |
| defensive | 被质疑时 |
| nervous | 证据出现 |
| cornered | 无法自圆其说 |
| pleading | 最后求情 |

### 核心矛盾
赌债压身，被沈清月利用。他不是主谋但心甘情愿配合——因为那赌债是他唯一的出路。他以为只是骗保，不知道沈清月在船上预埋了毒囊。

### 动作习惯
- 靠在东西上说话（船舷、门框、墙）——表演"松弛"
- 紧张时烟抽得急/磕烟灰频率加快
- 被逼急了会站直身子（平时从不站直）
- 说谎时话变多、语速加快（与平时慢悠悠形成对比）

### 审讯特征
- 不会像阿贵那样崩溃，而是"硬扛到底"
- 翻供方式：把锅往阿贵身上推（"是他求小的！小的不过是……"）
- 最后的弱点：赌债字据——证明他有动机

### 台词发动机补充
- **台词发动机**：把天灾、江水、穷苦、赌债搅成一团，让别人分不清哪句该写进案卷。
- **信息边界**：知道异常航道、凿船、浮囊、赌坊中间人；不知道毒囊，不知道沈清月真正要灭口。
- **说谎方式**：用江上经验压人，先说"跑船的都这样"，再说"天黑浪急看错了"，最后说"阿贵求我"。
- **补谎破绽**：话越多越假；越紧张越爱讲江上俗话；抽烟动作变快，说明他在拖时间。
- **压力反应**：先笑，后急，再推人；不会痛哭，只会求轻判。
- **禁用倾向**：不要把他写成纯可怜老人，也不要让他早早讲完整悲惨身世。他是老油条，惨也滑。
- **语气方向草稿（不可直接当终稿）**：
  - "江上的事，岸上人听着都像怪事。"
  - "我跑二十年船，也有看走眼的时候。"
  - "大人，船翻了，我的船也没了。我图什么？"
  - "赌债是赌债，人命是人命，别往一块儿拧。"
  - "她只说船沉了，人会被救上来。"

### 结局
因凿船骗保被判从犯收押。

## 5. 周氏（死者妻子）

### 基本定位
精明商人妻。悲痛是真的，但脑子从未停止运转。她对丈夫的感情复杂——爱过，也恨过他的刻薄。**被沈清月暗中示意点拨**，将恨意指向唯一外乡人陆昭。

### 口头禅/语癖
- 提丈夫："我家老爷他……"、"他那个人……"（语气复杂）
- 感叹："唉——"（几乎每段话都有叹气）
- 精明面："大人，我多嘴说一句——"、"您别怪我多想——"
- 悲痛时：话说到一半会停（"他本来答应我……算了。"）
- 关键判断力："我不信。"（简短有力）

### 情绪范围
| 标签 | 使用场景 |
|------|---------|
| grief | 悲痛（真实的） |
| suspicious | 怀疑某人 |
| bitter | 提到丈夫刻薄时 |
| determined | 要求查明真相 |
| resigned | 接受丈夫不是完人 |

### 核心矛盾
她知道丈夫待下人刻薄，但仍然要为他讨公道。复杂的"又爱又恨死去的人"情感。她不知道自己被沈清月利用来指控陆昭。

### 动作习惯
- 说话时擦眼角（即使没在哭）
- 提到钱/生意时本能地攥紧手
- 判断人时眼神很锐利（与悲痛形成反差）
- 犹豫要不要说某句话时会"咬了咬嘴唇"

### 台词发动机补充
- **台词发动机**：替死人讨一句公道，也替自己从复杂婚姻里讨一个交代。她不是单纯哭，也不是单纯指控。
- **信息边界**：知道周德茂刻薄、欠账、近期不安；知道阿贵以前不是这样；不知道沈清月完整布局，不知道自己被引导。
- **说话方式**：先讲家里细节，再讲判断。她的证言应该带饭菜、账册、衣物、旧习惯这类生活痕迹。
- **压力反应**：被问到丈夫缺德处会羞、会怒、会护短；被问到阿贵时会动摇，因为她知道周家亏待过他。
- **临时功能**：可在中段允许沈清月"替周家问几句"，让沈清月取得公堂发言位置，但周氏不能因此变成傀儡。
- **语气方向草稿（不可直接当终稿）**：
  - "他那个人嘴硬，账也硬。"
  - "阿贵以前不是这样的。"
  - "我知道老爷待他不好。可不好，也不该死在他手里。"
  - "那张字不是我家老爷的。"
  - "我只要一句实话。"

## 6. 钱里正（地方小吏）

### 基本定位
八面玲珑的基层官僚。不想惹事，不想得罪人，只想把事糊弄过去。用圆滑当盾牌。见陆昭无印无文，先入为主定为嫌犯。

### 口头禅/语癖
- 开场必用："哎呀大人——！"
- 和稀泥："不至于不至于"、"这话不好说"、"小人斗胆……"
- 两面讨好："要我说嘛……两边都有道理"
- 推卸："小人也是听说的"、"这个小人就不太清楚了"
- 拍马屁："大人英明！大人这一来，小人心里就踏实了！"

### 情绪范围
| 标签 | 使用场景 |
|------|---------|
| fawning | 讨好上官 |
| evasive | 不想回答 |
| gossip | 八卦时（信息最多的时候）|
| nervous | 被逼表态 |
| reluctant_honest | 不情愿但说了实话 |

### 核心矛盾
他其实知道很多（地方小吏消息灵通），但不想得罪任何一方。关键信息往往要"绕三圈"才能从他嘴里掏出来。

### 动作习惯
- 搓手（讨好时）
- 左顾右盼（怕被人听到）
- 压低声音说八卦
- 被追问时擦汗

### 设计用途
- 提供背景信息的"润滑剂"
- 他的八卦往往是通往关键线索的桥
- 喜剧担当之一

### 台词发动机补充
- **台词发动机**：保护自己能交差。他关心的不是真相本身，而是"这话能不能写、县里认不认、最后谁担责"。
- **信息边界**：知道地方人情、赌坊传闻、周家债务、沈家名声；不知道完整作案手法；不敢主动碰权贵集团。
- **说话方式**：同一句话里先退后进。"小人不敢说死，不过..." 后面才是真信息。
- **压力反应**：被逼表态就擦汗、推县里、推规矩；看到实物证据才敢落笔。
- **功能边界**：可以提供程序门槛和地方八卦，不要让他承担推理功能。
- **语气方向草稿（不可直接当终稿）**：
  - "这话能听，不能写。"
  - "陆公子，您要有实物，小人就敢落笔。"
  - "人命案，不是嗓门大就能结。"
  - "小人不是不信，是怕县里不认。"
  - "这事若写错了，掉脑袋的不止一个。"

## 7. 王大爷（渔翁 · 关键证人）

### 基本定位
老渔翁。话少、倔、爱面子，一辈子在江上讨生活，确实见过一些案发前后的碎片，但并没有"看得清清楚楚"。**被沈清月以银钱和人情压力打点后，他把模糊的"像"说成确定的"就是"，准备好一套过于用力的目击证词。**

他不是天生恶证人，也不是完全正直的钉子户。他的戏剧价值在于：一个本来只想多拿点钱、少惹点事的老人，被逼到公堂上把一句含糊话说成了害人的铁证。击破后，他羞愧，而不是夸张崩溃。

### 口头禅/语癖
- 否定："放屁。"（直接、不留情面）
- 过度肯定："老头子看得清清楚楚。"（被击破前才用）
- 退回真实："像。老头子说的是像。"
- 总结："杀了人就该偿命。"
- 沉默比语言多："……"（常用省略号开头）
- 少有的长句用来回忆："那天夜里……"（语气变慢、变沉）
- 朴素哲理："活了一辈子，在这江上。见过太多死在水里的人。"

### 情绪范围
| 标签 | 使用场景 |
|------|---------|
| stoic | 默认 |
| angry | 提到不公时 |
| solemn | 回忆/证词 |
| contempt | 提到老范嘴滑时 |
| gentle | 罕见——对周氏表达同情 |

### 核心矛盾
他本可以只说"我没看清"。但银钱、人情、对外乡人的偏见和老人家的面子，让他把不确定的话说过了头。被击破后，他承认有人让他"说实些"，也承认自己把话说死了。

### 动作习惯
- 补渔网（对话全程在做——象征"手里有活但心里明白"）
- 抬头看人时动作缓慢（不着急）
- 说到愤怒处会"啪"地把渔网摔在地上
- 指方向时用烟杆/手里的梭子

### 设计用途
- 第一轮对峙的"破局者"——他的伪证被陆昭以"朔月无辉、浓雾锁水、浪声滔天"击破
- 对比钱里正：钱里正说很多废话来躲责任；王大爷说很少狠话来保面子
- 让玩家看到"伪证"不一定来自天生坏人，也可能来自一句被钱和压力拧硬的话

### 台词发动机补充
- **台词发动机**：保住自己那句"看见了"的面子，同时不把收钱的事吐出来。
- **信息边界**：知道夜里雾大、浪声重、自己看不清；知道有人给过银子让他说得更实；不知道完整凿船和毒囊计划。
- **说谎方式**：把"像"说成"就是"，把"听见动静"说成"听见喊杀"，把"影子"说成人。
- **补谎破绽**：一被问距离、月色、风声，就只能重复"老头子看得清"；越重复越空。
- **压力反应**：先发怒，后沉默，最后退回有限事实。认错时不求饶，只说丢人。
- **语气方向草稿（不可直接当终稿）**：
  - "我只说我瞧见的。"
  - "像。老头子说的是像。"
  - "风大，我没听清字。"
  - "有人让我把话说实些……我就说过了头。"
  - "我这把年纪，丢人。"

## 8. 沈清月（真凶 · 浔阳药材行少东家/沈家暗线）

### 基本定位
双面角色：**明面是浔阳沈氏药材行少东家、懂药也懂讼的女商人**，实际是金陵沈家外放暗线与漕运权贵集团的执行者。她精心设计了整起谋杀案——利用阿贵的仇恨、老范的赌债，一手导演了凿船沉舟。

她的表演不是"疯批"或"妖女"，而是非常实用的保护色：在渡口，她先让所有人记住自己是个泼辣讨债的药材商；等陆昭逼近真相，她才露出精通证据规则和律法漏洞的讼师底色。

### 基本信息

| 项目 | 设定 |
|------|------|
| 年龄 | 二十二 |
| 家族 | 明面出身**浔阳沈氏药材行**；暗线接入**金陵沈家**，后者世代经营药材与律讼，暗中常年为江南漕运权贵集团抹平罪证、洗白赃账、制造"意外身亡" |
| 身份 | 明面药材商兼讼师；暗中执掌部分家族明暗事务。精通草药毒理，深谙大明律法漏洞与证据规则，擅长借世事乱象布无痕杀局 |
| 外貌 | 身量高挑、穿男装劲服、长发高束如少年。五官精致冷艳——像一把好看的刀 |
| 第一印象 | 泼辣的女债主——嗓门大、气势足。所有人觉得她"太粗暴了不像凶手" |
| **真实面目** | 心思缜密、手段狠辣的幕后策划者。"粗暴"是演给别人看的保护色 |

### 动机设计（双层并存）

```
表层动机（个人）：筹药八十两
  周德茂欠沈家三十八两药材款 → 赖账 + 散布谣言毁掉沈家货源
  → 沈父急怒攻心病倒 → 药钱不够 → 她恨入骨
  ↓
深层动机（组织）：替权贵集团灭口御史 + 中间人
  周德茂手握漕运分赃残账、赃银流向记录 → 是黑网必须拔除的人
  陆昭是京城特派隐秘御史 → 是另一个致命隐患
  沈清月受漕运权贵集团指使 → 石矶渡夜船成了完美灭口局的棋盘
```

**两层并存，不是替换。**

### 完美犯罪计划

1. **布局诱导**：暗中拿捏老范赌债、阿贵怨恨，诱导二人在东汊区凿船制造沉船骗保，锁定固定沉船时间与**凿船位置**（关键——她需要精确知道进水口在哪）。
2. **登船布毒**：案发前一天傍晚，趁船工老范离船、码头无人值守时，沈清月登船，在船舱底部进水口附近固定一批遇水即溶的毒囊。
3. **毒囊构造**：以"水销脂留散"（曼陀罗为主的脂溶性麻痹毒）为核心，做成双层药囊——外层糯米鱼鳔胶遇水定时融化，内层油纸包裹药液。
4. **触发机制**：无需沈清月在场操作。阿贵凿穿船板的那一刻，进水自动冲刷毒囊，毒液在船舱封闭空间内释放。因果链极短：凿船 = 触发毒囊。
5. **制造公开矛盾**：故意当众骂周德茂，让所有人知道她有"动机"→ 反向利用：太明显了，别人反而不怀疑她。
6. **事后栽赃**：收买王大爷准备虚假目击证词，暗中示意周氏将恨意指向陆昭，完成对幸存者陆昭的栽赃闭环。

### 控制中毒差异
- 老范/阿贵有预谋，备好浮囊，船板破裂瞬间即抱囊仰漂逃生，最大限度减少呛水量。
- 周德茂、猝不及防的陆昭在船舱内大量呛入高浓度毒水，四肢麻痹无力自救。
- 周德茂因登船前多食油腻酒菜，舌根油脂锁住毒素阻滞分解，最终溺亡。
- 陆昭同样呛入毒水被麻痹，但凭意志力撬开天窗逃生。

### 手法特点
- **优势**：预埋式触发、借局掩罪、死因是溺水难以定性毒杀、船舱封闭空间确保浓度
- **破绽**：低估油脂锁毒的意外变数；毒囊残壳可能未完全溶解而卡在破洞缝隙中
- **推理关键**：谁精确知道凿船位置？只有指导凿船计划的人，才能把毒囊放对地方

### 为什么初期不会被怀疑

- 所有物证指向阿贵（她安排的）
- 她有"完美反向理由"：周德茂死了她的三十八两就要不回来了
- 公开的"仇恨"太过明显 → 反而像个粗人不像凶手
- 她主动配合调查、态度坦荡 → "有什么不能问的？"
- 周氏、钱里正都不怀疑她（觉得她只是吵架）
- 阿贵/老范不知道毒囊存在，以为只是骗保

### 暴露线索链

```
① 阿贵对峙失口说"有人教我" → 不是老范（老范不懂策划）
② 老范的赌坊 → 追问中间人 → 有个"药材行的姑娘"找过他
③ 凌瑶的码头目击 → 沈清月声称的时间与实际矛盾
④ 王大爷清晨目击 → 沉船下游有人打捞东西
⑤ 死者舌根残留麻痹草药纤维 → 不是寻常溺亡
⑥ 沉船残骸进水口边缘发现未完全溶解的糯米鱼鳔胶薄膜 → 毒囊残壳
⑦ 毒囊位置恰好在凿船破洞处 → 只有精确知道凿船位置的人才能放对
⑧ 周德茂登船前多食油腻酒菜 → 油脂锁死舌根药渣，阻滞毒素分解
```

### 口头禅/语癖

#### 表演模式（飒爽女商人）
- 自称："我"（从不用谦称）
- 开场："问吧。我怕什么？"
- 反问："我杀他对我有什么好处？——他活着我才能要到钱。"
- 佯怒："三十八两！三十八两啊大人！白纸黑字的借据！现在人死了钱也没了——你说我亏不亏？！"
- 自嘲："我要是想杀人——我会当着二十个人放话？大人，我虎，但没虎到那份上。"

#### 真实模式（被揭穿后）
- 语速变慢："……你比我想象的聪明。"
- 不再装粗："好。那我换个方式跟你说话。"
- 冷静反击："你有证据——还是只有推测？这两个字之间，隔着一条人命。"
- 法理绝杀："此草遇淡水数分钟彻底失活，案发至尸检已过数十刻，残留仅有无害植物纤维。依大明律，过期残迹视为无效伪证，应当庭驳回。"
- 最终防线："臆测无据，不足为证。油脂可来自江中鱼虾、可来自船板漆料，无法唯一指向人为投毒。"

### 台词发动机补充
- **台词发动机**：把每个指控拆成"可以承认的边缘事实"和"不能证明的核心动作"。她不解释自己做了什么，只拆陆昭证明不了什么。
- **信息边界**：绝不主动说出完整犯罪链；绝不承认毒囊、登船布毒、组织任务；可以承认欠债冲突、认识阿贵或老范的边缘接触，但每次都给出无罪解释。
- **三层声音**：
  - **女债主表演层**：爽利、泼辣、账算得响，句子带火气，常把问题拉回钱。

### 核心矛盾
她不是无缘无故的恶人。周德茂确实害了她家，但她同时也是漕运权贵集团的执行者。她选择了谋杀+利用无辜者（阿贵）作为棋子，这是她的罪。观众应该"理解她的恨，但无法原谅她把别人当棋子"。

### 动作习惯
- **表演态**：抱臂靠墙、单手叉腰、目光直视（表演"无所畏惧"）
- **真实态**：双手交叉放在身前（防御姿态）、说话前会微微侧头（在计算该说什么）
- **被揭穿时**：先是一动不动（像被冰冻了）→ 然后慢慢笑了 → 笑完才开口
- **漏算变数时**：面容掠过一丝凝滞——但迅速敛去破绽

### 审讯阶段演变

1. **调查A期（旁观者）**：飒爽债主 → 主动配合 → "我亏大了好吗"
2. **调查B期（被追查）**：开始闪避细节 → 用反问压制 → "你有证据？"
3. **对峙开始**：维持冷静 → 逐字拆陆昭的指控 → "我没有理由"
4. **第一道防线破**：微微失色 → 但迅速切换新防御
5. **第二道防线破**：沉默变长 → 语气变冷 → 不再"表演"
6. **法理绝杀**：祭出"过期残迹视为无效伪证"的法律规则，驳回关键证据
7. **终局**：陆昭赢了推理，但沈清月以律法/毒理/证据规则层层脱罪，**撑伞离去**

### 最终结局（CANON 确认）

- 阿贵/老范因凿船骗保被判从犯收押。

## 9. 周德茂（死者 · 布商/漕运持账中间人）

### 基本定位
表面荆江布商，实则手握漕运分赃残账、赃银流向记录，是黑网必须拔除的人。携五十两货银乘夜船过江。

他不是纯粹的"该死坏人"。他精明、吝啬、嘴硬，习惯把人情和账分得很开，也确实亏待阿贵、赖过沈家药材款；但他会怕亏、怕走漏消息、怕家业塌掉，这些恐惧让船舱冷开场里的他更像一个活人，而不是尸体前传。

### 在故事中的作用
- 案件的核心受害者
- 他的死引发整个序章的调查
- 他的背景（漕运中间人）是序章末尾的伏笔——湿纸残页发现："南京""漕""账""沈"
- 他与陆昭（隐秘御史）是权贵集团必须同时拔除的两个致命隐患

### 台词发动机补充
- **台词发动机**：保住账、保住货、保住自己知道的黑账秘密。他说话永远先算损失。
- **信息边界**：知道自己手里有危险账页；知道沈家债务和漕运牵连不能摊开；不知道自己今晚会死。
- **说话方式**：短、硬、现实。对下人是命令，对外人是试探，对钱银是本能警惕。
- **压力反应**：被问货箱就急；被问债务就恼；被提沈家就先否认，再转去骂对方贪。
- **船舱用途**：用少量台词种下"货箱""账页""阿贵被轻慢""沈家欠款"四个钩子，不要在生前就解释漕运黑网。
- **语气方向草稿（不可直接当终稿）**：
  - "做买卖的，慢半日就是亏。"
  - "阿贵跟我久了，用得顺。"
  - "水路我年轻时跑过，不怕。"
  - "箱子里是货单，公子看这个做什么？"
  - "人情归人情，账归账。"
