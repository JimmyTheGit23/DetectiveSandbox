## 第五批：禁用括号动作描述

### 本轮任务

| 项目 | 目标 | 落地方式 |
|------|------|---------|
| 清理所有括号动作描述 | 台词中不再出现`（手僵住）（看了她一眼）（捧碗，沉默片刻）`等括号内容 | 重写全部闲聊桥段为纯台词 |
| 确立铁则第6条 | 所有角色的动作/表情/心理状态必须通过台词本身传达 | 写入重构蓝图 §1·铁则 + 陆昭/凌瑶 Agent |

### 核心原则

**括号里的动作是演员和动画的工作——剧本只写台词。** 动作描写如`（掏出一块干饼）`通过台词暗示（"拿着"暗示递东西）；表情如`（微微一愣）`通过台词的停顿和措辞体现（"……我本来就是"里的"……"就是愣住的停顿）；心理如`（沉默片刻）`直接省略——沉默就是那行没有台词。

### 改动文件

- `重构蓝图.md` — 铁则增加第6条"不写括号动作" + 验收红线增加对应条款
- `陆昭.md` — 7段闲聊桥段全部重写为纯台词 + 铁则增加第6条
- `凌瑶.md` — 1处括号删除 + 铁则增加第6条

### 铁则第6条原文

```
6. 不写括号动作：严禁在台词中插入（动作描写）、（表情描写）、（心理活动）等括号注释。
   动作是演员和动画的事，表情通过台词节奏和选词传达——不是用括号告诉读者"他愣了一下"。
   发现任何括号即删除，重写为纯台词。
```
