# 序章台词重构蓝图

> 创建时间：2026-06-12  
> 目标：在保留《渡口沉舟》CANON 证据链与四轮对峙骨架的前提下，重构台词与局部节奏。重点不是逐句微调旧台词，而是按场景任务整组重写，让陆昭更有抱负与脆弱，让凌瑶更可爱、爱闲聊、少攻略腔。

---

## 1. 重构总原则

### 不做什么

- 不逐句比对旧台词做同义替换。
- 不把陆昭写成冷面万能推理机器。
- 不把凌瑶写成连续报答案的提示器。
- 不破坏 `node_id`、`statement_id`、`evidence_id`、`requires`、`record_id` 等数据骨架。
- 不改变序章结局：陆昭赢了推理，输在法律漏洞；沈清月不认罪，撑伞离去。

### 要做什么

- 先写“这一场的戏剧任务”，再写台词。
- 保留证据链，重写人物反应、场景呼吸和情绪递进。
- 每个高压对峙之间给陆昭和凌瑶一段可记住的关系推进。
- 每条提示先有人味，再有方向。
- 每个关键证据至少经历一次“意义变形”，而不是只作为答案按钮出现。

### 对白自然度

- 对白要像人在现场说话：短、明白，先反应，再判断。
- 少用漂亮比喻、抽象大词和谜语式台词；一句话不要同时承担设定说明、推理和抒情。
- 保留轻微古代语境，但不堆文言，也不使用过度现代的网络口语。
- 凌瑶可以可爱、爱闲聊，但闲聊要帮人物喘气或带出观察，不连续抢话。
- 陆昭可以说理，但说理前要有人味：迟疑、感谢、歉意、克制的怒意或落水余悸。

## 2. 新版人物发动机

### 2.1 陆昭

关键词：年轻御史、抱负、见光、被误解、硬撑、温热坚定。

陆昭不是“冷”，而是“尽量稳”。他想查清漕运黑网，因为他相信被压进水底的人和账都应该见光。他的脆弱不是软弱，而是让玩家知道他每次站稳都付出了代价。

台词方向：

```text
少用：
说。
继续。
这句话有矛盾。

多用：
劳烦再说一遍。
这句我想听清楚。
这件事不能糊过去。
若我说错，你可以反驳。
我不是要赢你一句话，我是要把这件事说到能落笔为止。
```

每个大阶段必须给陆昭一个情绪落点：

| 阶段 | 脆弱点 | 反弹点 |
| --- | --- | --- |
| 开场落水后 | 身份凭证沉江，没人信他 | “先把自己从嫌疑里救出来，再救真相” |
| 王大爷伪证 | 被乡民当作凶手 | 不急着辩白，先拆目击条件 |
| 老范对峙 | 发现骗保局比想象深 | 不把穷困直接等同罪恶 |
| 阿贵对峙 | 面对底层怨恨与真实委屈 | 理解怨，但不放过害人 |
| 沈清月终局 | 证据成立却被规则挡回 | 失败后记住漏洞，成为后续火种 |

### 2.2 凌瑶

关键词：可爱、闲聊、陪伴、镖局经验、好奇、少说准话、多问好问题。

凌瑶不是“嘴碎”，而是“愿意把沉重的事说得人还能喘气”。她喜欢闲聊，常从闲话里带出观察。她的提示要像陪玩家一起想，不像系统弹窗。

台词方向：

```text
少用：
方向不对。
这句要用某某证据。
他肯定有鬼。

多用：
欸？我有点没听明白。
这话可能不算证据，但我总觉得不顺。
我押镖时见过类似的人，他不是怕你问钱，是怕你问路。
行吧，我陪你。你问，我帮你看人。
```

凌瑶每次提示的顺序：

```text
闲聊/情绪反应
-> 镖局经验或生活观察
-> 缩小争点
-> 轻轻推一把，不直接报答案
```

## 3. 序章节拍表

### 3.1 楔子与船舱

| 场景 | 保留功能 | 新情绪目标 | 重写要点 |
| --- | --- | --- | --- |
| 冷开场沉船 | 建立危险、官印沉江 | 先给濒死感，不急着解释阴谋 | 陆昭可以慌、呛水、摸空官印；不要全程冷静观察 |
| 半个时辰前 | 交代密查漕运 | 建立青年抱负 | 写他第一次独立密查，想让黑账见光 |
| 船舱观察 | 预埋周德茂、阿贵、老范 | 从“侦探扫描”改成“年轻人不安” | 让他既认真记细节，又承认自己睡不安稳 |
| 凌瑶救人后 | 建立搭档关系 | 她先是救命恩人，再是助手 | 加短闲聊：湿披风、热水、他醒来第一句话 |

需要优先改：`prologue_lines.csv`、船舱阶段 `dialogue_lines.csv`。

### 3.2 第一轮：王大爷伪证

| 场景任务 | 当前风险 | 重写方向 |
| --- | --- | --- |
| 拆掉“陆昭上岸行凶”的假目击 | 陆昭容易像在做题，凌瑶像提示器 | 陆昭先受伤但不急辩；凌瑶用“昨晚我捞他时的样子”提供人证温度 |

情绪骨架：

```text
王大爷咬死目击
-> 陆昭短暂沉默，因为他知道没人信落水者
-> 凌瑶插入“我捞他上岸时他连站都站不住”
-> 陆昭把情绪收回，拆雾、浪声、昏迷时间
-> 王大爷从硬钉子变成不敢咬死
```

重点文件：`testimony_press_lines.csv`、`testimony_break_lines.csv`、`testimony_wrong_reactions.csv`。

### 3.3 第二轮：老范触礁谎言

| 场景任务 | 当前风险 | 重写方向 |
| --- | --- | --- |
| 从天灾转成人为凿船 | 老范与陆昭都是功能推进 | 陆昭不把赌债直接等同罪，体现公正；凌瑶用跑镖路线经验聊“绕路的人心里有第二张地图” |

情绪骨架：

```text
老范说天灾
-> 凌瑶闲聊式问路：跑镖最怕临时改道
-> 陆昭拆破洞与钉痕
-> 老范用穷困和江上经验自保
-> 陆昭承认穷不是罪，但凿船是选择
```

### 3.4 第三轮：阿贵逃生伪供

| 场景任务 | 当前风险 | 重写方向 |
| --- | --- | --- |
| 从侥幸逃生转成预谋参与 | 容易把阿贵写成单纯坏人 | 让陆昭对十二年压榨有真实触动；凌瑶少吐槽，多显出“心软但不糊涂” |

情绪骨架：

```text
阿贵哭诉忠仆
-> 凌瑶先心软一下，不急着骂假哭
-> 陆昭问遣散、二两银子、浮囊
-> 阿贵从“小的”滑到“我”
-> 陆昭说理解怨恨，但不能把别人拖进水里
```

### 3.5 第四轮：沈清月终局

| 场景任务 | 当前风险 | 重写方向 |
| --- | --- | --- |
| 真相成立但法理失败 | 容易只剩证据辩论 | 陆昭的抱负在这里被最重地打击；沈清月攻击的不只是证据，也是“年轻人以为真相足够”的信念 |

情绪骨架：

```text
沈清月承认局部事实，否定证明力
-> 陆昭一件件把钱、人、毒囊、油脂连起来
-> 凌瑶从兴奋变成不安：她第一次看见“查出来也未必赢”
-> 沈清月用法律漏洞脱身
-> 陆昭沉默，不喊口号，只记下她漏算的那一瞬
```

终局台词规则：

- 陆昭可以激动，但不要咆哮。
- 凌瑶不要抢最终推理，只负责情绪陪伴和最后的“不甘”。
- 沈清月不认罪，也不崩坏。她只露出极短凝滞。
- 结尾要落到“火种”，不是单纯失败。

## 5. 质量控制流程

每批 CSV 改写前，先写一张小表：

```text
场景：
保留证据：
本场情绪：
陆昭变化：
凌瑶变化：
NPC 面具：
结尾钩子：
```

每批改写后，做四类检查：

1. **数据检查**：CSV 可解析，嵌套 JSON 可解析，ID 不变。
2. **证据检查**：正确证据仍能命中正确 statement，错误反馈不误导。
3. **人物检查**：陆昭是否有抱负/脆弱/温热坚定；凌瑶是否可爱/闲聊/少攻略腔。
4. **节奏检查**：每 8 句内是否有新信息、新情绪或新问题；高压后是否有呼吸段。

验收红线：

- 若一段台词只是在旧句基础上换词，退回重写。
- 若凌瑶连续两句都是直接提示，退回重写。
- 若陆昭连续一整场没有情绪代价，只剩逻辑推进，退回重写。
- 若改动让沈清月提前认罪或让序章赢下她，退回重写。
- 若台词像口号、判词、谜语或网络段子，退回重写成现场能说出口的话。

## 6. 示例风格基准

### 陆昭：温热坚定

```text
[陆昭]
我不想冤你。所以这句必须问清楚。

[陆昭]
你可以说我多疑。但这船上死了人，活着的人每一句话都要经得起水冲。

[陆昭]
我查这案子，不是为了替自己赢一句清白。若真相被按回水里，下一条船还会沉。
```

### 凌瑶：可爱闲聊式提示

```text
[凌瑶]
欸，我说个不太像证据的事啊。
我们镖局赶夜路，最怕有人临时说“换条近路”。
近路通常不近，便宜通常不便宜。
老范那条东汊，也像这种话。
```

### 两人关系呼吸

```text
[凌瑶]
你刚才又摸腰侧了。官印还在江里呢，摸不回来。

[陆昭]
习惯了。

[凌瑶]
那换个习惯。你要是想确认什么还在，就叫我一声。
我人在。
```

### 错证反馈

```text
[凌瑶]
这东西能说明他心虚，但压不到这句话。

[陆昭]
嗯。嫌疑是一回事，能落笔的矛盾是另一回事。
```
