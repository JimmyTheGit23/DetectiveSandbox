# 序章台词重构蓝图

> 创建时间：2026-06-12  
> 目标：在保留《渡口沉舟》CANON 证据链与四轮对峙骨架的前提下，重构台词与局部节奏。重点不是逐句微调旧台词，而是按场景任务整组重写，让陆昭更有抱负与脆弱，让凌瑶更可爱、爱闲聊、少攻略腔。

---

## 1. 重构总原则

### 不做什么

- 不逐句比对旧台词做同义替换。
- 不把陆昭写成冷面万能推理机器。
- 不把凌瑶写成连续报答案的提示器。
- 不破坏 `node_id`、`statement_id`、`evidence_id`、`requires`、`record_id` 等数据骨架。
- 不改变序章结局：陆昭赢了推理，输在法律漏洞；沈清月不认罪，撑伞离去。

### 要做什么

- 先写“这一场的戏剧任务”，再写台词。
- 保留证据链，重写人物反应、场景呼吸和情绪递进。
- 每个高压对峙之间给陆昭和凌瑶一段可记住的关系推进。
- 每条提示先有人味，再有方向。
- 每个关键证据至少经历一次“意义变形”，而不是只作为答案按钮出现。

### 玩法结构·硬规则

#### NPC 对话菜单

- **每个 NPC 对话菜单最多 4 个问题。** 引擎允许在满足条件后用新问题覆盖旧问题，但序章重构原则上不使用超过 4 问的菜单压力。
- 序章 NPC 初始问题建议控制在 3 个，最多保留 1 个条件解锁位。条件解锁的新问题必须替代一个已经完成戏剧任务的旧问题，不能覆盖仍承载关键线索的问题。
- 每个问题必须有明确场景任务：要么拿信息，要么看反应，要么建立人物关系。不能为了“内容丰富”增加闲问。
- 关键线索不能藏在第 5 个及以后的问题里；玩家不应该因为菜单覆盖顺序错过必需信息。
- 每次 NPC 对话结束后，优先用 `after_talk_*` 或呼吸段消化信息，而不是继续给 NPC 菜单塞新问题。

#### 证词轮次

- **所有证词轮次的基础证词必须固定为 5 句。** 初始证词、修正证词、终局证词都按 5 条 statement 设计，不做 4 句或 6 句以上的证词循环。
- 每轮 5 句必须有分工：1 句立场/遮掩，2 句事实叙述，1 句补谎或情绪反应，1 句可被威慑或举证击穿的关键句。
- 后续轮次不能一开始把全部信息摊开。需要安排“威慑/追问某一句后才出现的新说法”，让证人因为被追问而修正证词。
- 威慑追加的信息不应把当前轮次堆成 6 句以上；触发后应进入“新版 5 句证词”或替换原有某句，保持当前可循环证词仍为 5 句。
- 每轮至少设计 1 个“威慑才露出的词”：如时间、距离、看见/听见、谁教的、在哪个位置、哪个物件。这个词必须能引出下一轮证词或下一步证据。
- 举证命中前，玩家应通过威慑感到“这句话不稳”；不能把正确答案藏成纯猜谜。

### 🔨 对白自然度·铁则（全角色适用）

**这不仅是风格要求，是强制性验收标准。每句台词必须通过以下五条测试，任意一条不通过即退回重写。**

1. **朗读测试**：出声念一遍，会不会磕巴？会不会像在背稿？——`任何念不顺的台词都重写。`
2. **现场感测试**：这句话是角色面对眼前的人、眼前的事、眼前的情境说的——还是像在对观众解释设定？——`"如你所知……""根据……"等向观众喊话的句式，直接删除。`
3. **反应先于判断**：人先有情绪反应（惊讶、停顿、迟疑、松了口气），再有理性判断。台词顺序必须遵循这个自然规律。——`不允许跳过反应直接下判断。`
4. **一句一事**：一句话只说一件事。不要同时承担"说明背景+推进推理+表达情感"。——`发现负担过重的句子就拆分。`
5. **不写判词**：台词是对话，不是审判词、不是标语、不是谜语、不是诗词朗诵。——`口号和谜语式台词属于NPC，不属于活人。`
6. **不写括号动作**：严禁在台词中插入`（动作描写）`、`（表情描写）`、`（心理活动）`等括号注释。动作是演员和动画的事，表情通过台词节奏和选词传达——不是用括号告诉读者"他愣了一下"。——`发现任何括号即删除，重写为纯台词。`
7. **不写分析腔**：严禁角色说出"完成态的总结判断"。真人从不这样说——你说不出"她每句都在把话题往她想要的地方带"，你只会说"刚才王大爷本来要说雾，她一句'债还没清'，王大爷就把话吞回去了"。——`能用具体瞬间说的，绝不用抽象总结。`

### 🔨 铁则第7条详解：反分析腔·感官对话

**问题根源**：角色在闲聊中对不在场的NPC做心理分析，听起来像两个调查员在写报告。

```
❌ 分析腔（像在工作汇报）：
"她不像在配合——她像在主持。她在控制房间。"

✅ 感官腔（像人刚出来时说的）：
"我手心出汗了。她没凶，没喊，但你就是气短。刚才王大爷想说雾，她一句
'债还没清'，王大爷话就吞回去了——你发现没有，你说话的方向会被她换掉。"
```

**三条转换规则**：

| 规则 | 说明 | 示例 |
|------|------|------|
| **用身体感受替代心理分析** | 不说"我觉得他心虚"，说"他手在抖""我手心出汗了""嗓子发紧" | ❌"她不躲问题，她把问题拆成别的问题" → ✅"她每次答完，你都忘了原来问的是什么" |
| **用具体瞬间替代抽象概括** | 不说"他每句话都在撒谎"，说"刚才问他落水时辰，他停了半拍——那半拍是全场他唯一没准备好的一下" | ❌"她想让众人只看债不看船" → ✅"她说债的时候你没注意——其他人全在点头。但船呢？没人提了。" |
| **陆昭不是凌瑶的注解器** | 不说"你在说她控制了整个对话"，说"我也感觉到了""我也会被她带偏""你说得对，下次只问一件事" | ❌A"她不像在配合" B"她在控制房间" → ✅A"她不像在配合" B"我也被带偏过。所以下次一次只问一件事。" |

**验收测试**：遮住名字读3句——能感受到两个人在交换各自的感受，还是在合作写一份调查报告？

**此铁则对所有角色同样生效：陆昭、凌瑶、沈清月、阿贵、老范、王大爷、周氏、钱里正。**

### 🔨 八条铁则第8条：凌瑶不分析策略，策略归陆昭内心独白

**问题根源**：凌瑶（助手）在对话中做策略分析（"她换题了""全屋在跟她走""我们下次把原题递回去"），这违反了逆转裁判的铁律——**助手只负责感受、困惑、关心，不负责策略。策略是主角的事，且优先放在内心独白。**

**逆转裁判真宵的台词只有三类，从不逾越：**

| 真宵说 | 真宵绝不说 |
|--------|-----------|
| "咦咦咦！" | "这个证人在撒谎" |
| "律、律师先生……？" | "你应该拿这个证据反驳" |
| "好可怜……""我也会帮忙的！" | "他换题了,你递回去" |

**对比我们凌瑶的越界台词：**

```
❌ 越界（凌瑶在做陆昭的工作）：
"她不躲问题,她把问题拆成别的问题。"      → 这是策略观察
"全屋在跟她走。我们自己不知道。"         → 这是战术复盘
"下次她换题,原题再递回去。"             → 这是制定方案
"他的破绽不在他说了什么,在他不敢说什么。" → 这是推理

✅ 凌瑶该说的话：
"她答完我又忘了问什么了——第三次了。"    → 困惑,不分析
"周娘子点头了,钱里正也点头了。为什么啊?" → 观察具体瞬间,不解释
"你还好吗？刚才你脸都白了。"             → 关心陆昭
"这个人我不知道怎么问。"                → 承认无助
```

**陆昭的策略必须放在内心独白，不放在对话里说出来：**

```
❌ 陆昭在对话中说策略（像老师讲课）：
"所以我们不能跟。下次她换题,原题再递回去。"

✅ 陆昭的对话反应：
"……我也被她带偏了。"                   → 先承认
"你嗓子干？我去倒水。"                   → 先关心

✅ 策略放入内心独白（玩家能看,角色没说出来）：
（她在换题。每次我问A她答B——下次她转方向,我就把原话再递回去。）
```

**四条硬性规则：**

1. **凌瑶只负责三件事**：身体感受 + 具体瞬间观察 + 困惑/关心/害怕。绝不做策略分析。
2. **陆昭在对话中**：先共情凌瑶、先关心凌瑶、先承认自己也被影响。策略最多一句,其余放内心独白。
3. **内心独白是陆昭的策略空间**：所有"接下来怎么打"的分析,写在一对括号里——这是玩家能看但角色没说的部分。
4. **对话里不解释"对方为什么这么做"**：只说"刚才他做了什么"和"我怎么了",不说"他做这个是因为……"。

### 🔨 铁则第9条：每段对话必须有案外生活

**问题根源**：逆转裁判的真宵和成步堂在查案间隙聊超人剧、办公室植物浇水太多、海报没名字、房租交不起——60%的对话跟案情完全无关。我们的角色对话却100%围着案情转。角色没有生活，就只是办案工具。

**逆转裁判骨架 vs 我们：**

```
逆转裁判:  无关生活(60%) → 轻触案情 → 无关生活 → 推进方向
           看超人剧        导演是谁？   海报没名字   去制片厂
           年龄斗嘴                    真宵浇水太多
           房租交不起

我们:      案情分析(90%) → 身体感受 → 案情分析 → 方向指示
           刚才说了什么     手心出汗    她怎么换题    先查码头
```

**每条 after_talk 必须植入至少 2 句案外生活**（腿麻、饿了、衣服没干、雨还在下、外面有人喊卖鱼、火盆快灭了、急件还压在怀里、天快黑/亮了），占对话比例不低于 30%。案情讨论必须从生活中自然渗出，不能从案到案。

> 违反自然度铁则的对白，即使逻辑正确、信息完整，也不予通过。

### 对白自然度·落实细则

- 对白要像人在现场说话：短、明白，先反应，再判断。
- 少用漂亮比喻、抽象大词和谜语式台词；一句话不要同时承担设定说明、推理和抒情。
- 保留轻微古代语境，但不堆文言，也不使用过度现代的网络口语。
- 凌瑶可以可爱、爱闲聊，但闲聊要帮人物喘气或带出观察，不连续抢话。
- 陆昭可以说理，但说理前要有人味：迟疑、感谢、歉意、克制的怒意或落水余悸。

## 2. 新版人物发动机

### 2.1 陆昭

关键词：年轻御史、抱负、见光、被误解、硬撑、温热坚定。

陆昭不是“冷”，而是“尽量稳”。他想查清漕运黑网，因为他相信被压进水底的人和账都应该见光。他的脆弱不是软弱，而是让玩家知道他每次站稳都付出了代价。

台词方向：

```text
少用：
说。
继续。
这句话有矛盾。

多用：
劳烦再说一遍。
这句我想听清楚。
这件事不能糊过去。
若我说错，你可以反驳。
我不是要赢你一句话，我是要把这件事说到能落笔为止。
```

每个大阶段必须给陆昭一个情绪落点：

| 阶段 | 脆弱点 | 反弹点 |
| --- | --- | --- |
| 开场落水后 | 身份凭证沉江，没人信他 | “先把自己从嫌疑里救出来，再救真相” |
| 王大爷伪证 | 被乡民当作凶手 | 不急着辩白，先拆目击条件 |
| 老范对峙 | 发现骗保局比想象深 | 不把穷困直接等同罪恶 |
| 阿贵对峙 | 面对底层怨恨与真实委屈 | 理解怨，但不放过害人 |
| 沈清月终局 | 证据成立却被规则挡回 | 失败后记住漏洞，成为后续火种 |

### 2.2 凌瑶

关键词：可爱、闲聊、陪伴、镖局经验、好奇、少说准话、多问好问题。

凌瑶不是“嘴碎”，而是“愿意把沉重的事说得人还能喘气”。她喜欢闲聊，常从闲话里带出观察。她的提示要像陪玩家一起想，不像系统弹窗。

台词方向：

```text
少用：
方向不对。
这句要用某某证据。
他肯定有鬼。

多用：
欸？我有点没听明白。
这话可能不算证据，但我总觉得不顺。
我押镖时见过类似的人，他不是怕你问钱，是怕你问路。
行吧，我陪你。你问，我帮你看人。
```

凌瑶每次提示的顺序：

```text
闲聊/情绪反应
-> 镖局经验或生活观察
-> 缩小争点
-> 轻轻推一把，不直接报答案
```

### 2.3 陆昭·凌瑶闲聊桥段设计

> 核心原则：每个高压对峙阶段之间，必须硬性植入至少一段陆凌闲聊。闲聊不是"填时间"，而是让玩家看见两个人在不查案时是什么样的——陆昭放下逻辑时的温热，凌瑶不用提示时的可爱，以及两人距离如何一步一步拉近。**所有闲聊必须满足：推动角色认知 + 流露关系温度 + 让玩家喘口气。**

#### 硬性植入点 × 7 段

| # | 时机 | 戏剧功能 | 切入方式 | 陆昭变化 | 凌瑶展示 |
|---|------|---------|---------|---------|---------|
| 1 | 落水苏醒后 | 建立"她先是救命恩人，再是助手" | 姜汤、湿衣服、他醒来第一句话 | 拘谨、不擅表达感激 | 照料型关心——用日常动作，不直接说"我关心你" |
| 2 | 王大爷伪证被拆后 | 凌瑶第一次认真认可陆昭 | "你那样问话的样子，像个真的查案的人" | 被"真的"这个词触动 | 观察力+笨拙但真诚的认可 |
| 3 | 老范出场前 | 镖局身份展示+强行关心 | "你饿不饿？""镖局规矩——赶路先喂人" | 不吃但接了饼→接受关心 | 用镖局经验当借口进行照料 |
| 4 | 老范败退后 | 凌瑶开始关心他内心感受 | "你查案子的时候，心里会难受吗？" | 承认会难受+原则不退缩 | 好奇心+情感深度萌芽 |
| 5 | 阿贵崩溃前 | **全序章最暖的关系锚点** | "你刚才又摸腰侧了……那换个习惯。你要是想确认什么还在，就叫我一声。我人在。" | 愣住→极短的笑→记在心里 | 观察入微+用俏皮话表达陪伴——不说"我支持你"，说"我人在" |
| 6 | 阿贵崩溃后 | 凌瑶消化"理解但不原谅"的复杂 | "他哭成那样……我差点信了" | 解释原则，但也看向凌瑶 | 从心软到学会不糊涂 |
| 7 | 沈清月登场前 | 决战前夜的温度 | "你今天已经把三句谎话都揭穿了……我陪你把这条链拉到头" | 极短的笑→"行" | 不喊口号，用"我陪你"兜底 |

#### 闲聊写作规范

1. **篇幅控制**：每段闲聊 4-8 句，绝不拖过长。闲聊是呼吸，不是正戏。
2. **切入点必须生活化**：吃食、天气、身体感受、镖局规矩——从最日常的细节入手。
3. **每段闲聊必须有一个"记忆点"**：一段对话后读者能记住的那一句（如"烫就对了，烫说明你还活着""我人在""赶路先喂人"）。
4. **陆昭的回应必须有递进**：从拘谨（只说"……烫"）→偶尔接话→露出短笑→主动回应凌瑶。全程不可跳过某个阶段。
5. **凌瑶不抢推理**：闲聊中她可以关心、好奇、困惑，但推理仍然属于陆昭。闲聊中绝不出现"你下一步应该查……"。
6. **不需要每段都走"闲聊→镖局经验→缩小争点"模板**——有些闲聊只是为了让人物喘气，自然流动即可。

#### 闲聊验收红线

- 若一段闲聊全程在交换信息而不是流露关系温度 → 退回重写
- 若凌瑶在闲聊中直接给了推理方向 → 砍掉推理部分
- 若陆昭全程面瘫只有"嗯""知道了" → 给他加反应
- 若闲聊超过 10 句 → 剪到 8 句以内

### 2.4 闲聊补齐执行计划 —— 从 6% → 30%

> **现状**：全序章 ~1003 句对话中，闲聊仅 ~60 句（6%），缺口约 **240 句**。功能密度高达 94%，每个对峙之间几乎无情绪缓冲。以下六个缺失区为硬性补齐点，任何 CSV 改写工作必须先满足这些区域的配额。

#### 补齐基准线

| 指标 | 当前值 | 目标值 | 需新增 |
|------|--------|--------|--------|

## 5. 质量控制流程

每批 CSV 改写前，先写一张小表：

```text
场景：
保留证据：
本场情绪：
陆昭变化：
凌瑶变化：
NPC 面具：
结尾钩子：
```

每批改写后，做四类检查：

1. **数据检查**：CSV 可解析，嵌套 JSON 可解析，ID 不变。
2. **玩法检查**：NPC 同时可见问题≤4；每轮基础证词=5句；威慑追加后仍回到 5 句证词结构。
3. **证据检查**：正确证据仍能命中正确 statement，错误反馈不误导。
4. **人物检查**：陆昭是否有抱负/脆弱/温热坚定；凌瑶是否可爱/闲聊/少攻略腔。
5. **节奏检查**：每 8 句内是否有新信息、新情绪或新问题；高压后是否有呼吸段。
6. **自然度检查**：每句台词是否能通过朗读测试 + 现场感测试 + 反应先于判断 + 一句一事 + 不写判词。**这是全剧本文本的强制性验收，不分角色。**

验收红线：

- 若一段台词只是在旧句基础上换词，退回重写。
- 若凌瑶连续两句都是直接提示，退回重写。
- 若陆昭连续一整场没有情绪代价，只剩逻辑推进，退回重写。
- 若改动让沈清月提前认罪或让序章赢下她，退回重写。
- 若 NPC 菜单同时出现超过 4 个问题，退回重排。
- 若任一证词轮次不是 5 句，退回重排。
- 若关键追加信息不是通过威慑/追问自然露出，而是一开始全摊开，退回重写。
- 若台词像口号、判词、谜语或网络段子，退回重写成现场能说出口的话。
- **若任何一句台词出声念一遍磕巴或像在背稿，退回重写。**
- **若出现任何括号动作描述如（手僵住）（看了她一眼），直接删除，重写为纯台词。**

## 6. 示例风格基准

### 陆昭：温热坚定

```text
[陆昭]
我不想冤你。所以这句必须问清楚。

[陆昭]
你可以说我多疑。但这船上死了人，活着的人每一句话都要经得起水冲。

[陆昭]
我查这案子，不是为了替自己赢一句清白。若真相被按回水里，下一条船还会沉。
```

```text
[凌瑶]
欸，我说个不太像证据的事啊。
我们镖局赶夜路，最怕有人临时说“换条近路”。
近路通常不近，便宜通常不便宜。
老范那条东汊，也像这种话。
```

你刚才又摸腰侧了。官印还在江里呢，摸不回来。

习惯了。

[凌瑶]
那换个习惯。你要是想确认什么还在，就叫我一声。
我人在。
```

这东西能说明他心虚，但压不到这句话。

嗯。嫌疑是一回事，能落笔的矛盾是另一回事。
```
