# 叙事修订日志 (Narrative Revision Log)

基于逆转裁判序章对比分析，对《石矶渡》序章进行的叙事强化修改记录。

## 修订 #1: P0-1 陆昭情感锚点 + 凌瑶羁绊建立

**日期**: 2026-06-13  
**优先级**: P0  
**影响文件**: `data/case_tables/prologue_ferry/prologue_lines.csv`

### 问题诊断
逆转裁判中成步堂有"千寻姐"作为情感锚点，玩家知道"他为什么要赢"。我们的陆昭全程是冷静专业的情报分析，缺乏情感驱动力。

### 修改内容

#### 1. 新增 cabin_3b（老师的旧砚）
```
走之前老师把那方旧砚推过来，说"带着压行李"。六斤重的砚台压什么行李。……他是怕我回不来，想让我手边留个念想。我没接。现在有点后悔。
```
- **emotion**: warm
- **设计意图**: 用具体物件承载师生之情。老师没说煽情的话，用笨拙借口塞东西。陆昭逞强没接，独处才承认后悔。隐含焦虑："如果我死了，连他给的东西都没带在身边"。

#### 2. 新增 cabin_5b（"写信回来"）
```
……老师送我出京那天站在驿道口，什么都没多说，就一句："写信回来。"不是"查清楚"，不是"小心"。是写信回来。……那我得活着把信寄出去才行。
```
- **emotion**: determined
- **设计意图**: 从恐惧中拉回自己的锚定方式——不是空洞的励志，而是一个具体的承诺。"写信回来"三个字的重量：老师只想确认"你还活着"。

#### 3. 新增翻船→获救过渡段 (cabin_after_all_talked_9 ~ 15)
```
"轰——！"一声刺耳的巨响从船底炸开，整个舱室剧烈倾斜。
冰冷的江水瞬间冲毁舱门，油灯熄灭，无边的黑暗和失重感将我吞没……
好冷。翻滚的浊流疯狂拉扯着四肢。官印、木匣……抓不住，全抓不住了。我在往下沉。
肺部像要炸开般剧痛。真的要无声无息地死在冰冷的江底了吗……
模糊中，冰冷的水流似乎被强硬地撕开。一只极温热、极有力的手，死死扣住了我的手腕！
被猛地拽出水面的瞬间，冰凉的夜风灌入胸腔，耳畔只留下一个清亮而坚决的声音——
"喂！撑着点！抓紧我，不许松手！"
```
- **设计意图**: 
  - 快节奏碎片化（溺水时思维断裂）
  - 凌瑶的出现如同一道光——朴素而有力
  - 与后续 first_trust 对话形成完美呼应（"你被捞上来第一句话不是救我，是船上还有人"）
  - 建立"这个人救了我"的原始情感连接

### 效果预期
玩家在序章建立情感支点：**陆昭有一个等他回去的人（老师），而凌瑶是在最绝望时刻拉住他的人。** 后续所有调查行为都有了双重动机：为案件真相 + 为了不辜负这两个人。

## 修订 #2: P0-2 证据反转节奏——击破三段式 + 旁观者反应

**日期**: 2026-06-13  
**优先级**: P0  
**影响文件**: `data/case_tables/prologue_ferry/confrontation_lines.csv`

### 问题诊断
逆转裁判中每个证人被戳穿时都有清晰的三段变化（死撑→破绽暴露动摇→彻底崩溃），且旁观者反应营造出"整个法庭气氛翻转"的快感。我们原来的对质中老范几乎没有独立击破弧，阿贵的认罪太突兀。

### 修改内容

#### 1. 新增 confrontation_fan（老范独立对质段）
- **testimony_1**: 老范油滑的初始证词（天灾论）
- **intro_dialogue**: 对质开场
- **press_1**: 追问东汊航道选择
- **break_hull**: 船底凿痕击破三段式
  - 死撑："旧伤旧痕"搪塞
  - 动摇：新茬泛白+吃水线位置→烟磕急了、句子说一半
  - 破防："那死鬼崽子要是还在，我何至于……"→丧子之痛暴露→"是被逼的！"
- **break_hull_bystander**: 旁观者反应
  - 钱里正：原来不是天灾！
  - 周氏：杀千刀的！
  - 凌瑶：追问幕后人
- **defeat_dialogue**: 失败分支

#### 2. 重写 confrontation 的 victory_dialogue（阿贵击破三段式）
- **证词陈述 (order 0-3)**: "背过的话"——太齐整
- **凌瑶质疑 (order 4)**: 点破异常
- **浮囊追问/死撑 (order 5-8)**: 浮囊亮出→否认→推给老范
- **购买记录击破/动摇 (order 9-12)**: 名字+细节对上→抠袖口→辩不下去
- **防线崩塌/破防 (order 13-14)**: "有人教小的买的！"
- **十二年爆发 (order 15-18)**: 从"小的"切换到"我"——"我跟了他十二年。吃剩饭睡柴房。二两银子。"
- **旁观者反应 (order 19-21)**:
  - 周氏："年节你还帮我贴过对联，你怎么下得去手……"
  - 钱里正："背后有人推"
  - 凌瑶："委屈不是杀人的理由"
- **认罪+供出沈清月 (order 22-38)**: 原有内容保留

### 设计亮点
- 老范的"烟杆"作为情绪信号物：磕烟灰→停在半空→别在腰上
- 阿贵的称谓转折：从"小的"到"我"标志伪装碎裂
- 旁观者反应创造"场面翻转"的群体氛围

## 修订 #3: P1-1 凌瑶独立视角

**日期**: 2026-06-13  
**优先级**: P1  
**影响文件**: `data/case_tables/prologue_ferry/dialogue_lines.csv`

### 修改内容

#### 1. 阿贵 ask_twelve_years 末尾（order 17-18）
- **凌瑶**（gentle）："陆昭，我觉得……真要是恨到去动手杀人，他提起那姑娘时，眼里就只该剩恨意了。他现在哭得这么委屈，哪像是有杀人的戾气？"
- **陆昭**（serious）："……屈辱会滋生极大的恨。但你的看法，不无道理。"
- **设计意图**：凌瑶从江湖经验出发给出"不像有戾气"的判断，与陆昭的逻辑推导形成对比。

#### 2. 沈清月 intro,5 替换
- **原文**："她说得好坦然……欠她钱的人死了，她倒像在报账？这也太淡定了。"
- **新文**（gentle）："一个姑娘家在码头讨债，不把账算得死死的、话说得硬硬的，怕是早被那些赖账的吃得骨头都不剩了。我倒觉得，她这股凡事算得清清楚楚的脾气挺坦荡的，不像是心里有鬼的样子。"
- **设计意图**：凌瑶作为独立行走江湖的女性，对沈清月产生一瞬的共情"错判"。后被证明判断有误，但让角色更真实立体。

## 修订 #4: P1-2 老范赌债故事扩充

**日期**: 2026-06-13  
**优先级**: P1  
**影响文件**: `data/case_tables/prologue_ferry/dialogue_lines.csv`

### 修改内容
`lao_fan,ask_gambling_story` 节点从 8 句扩充至 12 句，核心新增：
- "那年冬月，孩子发热烧得直说胡话，药铺要二两银子才肯抓药。我跑了一整天，一分没借到。"
- "回船时候码头边有人递话——'范老哥，急用银子？我认识个门路。'"
- "二两变五两，五两变十两……等我还不上，还是那帮人，又凑上来说可以借。"
- "到头来四十二两。那死鬼崽子……也没等到那副药。"

### 设计意图
- 用具体场景（孩子发热、药铺要钱）替代概括叙述，让玩家共情
- "码头有人递话"暗示有组织放贷，呼应沈清月利用赌债的伏笔
- "也没等到那副药"——一句话概括悲剧结局，比"没了"更有画面感

## 修订 #6: P2-2 世界感——荞麦枕联想

**日期**: 2026-06-13  
**优先级**: P2  
**影响文件**: `data/case_tables/prologue_ferry/prologue_lines.csv`

### 修改内容
新增 `cabin_free_explore_aside`：
```
枕头硬邦邦的，里头塞的好像是荞麦壳。……京城租的那间房也是荞麦枕，睡了三年都没压扁。走的时候忘了带，也没什么可惜的。就是今晚换了个硬法。
```

### 设计意图
- 陆昭注意到一件与案件完全无关的小事（枕头）
- 联想到京城生活——赋予他"有日常、有过去"的质感
- "也没什么可惜的"——嘴硬的自嘲，让严肃人设多了一丝人味
- "换了个硬法"——微妙双关（枕头硬/处境硬），不点破
