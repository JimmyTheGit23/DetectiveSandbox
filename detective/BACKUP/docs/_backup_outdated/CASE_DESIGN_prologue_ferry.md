# 序章「渡口沉舟」— 案件设计文档

> **case_id**: `prologue_ferry`
> **时间线**: 万历廿二年 · 腊月 · 荆江石矶渡
> **难度**: 简单（教学案）
> **预估时长**: 30-45 分钟
> **定位**: 免费/钩子/教学；陆昭×凌瑶首次搭档

---

## 一、案情梗概

万历廿二年腊月。长江中游荆江段，石矶渡——一个偏僻的江畔小渡口。连日冬雨，江水暴涨。

商人**周德茂**携仆从**阿贵**乘船过江，准备经水路去武昌府办货。当夜船在江中倾覆，周德茂溺亡。船家**老范**声称遇上暗礁急流，不可抗力。

巡按御史**陆昭**奉旨赴任途中被暴雨困在石矶渡，被死者家属拦住求助。金鳞镖局信使**凌瑶**同样滞留此地，她无意中目击了案发前夜的可疑行为，由此成为陆昭的第一个搭档。

## 二、真相

### 合谋者

- **主犯**: 仆从阿贵
- **共犯**: 船家老范

### 动机

- **阿贵**: 跟随周德茂十二年，主人发达后准备遣散旧仆（已写好「遣散银二两」字据）。十二年青春换二两银，既恨且惧。
- **老范**: 欠赌债四十余两，急需大钱。阿贵许诺事成后分他五十两货银的一半。

### 手法

1. 老范故意选了经过暗礁的航道（本地人都知道避开的水域）
2. 到暗礁处时，阿贵以「帮东家盖被」为由靠近，趁船体剧烈摇晃按住周德茂
3. 老范同时打开事先做了手脚的船底活板，江水涌入
4. 阿贵提前穿了从老范处拿的水牛皮浮囊（藏在夹衣内），假装落水实际安全
5. 周德茂不善水，被按压后呛水，在冰冷江水中迅速溺亡
6. 老范水性极佳，自行脱困

### 伪装

- 对外说法：暗礁翻船，不可抗力
- 阿贵装出「惊吓过度」痛哭流涕
- 老范将船残骸推到下游礁石群——让它看起来像自然触礁

## 七、推理路径

```
Phase 1 教学阶段：
  → 去码头看沉船残骸 → 发现船底破洞
  → 对话周氏 → 了解背景 + "阿贵反常"
  → 对话阿贵 → 哭得很假 + 细节矛盾
  → 对话老范 → 解释"暗礁"（谎言）
  → 凌瑶引导：教玩家地图移动、搜索、笔记本

Phase 2 自由探索：
  → 发现王大爷 → 证实航道错误
  → 搜索阿贵行李 → 发现浮囊
  → 搜索老范住处 → 发现赌债
  → 用证据质问阿贵/老范 → 揭穿谎言

指证阶段：
  凶手=阿贵 + 动机=图财报复 + 手法=合谋凿船
```

## 八、序章开场（爆炸式）

### 第一幕：尸体

> 黑屏。江水声。风雨大作。木头断裂的巨响。人的惨叫被江水吞没。
>
> 画面亮起：冬雨如刀。荆江石矶渡。黎明。
>
> 一具尸体被江水冲到岸边。面朝下，半截身子还泡在浑黄的水里。
>
> 围观的人已经站了一圈。没人敢上前。

### 第二幕：陆昭被拦

> 「大人！大人您是京里来的官吧？！求您做主啊——」
>
> 一个妇人跪在泥地里，死死抓着陆昭的衣角。她身后，就是那具尸体。

### 第三幕：凌瑶冲来

> 远处一个身影穿过人群挤进来。深蓝灰短衫，浑身是雨水。
>
> 「让让让让——！那个大人！昨晚我看到那个船家干了件怪事！」

三拍之内：**尸体-悬疑-关键人物**全部到位。

## 九、教学设计（凌瑶引导）

| 时机 | 凌瑶台词 | 教学内容 |
|------|----------|----------|
| 序章结束后 | "那个……陆大人，咱们先去哪？" | 地图移动 |
| 第一次到达地点 | "这地方能搜搜看吧？我帮您望风！" | 搜索/探索 |
| 第一次获得证据 | "这东西重要吧？看看小本本记上了没？" | 笔记本 |
| 第一次获得线索后 | "陆大人，要不要咱们合计合计？" | 讨论功能 |
| 获得足够证据 | "证据够了吧？是不是该抓人了？" | 指证面板 |
| 对话中出现证据选项 | "您不是拿到那个东西了吗？问问他看！" | 出示证据 |

## 十一、结案后 META 钩子

### 密信彩蛋（Perfect/Good 结局后）

> 案件结束。阿贵和老范被押送至县衙。
>
> 陆昭收拾行装准备启程时，凌瑶从沉船残骸中翻出一样东西——一封泡烂的书信。
>
> 大部分字迹模糊不清，但能隐约辨认：
>
> 「……沈氏旧案……按察司……棋子不知棋盘……」
>
> 收信人一栏只剩一个姓：**沈**。

### 神秘旁白（结局画面淡出后）

> *「……第一步棋，落下了。」*
>
> *「不要急。让他先走完这段路。」*
>
> *「浔阳楼的事……很快就会发生。」*
