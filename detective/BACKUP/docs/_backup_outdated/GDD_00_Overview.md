## 一、项目概述

《七日蝉鸣》是一款以「七天限时破案」为核心体验的沙盒侦探游戏。玩家扮演侦探，在一个封闭小镇中调查凶杀案，通过探索场景、收集线索、审问嫌疑人、推演逻辑来揭开真相。

### 核心卖点

| 特性 | 说明 |
|------|------|
| AI 预生成剧本 | 每局开局前由 AI 生成独特案件，确保高重玩性 |
| 零运行时成本 | 运行时纯本地执行，无实时 API 调用 |
| 选项制对话 | 动态选项列表替代自然语言输入，消除 AI 幻觉 |
| 七日倒计时 | 时间压力驱动决策，每一步都有代价 |
| 多结局分支 | 至少 5 种结局，由玩家行为动态决定 |

### 一局参数

| 参数 | 值 |
|------|-----|
| 一局时长 | 约 2.5 – 3.5 小时 |
| 游戏天数 | 7 天（序章 + D1-D7） |
| 1 天 ≈ 现实时间 | ~25 分钟 |
| NPC 数量 | 6 – 10 人 |
| 场景数量 | 8 – 12 个可探索地点 |

## 三、关键架构决策记录

### 决策 1：保持 Godot 4.x
- **原因**: 项目已初始化为 Godot 工程；2D 侦探游戏无需 Unity 的 3D 能力；GDScript 迭代更快

### 决策 2：零运行时 API 成本
- **原因**: 去掉实时 LLM 调用；AI 仅在开局前预生成对话树；运行时纯本地执行
- **方案**: 预制模板 + AI 填槽 + 本地约束校验

### 决策 3：选项制对话替代自然语言输入
- **原因**: 彻底消除 AI 幻觉风险；降低成本至零；可精确控制叙事分支
- **方案**: 动态选项列表，根据玩家状态/线索/信任度自动增减可选项

### 决策 4：认知负荷替代精神值
- **原因**: 更贴合侦探调查的心理建模；为信息过载提供有意义的游戏机制

### 决策 5：推理陷阱替代 QTE
- **原因**: QTE 与推理体验不匹配；推理陷阱更考验玩家逻辑能力

### 决策 6：2D 16×16 极简像素风
- **原因**: 开发者无专业美术能力；16×16 像素精度制作门槛最低、迭代最快；极简风格容错率高，风格统一比精致更重要；与 Godot 4.x 的 2D 系统完美适配
- **方案**:
  - 风格参考：Undertale / DELTARUNE 式极简复古像素
  - 视角：Top-Down 俯视
  - 像素精度：16×16 基础单元格（角色/Tile/物品图标均为 16×16，UI 可用 2x/4x 倍率）
  - 调色板：限定 16-32 色，暗色调侦探风（参考 PICO-8 色板或自定义）
  - 美术策略：极简像素 + AI 生成辅助，零外部成本
  - 制作流程：AI 生成图 → 纯紫背景(#FF00FF) → 色键去除 → 导出透明 PNG → 像素化缩放
  - 分阶段执行：Phase 1-2 使用纯色块占位图；Phase 3 通过 AI 生成像素素材统一替换
  - Godot 渲染：Viewport 拉伸模式 `canvas_items`，纹理过滤 `Nearest`（保持像素锐利）
